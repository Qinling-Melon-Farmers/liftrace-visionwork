# uav_coverage_memory — research observer

独立ROS1旁路包，shadow入口默认不启用，未被正赛launch包含。research_trial.launch是额外的显式SITL研究包装入口，必须有sim_run.sh提供的SIM_RUN_DIR。观察器自身没有目标选取、航点/速度命令、MAVROS/投递服务调用；当前只用于搜索效率研究的第一阶段。

输入来自实际RGB、匹配CameraInfo、图像源时刻的相机到地图TF、FreeDOM占据点云和任务状态。配置集中在`config/shadow.yaml`；相机内参/畸变来自CameraInfo，不在源码写固定值。输入ROS订阅队列均为1；另保留最多8份CameraInfo和4份限量占据点云，按图像时刻选快照，图像不排历史队列。原始图像只接受全幅、无binning的匹配标定，裁剪/缩放必须先提供相应标定。

核心`src/uav_coverage_memory/memory.py`不依赖ROS，负责有界栅格、像素质量、畸变/姿态投影、已知点云遮挡、连续多帧累计和TTL/重置。每格取中心及四个内缩角点，全部落入成像有效域和边缘裕量后才参加质量/遮挡判别。布朗畸变投影限制在标定成像域，避免远处射线经多项式外推折返进画面。

## 状态和边界

| 数值 | 含义 |
|---|---|
| 0 | 未保留观测/记忆已过期 |
| 20 | 实际图像投影内，但占据地图缺失、过期、过大或无效，可见性未确认 |
| 40 | 局部过暗/过曝或纹理方差不足；低纹理与模糊尚未通过真实标签区分 |
| 60 | 投影前方存在已知障碍点，保守邻域遮挡 |
| 80 | 图像质量代理通过、未发现已知遮挡，等待足够独立帧和持续时长 |
| 100 | 多帧可见估计，**不表示已知自由空间、目标召回或搜索完成** |

`~state_grid`借用OccupancyGrid作为带原点/分辨率的显示容器，数值是上表状态码，**不是占据概率，严禁接规划地图入口**。`~status`是带epoch、原因、各状态面积及处理时间的JSON。默认输出位于`/research/coverage_memory/`。

图像/标定/TF时间错误不增加观测。实际新帧之间必须满足最小间隔，定时器重复读取同一图像不计新帧；连续观测中断会重建连续帧计数。新障碍遮挡会撤销对应活动估计；新鲜地图缺失时不保留本次活动估计。历史可见估计最多保留配置的TTL，不承诺环境期间不变。

任务ID变化、ROS时钟回退、标定变化和本地`~reset`会清除相应记忆；任务/手动重置还丢弃排队图像与点云并拒绝旧时间戳。reset仅清研究观察器，**不会清FreeDOM或视觉目标缓存**。上游地图内容复用、定位重置和裁判调整后的联合epoch机制仍需后续验证；新时间戳不证明上游内容已更新。

占据点云只能帮助发现遮挡，无点不能证明射线畅通。当前5点/格、8px遮挡分块及邻域扩张也不是完整遮挡积分；100始终只是估计，不输出coverage_complete，不影响任务游标。

## 使用与检查

`launch/shadow.launch`默认`enabled=false`。经后续明确授权的联调中，可单独启用观察器，`config`指向现场参数文件；它本身不启动Gazebo、PX4、相机、雷达或任务控制。原比赛入口不增加include。

独立Catkin构建/安装后，可通过`catkin_make run_tests_uav_coverage_memory`运行纯离线测试，测试不启动ROS Master。研究包不应复制到正赛部署包；板端参数和资源尚未验收。

后续增加了50万点上限和保留字节序/行填充的数组点云解码、显式同帧清晰参考选项（默认关闭）以及限量同步Recorder。Recorder默认关闭；研究入口最多120份、每6 ROS秒采样一份，不录全场视频/bag。

queries.py提供只读区域面积/排序和MissionLedger；活动TTL到期不抹掉历史，当前视角遮挡也不代表过去未看过。联合epoch变化才清空历史。该模块当前仅离线验证和复盘，无导航目标输出；历史估计依然不是可达性/检出证据。

状态栅格的Header是状态快照时间，100可能来自TTL内较早的图像，不表示此帧刚刚看见；使用时必须同时理解epoch和上述估计语义。
