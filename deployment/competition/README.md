# 独立正赛入口

## 2026-10-10：已验证投递优化定向集成

当前主线集成采用实飞确认的物理槽位补偿与投递提速：先确认靶心，再冻结靶心并计算完整姿态旋转后的FC补偿目标；补偿与下降并行。当前FC和投口水平误差均严格小于4cm，FC离地0.35～0.45m，并且原许可有效时即可请求释放，不另等速度门槛或0.30秒稳窗。冻结前仍需五张不同的新鲜图像，短暂缓存过期仅撤销就绪并允许有界接续计数。H使用独立低位稳定条件，不能套用投递的取消稳窗规则。

正式模板按此前用户明确要求保持规划1.2m/s、加速度1.0m/s²；投递0.35m、软件限高3.2m，走廊快/慢前视0.6/0.4m，运动优化与高位续扫默认开启。普通默认FC高位2.6m；矩形/两线候选FC2.76m，三线候选FC2.16m（镜头2.60/2.00m）。三个候选均可选择，但全尺寸场地覆盖和速度表现仍需按实际场地验证，不能把有限测试场地成功当作这些配置全部验收。

H观察高度保留正式0.9m；低位目标0.35m、POSCTL交接高度上限0.37m，需既有H位置/速度/短稳定窗条件。POSCTL之后由飞手完成末段，现场实现成功不代表竞赛自主落地判分已经确认。

导航脱困恢复、EV预测和现场YOLO执行层优化本轮不进入main。10月10日板端只更新0928，独立正赛目录未随此次主线合并自动更新。源码集成范围和剩余研究项见[本轮记录](../../docs/verification/main_selected_20261010/REPORT.md)。下方带日期段落为历史交付状态。

完整操作、版本来源和待验收范围见 [整机说明](../../docs/deployment/competition_integration_20261003/README.md)。本目录不依赖九组专项。field.example.yaml需按现场测量填写；默认缺走廊/H时不能飞行。

当前有效参数、规则/技术会差距、实测FOV覆盖及同步状态见 [10月4日正赛复核](../../docs/verification/competition_config_20261004/REPORT.md)。其中生成的runtime/control仅供离线参数分析，不可直接用于飞行。
