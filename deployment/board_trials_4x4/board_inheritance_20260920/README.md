## 静态TF的具体适用条件

“静态”不等于“单位变换”。任务地图固定在起飞坐标系，只说明它不会跟随机头旋转，不能证明独立初始化的LIO与飞控地图零点完全一致。相机/IMU安装杆臂和两个估计器初始化、航向对齐/重置都可能造成差异。

同一机体中心B的两路位姿给出：`T_camera_init_map = T_camera_init_B × inverse(T_map_B)`。先补偿IMU到飞控中心的已知杆臂，再比较同一时刻的同一物理点。本入口的LIO外部位姿适配已处理该杆臂；不能把两个不同物理原点直接当成同一点。

例如map的X轴相对任务X轴差10°，直接使用单位TF时，沿X发出的2m目标横向偏差约`2*sin(10°)=0.347m`。平移差20cm则会给整条航线带来约20cm偏移，Z原点差还会影响巡航和视觉地面投影；“地面MAVROS Z≈0”无法单独消除这些差异。

可以静态发布的情况：本次启动后已测量/标定变换，两估计器在本次运行中没有重置或相对漂移，且只存在一个TF发布者。这时固定发布测得的非单位变换是合理方案；每次重新初始化仍需重新核验。只有实测确实重合时，单位TF才成立。

当前实际实现是20组同步稳定样本建立关系，随后滤波更新、20Hz动态广播，并有变换跳变稳定性检查；**不是已经实现了“测一次后冻结静态TF”**。此次保留既有行为，没有趁部署更换定位算法。若后续要试固定变换，应单独验证估计器重置/漂移的处理，不能直接把节点替换成全零平移/单位四元数。
