# 任务二：低空多投、走廊避障与H视觉降落

工作台显示“现场第2组 · 低空多投接走廊/H（默认两投）”，仍对应05_low_multi。

- 低空搜索/恢复巡航为FC中心离地1.4m。有效高权重类别为red_cross、panzer、bridge；任一类别的候选通过连续观测、身份/坐标/时间校验后即可中断，不等待三个目标齐全。检测框本身不构成释放许可。
- 目标接近、投口杆臂补偿、视觉对齐、下降、释放许可和防重复均继承原任务链；本组投递目标0.30m、释放范围0.28～0.35m保持原值。速度档不覆盖这些投递参数。
- 第一次投递后恢复搜索；若已有可用高权重目标，现有调度可直接选择下一个目标。未完成的搜索航点游标保留。delivery_count支持1～3，默认2；最后一次释放必须完成RECOVERY才能进入投后走廊。未投满就扫完、恢复失败或任务失败不得算成功。
- 投满后按corridor_waypoints进入同一Fast-Planner/实时三维地图避障链，经过走廊、到landing_xy，按模块08的H视觉对准、下降和POSCTL交接流程收尾。飞手完成落地；不会使用旧的原地30cm悬停收尾。

在F:/UAV/飞行工作台重启服务、刷新网页，打开任务二的“地图调整航点”。支持点击、拖动、坐标输入、排序、删除、撤销及本机YAML导入导出。
低空搜索点使用search_waypoints_xy；每个点为相对静止起飞参考的[x,y]，统一搜索AGL为1.4m。地图中的高位survey_xy不参与此任务。走廊点可单独设置AGL，H位置可单独调整。
保存并用于本组后自动生成独立现场覆盖YAML，原现场文件和其他任务草稿不覆盖。先执行“配置检查”核对有效参数。

两档沿用模块08的规划限制：有限空间0.5m/s、0.35m/s²；参考08速度1.2m/s、1.0m/s²，后者继承08跟随距离与制动假设。速度是规划上限，实际飞速仍受轨迹、跟随控制、目标对齐和避障约束。走廊默认高度按实测航点设置，当前参考为0.9m；H捕获高度1.2m。

本组独立site.yaml的走廊/H几何复制模块08现有现场文件，搜索初始保留前方6m直线。它不是新场地测量或实飞验收，换场地必须在地图重新填写。空走廊/H配置会拒绝启动；直接运行裸模块settings.yaml也会拒绝空走廊，需传入site.yaml或工作台生成的覆盖文件。
