# toudi4 新视觉闭环实跑与当前阻塞

日期：2026-08-13

## 1. 本轮结论

本轮在 `toudi4_copy.world`、仓库内单下视相机 + MID360 机架、PX4 SITL、
Fast-Planner、新 `uav_vision` 和旧 `patrol_control` 上执行了两类完整联调。投递动作全部
接 `uav_mission` 的安全代理和 raw mock，未启动真实舵机或 PWM。

- 固定三投：自动起飞、建图、新视觉地图候选、旧控制对准和两次受保护 mock 投递实际
  发生，但 3/3 和 H 视觉降落未通过。
- 无靶标坐标覆盖搜索：仅向任务管理器提供 12 个覆盖端点，没有提供任何靶标真值坐标；
  新视觉发现五类标准靶并形成五个 stable ID，按权重完成 tank、panzer 两投，第三投未完成。
- 两轮均不能作为完整比赛闭环 PASS；日志按 `sim_run.sh` 规范完整保留。

## 2. 固定三投结果

日志：`logs/toudi4_newvision_fixed3_20260812_232317/`

已证明：

1. PX4 SITL 能自动进入任务并起飞；
2. 单下视相机图像约 18～21 Hz，新视觉能输出合法 `camera_init` 地图候选；
3. 新视觉证据能带动旧控制进入对准/下降状态；
4. 安全代理允许的 mock 投递实际完成两次。

失败点：

1. 首个 pillbox 的高位投递承诺在旧控制完成稳定帧和下降前过期，最终只有 2/3；
2. 本轮没有产生可验收的 H 结构确认证据，末段只是进入仿真 `AUTO.LAND`
   分支，不能算 H 视觉降落；
3. Gate 退出码为 1，因此此前 toudi3 的固定三投 PASS 不能直接外推为 toudi4 PASS。

## 4. 本轮修正的接口问题

首轮覆盖搜索暴露了两个真实代码问题，已在提交 `0869c37` 做最小修正：

1. 外部任务模式下，旧 `WayPointDetectDone()` 不再用固定路线航点覆盖 Mission Manager
   给出的候选 `map_point`；旧固定路线分支保持原行为。
2. 高位标准图案是语义候选，下降后的 circle 是释放证据，两者不会拥有同一个 stable ID。
   当前按载荷顺序、对准模式、circle 证据和飞机到语义地图点的距离完成安全归因。
3. 投递承诺调整为 45 s，外部对准/任务对准上限分别为 75/90 s；地图 ID 合并距离调整为
   0.7 m。复跑中五类恰好形成五个 ID，未再出现 pillbox 分裂。

## 5. 走廊与 H 的场景阻塞

当前 `toudi4_copy.world` 不能用于旧 0.8 m 门洞 Gate：

- 旧 `toudi3.world` 的门洞由 `Wall_15` 四段 collision 组成，北区边界还依赖
  `Wall_16`；
- `toudi4_copy.world` 中没有 `Wall_15` 和 `Wall_16` 实体，只保留/另存了
  `Wall_14`、`Wall_20`、`Wall_22` 等模型；
- 因此直接运行旧 `x=-2.88, y=4.0→4.45` 路线只会穿过缺失障碍的空场，不能证明避障
  或穿门能力。

H 模型 `landing_h=(-0.493412,-1.77269)` 存在，但 Coverage R6 当前返航/落地条件只检查
回到任务点和高度，不检查 H 视觉证据；固定三投本轮也没有 H 确认。因此两条链路都不能
宣称 H 自主降落已通过。

## 6. 可落地解决顺序

1. 从旧 `toudi3.world` 恢复 `Wall_15`、`Wall_16` 的 collision/visual 到 toudi4 的
   专用派生 world，保留 `toudi4_copy.world` 原文件不动；用脚本检查 0.8 m 门宽、门高、
   门前后净空和模型唯一性。
2. 建立独立 corridor assertion：必须记录门南/门中/门北双向穿越、0 碰撞、机体中心与
   门框净空、唯一 `/fastplanner/goal` 发布者；直达 PX4 航点不能作为规划避障 PASS。
3. 对 bridge 失败做图像级复盘：保存进入 ALIGN 前后 5～10 s 的 debug image、circle
   refine 拒绝原因、图像时间戳/TF 年龄和机体位置，优先检查地图落点偏差、近地视场裁切、
   circle 阈值，而不是继续放宽全局超时。
4. 为 H 建立独立 landing assertion：任务阶段必须为 `landing`，H 内外结构证据有效，
   再允许旧控制执行末段；普通返航至 `(0,0)` 或高度下降不能计为 H PASS。
