## 启动工作台和设备

在Windows终端执行，浏览器打开服务打印的地址（默认 `http://127.0.0.1:8791/`）：

```powershell
wsl -e bash -c 'cd /home/xhj/liftrace-worktrees/r2026-board-vision-tests && bash tools/flight_workbench/start_workbench.sh'
```

1. 顶栏「板端地址」选现场IP →「连接」→填SSH口令（免密可空）→弹窗「连接」。
2. 「单实例检查」→「开始检查」：确认工程/模型/环境存在、旧专项已退出。正常roscore/MAVROS存在时会显示进程，设备链可保留。
3. 「一键启动设备」→默认不勾「包含舵机端子」→「确认启动」，等roscore、MAVROS、MID360、相机逐项成功。
   某步失败先看对应终端、处理后再启动设备；已运行会话会复用。
4. 现场1/2/4/5实投还需在「5a · 舵机 PWM 初始化」点「启动」并确认，再在「5b · 舵机服务」点「启动」并确认。
   驱动启动会复位三只舵机；先确认载荷/人员位置。已有外部服务不重复启动，服务须为 `/legacy/Servo_raw` / `patrol_control/Servo`。
   仅记忆、采集、H、走廊及看板模拟整场跳过舵机。

**一键启动设备不启动专项，此时不会出现专项READY。** 还必须按下节点任务卡片。

## 点击开始本轮

1. 新配置先勾「只做配置检查」→「预览（preview）」→「确认启动 preview」。看到CONFIG_VALID后取消配置检查勾选。
   04/08空坐标报错是预期，不能绕开；需要真实preview检查图像/定位时，先运行preview、收尾退出后再开flight。
2. 目标卡片上方「模式」点「飞行 flight」（只是改变表单，尚未启动）。
3. 勾「已确认：飞机回到起飞点、未解锁、机头朝场内」。实投组输入「实投」；第6组另选速度。
4. 点卡片**底部「飞行（flight）」**→核对完整命令→弹窗「确认启动 flight」。只选卡片不启动。
5. 等 INITIALIZING → MAPPING_READY →最终READY。fc_lio_disagreement时保持静置等收敛。READY后由现场飞手人工解锁。
6. 当前现场配置在人工解锁后自动请求OFFBOARD、起飞稳定、调用一次任务开始。看时间线 `AUTO_MISSION_START True`。
   **不用再点右栏「启动任务」**。False/取消时由飞手判断，不重复点击催促。
   本工具无自动解锁按钮；人工解锁仍是保留的现场动作。

## 换下一组

**只在落地上锁后换组，不能空中切任务或重启应用。**

1. 现场1–6结束是30cm悬停，先由飞手接管落地上锁；H类等待实际ON_GROUND和未解锁。
2. 当前卡片「停止（Ctrl+C）」→「停止试飞」。已正常退出则无需再停。停止入口不是降落指令。
3. 终端6确认BAG_CLOSED、Trial application stopped和会话退出。
4. 放回起飞点、机头朝场内+X、静置、重装所需槽位。正常设备链和已有舵机服务可以保留。
5. 下一张卡片点「选择此组」，重新选flight、勾确认、输入实投词，点底部flight，重新等该轮READY，再人工解锁。
   不用每轮点「全部停止」/「一键启动设备」；换电或网络变化后重新检查和连接。
6. 全部结束先落地上锁、trial收尾，再「全部停止」或「断开」。它们会关闭本工具管理的应用/设备会话，外部终端启动的设备另行收尾。
