# 补偿终点边界小修复（2026-10-08）

## 改动目的

投递末段由控制器直接跟随位置目标，普通规划器仍在工作不代表这一小段重新通过了完整规划避障。本轮仍不接回下降点云准入；现场验证应选择投递区域确有净空的位置。

已有 `NearWallAlignFence` 会裁剪最后的ALIGN指令。若补偿FC终点位于这个范围外，继续检查到未裁剪终点的4cm释放误差就可能一直不能通过。例如靶心在合法FC边界内4cm，后仓要求FC继续向外12cm，指令裁剪后仍差8cm。

## 本轮行为

1. 从靶心减去完整姿态旋转后的物理投口杆臂，得到原始补偿FC终点。
2. 在冻结前复用已有边界的 `contains()`，分别使用当前和目标航向，与最终指令裁剪使用相同机体尺寸及航向余量。边界未启用时不新增限制。
3. 明确不可达时保持当前位置、不冻结下降、不发起舵机，并锁住本次失败尝试；不会把截断终点当作补偿成功，也不会由下一张图像把失败尝试复活。
4. 通过已有 `DropAlignmentFeedback` 携带绑定本次动作的原因 `compensated_target_outside_boundary`，任务桥接复用既有取消/未执行回执和目标失败处理。没有新增任务管理器、点云订阅或恢复状态机。
5. 新的完整ALIGN动作重置后，可正常处理下一个目标；已冻结的合法目标仍不追低空残缺图像，已开始的释放与投后恢复不受晚到反馈打断。

正常靶位的流程及参数不变：原视觉确认→冻结→补偿与下降并行→到位低速稳定→原许可有效时释放。此次终点判断不证明整段补偿下降路径不存在实体障碍，也不修改任务总期限和原重试策略。
