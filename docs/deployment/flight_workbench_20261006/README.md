## 已手动启动节点后的实时观看

无需通过工作台重新启动节点。在主页点「连接」，随后点顶栏「实时观察」或「电机诊断」，
分别打开 `/observe` 和 `/motor` 独立大页。也可直接在浏览器打开
`http://127.0.0.1:8791/observe`、`http://127.0.0.1:8791/motor`。
连接会启动只读探针；不会替换现有定位、控制或飞行进程。两页只有状态查看与浏览器本地记录操作。

显示 FC/LIO/EV 各自坐标系的位姿/姿态、目标位置、电池、任务及低空诊断状态、LIO耗时和队列。
未收到/过期消息明确标注；FC local Z不当作离地高度，不未经TF直接比较跨坐标系距离。
曲线约1Hz，仅适合趋势观察；高频reset、控制脉冲和故障根因需以录包/飞控ULog复查。

本轮不增加相机预览、JPEG编码、视频录制或相机启动，沿用现有设备链设置。

## 电机低空诊断大页

三组动作来自已有 `deployment/low_hover_observation/profiles.yaml`：定点悬停、前移、四边形。
沿用另一个对话准备的终端启动流程，本页不下发动作。正在执行时可直接连接观看。

1. 在页内查看当前低空诊断 `profile/stage/index/reason` 与录制进程状态。
2. RC输出先按原始通道显示。若要四电机曲线，先逐路选择真实的RCOut数组通道并确认映射；
   默认全部未映射。不能把 AUX1 或 ULog logical Motor1直接等同于RCOut第1项。
3. 选择本次观察组标签，点「开始本地片段」，观察后点「结束本地片段」。这个按钮只采集已收到的浏览器数据，
   不启动或停止无人机动作/板端录制。
4. 比较不同片段的样本数量、输出、姿态、高度、电池和LIO趋势，导出JSON/CSV。
   当前页最多保留1800条采样，页面关闭后应重新观察或使用已导出文件。

RC输出是控制输出，不是电流、温度或RPM。ESC数据仅在原话题提供时显示，
按消息数组条目列出，未核实物理编号前不自动关联四电机。电池总电流不能代替某个电机电流。
MAVROS1.20.1 RCOut由SERVO_OUTPUT_RAW按port及协议通道数拼接，不能靠历史机臂编号猜数组映射。
[RC IO源码](https://github.com/mavlink/mavros/blob/1.20.1/mavros/src/plugins/rc_io.cpp)，
[ESC状态消息](https://github.com/mavlink/mavros/blob/1.20.1/mavros_msgs/msg/ESCStatusItem.msg)。

## 常规试飞按钮顺序

1. 选择当前板端地址，点「连接」。核对工程根、现场目录和环境脚本。
2. 点「单实例检查」，看设备/旧应用、源码能力与生成接口检查。正在运行的设备可复用，
   冲突的旧专项应用须先退出；检查结果不能代替接线与实物朝向核对。
3. 在目标卡片点「选择此组」或标题。选组只切换界面，选中不会启动、停止或替换正在运行的任务。
4. 按需要选择投递方式、运动优化、搜索路线、续扫；第6组另选采集速度与光照标签。
   点「配置检查（不启动节点）」；应看到 `CONFIG_VALID`。04/08航点留空会拒绝，需先填实测坐标。
5. 点「一键启动设备」，依次等待 roscore、MAVROS、MID360、相机就绪。仅真实投递需要另行
   启动5a/5b舵机，两个操作各有独立地面确认；5b会依次复位三槽。
6. 选卡片「飞行 flight」模式，勾「飞机回到起飞点、未解锁、机头朝场内」。
   实投需输入「实投」。点「飞行（flight）」，核对弹窗命令，再确认启动。
7. 等 `INITIALIZING → MAPPING_READY → READY`。**飞手人工解锁并拨入 OFFBOARD**；
   稳定后入口自动启动任务，看到 `AUTO_MISSION_START True`。工作台不解锁、不切飞控模式。
8. 现场1–6组末段显示 `PILOT_HANDOFF`（30cm悬停交接）后，由飞手接管落地上锁。
   H/走廊/整场走既有H视觉降落流程。ABORT或切换模式接管后，工作台不自动恢复任务。
9. 已落地上锁后，点「停止（Ctrl+C）」，等待 `BAG_CLOSED` 与应用退出。
   再选下一组、重新检查/启动；设备链可保留。运行中仍可浏览其他卡片，所有新启动按钮禁用。

「预览（preview）」会启动地面应用链；只想验证配置应点独立「配置检查」，二者不同。
任务切换不能通过飞行中点另一张卡片完成，必须完成当前任务接管、落地与收尾。

## 监测含义与版本要求

- READY表示应用就绪，不代表起飞许可或飞行验收。COMPLETE与ABORTED单独显示，
  `armed=False`只代表上锁；不能据此证明任务成功或已落地。
- 30cm悬停状态来自 `/board_trials/terminal_hover_status`；LIO诊断来自
  `/laserMapping/realtime`，展示输出年龄、IMU/雷达队列与诊断级别。两话题在YAML中可改。
  缺失/过期显示未观测；LIO主线程CPU不代表所有OpenMP线程总CPU，队列小也不证明定位准确。
- 回报保存启动选项、任务终态、悬停状态及LIO诊断。回报是观测记录，不自动给飞行判PASS。
- 工作台不自动部署代码。板端需具备当前模块脚本、`run_trial.py`、任务/控制/视觉补丁及
  重新编译后的消息服务；仅复制Python不足以满足最新释放许可链。
  「单实例检查」会对比源码字段与已加载生成接口，并显示续扫参数能力。
  Git HEAD仅代表目录版本，不代表已经运行的进程版本。
- EV连续性/飞控reset恢复仍是独立诊断研究，未加入自动恢复、重新解锁或自动抢回控制。

离线验证覆盖：参数/确认约束、前后端命令一致、10卡切换、模拟与实投、配置检查、
并发拒绝、遥测新鲜度、ABORT/上锁区分、只读探针、纸板工程端到端与浏览器实际控件。
具体本轮通过数及同步提交见联调变更记录。
