# 飞行工作台分发版 · 2026-10-16

## 启动

完整解压后，Windows双击 `start_windows.cmd`，浏览器打开终端实际显示的地址（默认 http://127.0.0.1:8771/）。Windows工作台支持原生Python，不需要Linux/WSL；需要已安装Python 3.10+及requirements.txt中的依赖，本包不是内置Python的独立exe。Linux/WSL使用start_workbench.sh。

已有工作台请先正常关闭旧后端，再启动新目录；只刷新浏览器不会替换旧后端。现有个人连接配置可能被保留，请在页面核对当前板端IP。
