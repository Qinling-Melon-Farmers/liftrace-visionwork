## 启动
完整解压后 Windows 双击 `start_windows.cmd`；Windows 原生 Python 3.10+，依赖见 requirements.txt，不需要 WSL。本包未内置 Python。Linux/WSL 用 start_workbench.sh。关闭旧工作台后再启动；默认网址 http://127.0.0.1:8771/。页面顶部显示本版标识，默认板端 orangepi@192.168.43.99；个人已有连接配置优先，换网络在界面修改。
