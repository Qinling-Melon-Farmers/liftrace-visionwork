# 板端建图启动修复与高位记忆复盘（2026-09-29）

本轮只修改本机板端专项入口、做离线检查并同步参考分支；没有连接飞机、启动仿真、改飞行速度或替换视觉模型。八组专项共用本次启动修复。导航/视觉高位策略源码没有在此轮重新调阈值。

## 建图修复

原顺序为定位与FreeDOM同时启动，随后等待飞控稳定。现在改为：

1. 确认旧定位、规划、视觉应用已退出；发现同名残留节点就拒绝启动，不自动杀他人的节点。
2. 先启动FAST-LIO、外部位姿桥及原静态TF，FreeDOM尚不存在。
3. 保留原静置/机头方向/相机检查，并新增两路FC中心位姿一致检查：位置差≤0.20m、航向差≤5°，持续2秒。两路都在camera_init；按源时间戳配对，最大配对差0.10秒、位姿年龄0.30秒。使用历史缓冲配对，避免将较新的飞控位姿与延迟到达的LIO硬比较。
4. 飞机必须保持未解锁。MAVROS状态年龄上限2.5秒，适配约1Hz状态发布。
5. 启动独立mapping.launch，得到空白FreeDOM进程；等待同坐标系非空点云持续至少3秒，点云年龄≤1.5秒，等待上限30秒。
6. 启动任务应用，确认检测、精修、投影、候选四路都至少有两个递增源时间戳且年龄≤1秒，再结合控制输出宣布READY。空候选数组允许通过；一条启动时的空数组不能证明链路活着。

建图预热或应用准备期间若定位一致性失效，启动失败并按原收尾路径停止本次子进程。下次重新运行从空地图开始。不会在飞行中重置地图；不将墙体或人员残影按时间直接清空。达到READY前不要解锁。

参数集中于`deployment/board_trials_4x4/common/uav_board_trials/config/mapping_startup.yaml`，可通过`--mapping-startup-config /path/config.yaml`明确选用完整现场配置。原静态TF、mapping_imu变换来源、已知安装外参、膨胀25/20/10cm、虚拟顶棚关闭均保留。这个补丁先阻止初始化污染，没有宣称解决飞行中估计器漂移或全部动态障碍清除问题。

`localization.launch`默认不再带FreeDOM，硬件请沿用各组start.sh，由supervisor按顺序启动；不要仅单独launch localization后就认为地图已就绪。既有SITL入口显式传start_mapping=true，保留原仿真行为；本轮没有运行SITL，不能把静态展开称为飞行通过。

## 当前高位流程与门槛

完整策略：低空入场→定点升到高位→巡航积累粗/精线索→走完路线或三类可用证据齐备提前结束→当前位置附近选可行下降点→低位按障碍代价排序重访→新鲜视觉确认→对准/释放/恢复→走廊与H阶段。

|层级|入口与门槛|可做什么|
|---|---|---|
|单帧粗线索|类别置信度≥0.60，有效地图投影/TF；图像年龄≤0.50秒、TF年龄≤0.10秒；SURVEY高位阶段|保存导航假设，无需圆环，不能直接投递|
|支持提前结束的粗线索|同一位置至少两张不同图像，间隔0.10–1.00秒，位置差≤0.50m；无同类多位置或同地异类冲突|三类bridge/panzer/red_cross同时满足后，高位优先/整机模式可提前中断|
|正式视觉confirmed|标准靶类别≥0.60、有效几何≥0.70、中心已精修且地图有效；红十字类别≥0.80、几何≥0.70；3次有效观察，搜索时相邻有效观察可间隔≤1秒|提供正式候选；本节点没有“高位一律不准confirmed”的高度禁令|
|高位精线索目录|正式候选通过任务准入后，还需多次独立采样；目录默认3次、时间跨度≥0.20秒、类别投票≥0.80、类别置信度≥0.70、质量≥0.50、位置不确定度≤0.45m|提高导航证据等级，不能充当低位新鲜释放证据|
|低位复核|到达重访位置后新产生的confirmed，正式任务准入、连续证据≥3；高度在低位巡航±0.20m，空间关联默认0.60m|消解该位置类别，进入接近/对准；释放仍走独立许可|

现场2m配置的记忆高度窗口现为1.8–2.2m；2.2m是观测容差，飞行指令上限仍是现场指定2m。仓库原八组默认高位2.6m，配合现场site YAML覆盖为2m；勿混用这两个口径。`candidate_min_streak=1`只放宽高位任务目录对已confirmed候选的当前连续计数检查，不会把单个bbox变成confirmed。

低位访问順序按观测障碍网格的路径代价比较访问排列，飞行仍由三维规划器实现；不是忽略障碍的直线三点最短路。低位复核默认5秒，约1秒仍无结果可尝试约0.5m换视角，受原有预算约束。

## 粗线索的替代、冲突与去重

`NavigationMemory`以位置和证据等级管理，最多保留每类两个位置：低空已复核 > 正式精线索 > bbox粗线索。一般同位关联半径0.60m。

- 同类、同位：新且不弱的证据更新旧位置；精线索可以替换粗线索，粗框不能覆盖已有精线索；重复图像时间戳不增加支持数。
- 同类、不同位置：保留有限竞争假设；同等级两个位置会暂停该类提前中断资格，不按“出现次数多”直接宣告真实位置。
- 同位、不同类别：证据等级更高者抑制弱标签；同等级冲突保持待复核。
- 低空明确某位置的真实类别后，仅清理该位置的其他类别假设，并阻止旧高空粗框重新灌回。不会因此删除远处同一类别的真实靶。
- 某位置复核失败退役后，反复的弱bbox不能复活该位置；新的正式精修证据仍可重新支持它。

例如A处误报bridge、实际为panzer，B处是真bridge：先确认B处bridge不会自动证明A处是什么，更不会删掉A处panzer。要等低空复核A，才能清掉A处错误bridge。反之，在A确认panzer，也不应删除B的bridge。

## 对整场的帮助与仍有的影响

粗线索的价值在于高位缺圆环时仍保存地点，低位直接去这些地点重新看，可能省掉遍历。但误分类/同位异类必须保留低空消歧，否则会更快飞往错误靶位；confirmed也不等于允许释放。

整机`HighViewFull`保留有界冲突位置复核与补搜；八组中的`memory_only`/`high_view`属于“完整一圈”专项，明确不提前中断，结束时冻结无冲突目标清单，若清单为空会失败。即使放宽高度后有三类竞争假设，也不能推导这两组会自动重访全部冲突位置。`high_priority`复用提前中断策略，`full_mission`最接近完整研究整机。

因此本轮优先修正建图初始化与正式视觉链READY，保留当前证据分级；下一步地面确认地图/视觉链持续运行，再验证低空按位置消歧。尚不能从这两轮宣布整场节时、三目标找齐或所有停滞根治。
