# 实机单帧位姿跳变与任务终止检查（2026-10-01）

## 已修改
第五组两帧飞控融合输出间隔40ms，三维变化0.40236m，其中Z变化0.39384m，旧门槛3×dt+0.25=0.370m。LIO同期平滑。该差分不能代表物理飞行速度，取消 HighViewProbe.update_pose 内跳变即抛异常的冗余判定，完整高位及板端派生运行时共同生效。采用飞控当前有限、同坐标系、时间有序的估计，不做冻结、平滑伪造位姿，也不叠加新的恢复状态机。

保留非有限值、错误frame、时间回退检查，以及观测使用时的pose_max_age。跳变不再自动终止任务不代表定位故障已根治；大幅定位偏移仍可能影响地图、航点与投影，需要继续检查飞控融合与外部定位输入。没有改变投递允许条件、定位来源或控制设定点。

同时修正 probe.failure 在已有ABORT后被下一次tick的decision_pending覆盖：优先保留活动ABORT的原始reason。

## 其他终止机制
已检查任务核心、运行时、ROS manager、高位运行时及板端专项脚本。详细静态清单见 ABORT_ENTRY_INVENTORY.md，共91处终止/异常转发调用点；这是调用点数，不是91种独立故障，也不代表PX4/C++全链的穷尽审计。

| 类别 | 条件/行为 | 本轮处理 |
|---|---|---|
| 单帧位姿差分 | 原3m/s×dt+0.25m即异常→ABORT | 删除 |
| 位姿合法性 | frame错误、NaN/Inf、时间倒退→回调异常 | 保留；不同坐标系不能混用 |
| 相机标定变化 | CameraInfo宽高/frame/K/D逐项完全相等比较；运行时变化→ABORT | 保留；确有浮点微扰误触发风险，但没有本轮触发证据。后续改容差需依据标定精度，不能吞掉真实标定切换 |
| 地图输入 | frame/点数上限250000、XYZ字段类型/下降余量异常→回调异常 | 保留；过大地图与畸形单帧可考虑拒收并使用有新鲜度限制的旧图，当前未实现 |
| 通用回调异常 | candidates/result/timer/board_pose等异常统一终止 | 保留未知程序异常处理；本轮从来源消除错误的跳变异常 |
| 时钟/执行器/事务不一致 | 运行时时间回退、执行器改变、路由绑定或调度状态不一致 | 保留；涉及命令归属与重复执行风险 |
| 持续无进展/运动失败 | 专项整圈持续无进展令事务到期，整圈失败→ABORT | 保留；不是一帧抖动。需要区分绕行期间直线距离不减与真正停滞 |
| 高位/局部复核终止 | 未验证爬升、无下降路线、无可用补搜路线、局部预算耗尽、专项记忆不完整 | 保留明确失败；不伪造专项完成 |
| 返航/降落失败或超时 | return_home_failed、landing_failed、safety_motion_timed_out | 保留 |
| 投递事务不确定 | 目标动作到期隔离槽位并返航，投后恢复到期返航 | 非直接ABORT，不可与视觉低分混算；保留 |
| 实验段完成 | 单重访probe用ABORT/hold结束实验段 | 接口语义不是碰撞或飞控失效；未改 |

低置信度、过期候选和圆环低分通常是拒绝观测/许可，不是直接ABORT；应追踪后续预算或运动失败，不能把所有拒绝原因当终止机制。初始化配置校验失败不属于飞行中ABORT。
