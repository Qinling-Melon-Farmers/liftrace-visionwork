# 16:15:35 起飞后异常左飞排查（2026-10-02）

主要原因已定位：MID360 转了90°安装，但现有 LIO→机体外部定位链没有安装旋转补偿。

## 排除任务航点向左下发

起飞航点生成值：x=0.000522894m，y=−0.011730742m，z=1.142358899m（local Z）。
OFFBOARD窗口内 `/navigation/setpoint_mission` 与 `/mavros/setpoint_position/local` 的 XY 始终为前述起飞XY，
没有横向航点变化。Z约0.188~0.429m，是控制器距离限制后的渐进起飞设定点，不是1.4m最终目标已到达。

发送到MAVROS的设定点约20Hz，最大消息间隔约0.062s；FC位姿约30Hz，最大间隔约0.044s。
LIO外部位姿约10Hz，OFFBOARD窗口最大间隔约0.180s、消息年龄最大约0.158s。
未见起飞异常前的长时间定位断流；定位时间戳拒绝/closed-topic错误主要在启动或接管落地后的收尾。
因此当前证据不支持“工作台切错组/任务发左航点/雷达网口再次断线”解释。

按接近同一header.stamp配对（采样偏差约20ms以内），FC与LIO位置差：
16:18:10约0.002m，16:18:16约0.166m，16:18:18约0.389m，16:18:19约0.799m。
这说明两路估计在运动中分离；其本身不区分实际位移、滤波延迟和估计误差，不能单凭该差值宣布LIO丢定位。
ROS中x增大/y减小也不能直接标为物理左/右：本轮恰有机体轴未对齐问题。

## 关键证据：机体轴约90°错位

对起飞初段66组姿态样本，以起飞前姿态为基准，计算各自机体系旋转增量，拟合绕Z轴的相对轴旋转：

| 指标 | 结果 |
|---|---|
| 轴向拟合角 | 92.62° |
| 配对最优额外时间偏移 | 0.01s（搜索−0.15~+0.15s） |
| 假定两套机体系同轴时倾角RMS | 6.38° |
| 补轴旋转后倾角RMS | 0.37° |
| FC俯仰增量与LIO横滚增量相关系数 | 0.9993 |
| FC横滚增量与LIO俯仰增量相关系数 | −0.9951 |

用户确认“雷达转了90°安装”，与上述动态串轴一致。92.62°是本轮运动数据拟合值，
不能直接作为标定参数写上板；安装方向的正负号及飞控箭头仍须按实物轴与地面运动核实。

代码与实际板端脚本一致：`uav_mission/scripts/lio_external_pose.py` 的 `body_position()`
仅用 IMU→机体平移修正位置，输出四元数仍为原LIO四元数；没有 IMU→机体安装旋转。
`localization.launch` 与 known_rig 也仅描述 body_to_imu_xyz，固定TF的这段旋转为单位四元数。
启动检查只比较位置和yaw，不比较横滚俯仰或动态轴响应，所以静置yaw收敛后仍可能通过READY。

事后只读读取飞控：EKF2_EV_CTRL=15，EKF2_HGT_REF=3，EKF2_EV_DELAY=0，
EV_POS_X/Y/Z=0，SENS_BOARD_ROT=0。它们是事后当前值，bag没有飞行时参数快照。
PX4说明EV控制位包括位置、高度、速度、yaw，外部姿态的机体系必须与实际安装对应；
只把静置yaw“等到接近零”不能验证轴向正确。
参考 [PX4外部定位坐标系要求](https://docs.px4.io/main/en/ros/external_position_estimation)
与 [EKF外部定位融合说明](https://docs.px4.io/main/en/advanced_config/tuning_the_ecl_ekf)。

## 修正要求与下一次地面验证

1. 先核实雷达X/Y轴、飞控箭头相对真实机头方向，登记安装旋转；确认雷达固定可靠。
2. 在外部定位适配层参数化完整 IMU→机体旋转和平移，不改FAST-LIO内部雷达→IMU出厂外参来代替机体安装旋转。
   机体姿态应为 `R_world_body = R_world_imu * R_imu_body`，机体位置同时按正确安装坐标补偿。
3. 同时处理起飞固定任务frame、位置坐标与 camera/IMU TF。任务配置假定+X朝机头前方；
   只改姿态yaw、只旋转位置或只改map静态TF，都可能留下另一处轴向不一致。
   若继续以起飞机头为任务+X，需固定相应世界旋转，再一致地转换位置和姿态，不能仅加一个yaw常数。
4. 地面未解锁、停桨条件下，人工小幅前倾/左右倾斜及前后/左右平移，观察FC与修正后LIO在同一frame中的轴响应；
   前倾应对应两路相同的pitch变化，侧倾应对应相同roll，位置前进/左移与任务+X/+Y一致。
   现有静置位置/yaw门限继续保留，并补足轴向验证；不得把放宽门限当修复。
5. 修正后先preview确认轴向/TF/静止参考/消息时序，通过后再由现场安排新的飞行。
   本轮没有执行或自动安排重飞，没有擅自改导航组源码/部署。
