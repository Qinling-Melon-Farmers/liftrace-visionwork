# 导航组轻量搜索策略仿真上游

更新时间：2026-09-04

## 1. 仓库与定位

- 上游仓库：<https://github.com/sakelier/liftrace-sim.git>
- 上游 `main` 核对 revision：`18f6ee8219120f1c00279b7fe41d9dda6fbc1377`
- 本机修正分支：`feat/ks2a543-vision-baseline@6b070f5`（上游 push 因权限 403 未完成）
- 定位：面向比赛任务级搜索策略的纯 Python 轻量仿真，不是 ROS/catkin 工作区，也不替代
  PX4、FAST-LIO、Fast-Planner、Gazebo 或整机 SITL。
- 数据流向：从视觉组 `uav_vision_eval` 接收实测性能表，向导航组
  `liftrace-controlwork/uav_mission` 提供搜索参数与任务策略候选。

## 2. 当前能力

当前上游已覆盖 M0～M2-D：牛耕航迹与名义时间、下视视场和驻留时间、随机目标与
Monte Carlo、视觉 V-SIM-04 查表、障碍膨胀/A*、视线遮挡、搜索中断/复核/投递/恢复、
三件载荷与 600 秒规则计分，以及多种有限载荷投递策略比较。仓库已导入
`vsim04_20260902_v2` 的 B100/C25/D16 数据，但它们属于 D435i 历史相机口径；当前运行代码
实际只消费 B 的 `condition_success_rates.csv`，C/D 尚未接入策略模型。

适合用它快速筛选：搜索高度、速度、航带间距/方向、是否中断、恢复位置、载荷预留和
投递优先级。筛选出的少量候选再进入 Gazebo/SITL，可减少整机仿真的组合数和墙钟时间。

## 3. 结论边界

当前模型仍含显式 `ASSUMED` 输入，包括目标分布、转弯耗时、遮挡阈值、复核/投递成功率、
服务时间、任务级飞行模型和未来 Cue 先验；避障得分、穿门和自主降落也未完整建模。因此：

- Monte Carlo/Pareto 结果只能用于候选策略排序，不能直接写成比赛得分预测或 Gate PASS；
- KS2A543 新 B100 到位前，旧 D435i 精确查表必须关闭；所有 Cue 概率均只能标为回退假设；
- 所有进入整机联调的策略必须记录 `liftrace-sim` revision、配置、seed、视觉数据 provenance
  和未测条件策略；
- 最终仍以正式随机场 ROS/Gazebo/SITL 的目标事务、三投、返航、走廊、LAND、碰撞、越界、
  高度和墙钟 Gate 为准。

## 4. 与视觉主仓的协作约定

视觉主仓继续交付按类别/高度/速度/偏差/运动条件组织的实测表及 provenance，不在视觉节点
中复制搜索策略。导航组在 `liftrace-sim` 中完成大规模策略筛选，在 `liftrace-controlwork`
中实现唯一正式任务策略；视觉主仓只保留接口、场景、评测和整机联调所需的最小接线。
