# 2026 实机相机与投递机构安装外参基线（2026-09-05）

## 1. 本次冻结结论

- 机械组建议以雷达 IMU 为相机安装位置的主基准，并确认相机可按其正下方处理。
- 本次任务明确采用：相机光心位于雷达 IMU 基准点正下方 `0.20 m`。
- 飞控盒基准到相机光心为正下方 `0.16 m`，作为当前软件 `body` 帧接线的工程值和机械
  交叉核对值；该口头数据未进一步区分盒体表面与内部 IMU 原点。
- 群聊中的“距雷达 IMU 约 21 cm”保留为近似口头记录，不与正式 `0.20 m` 值取平均。
- 2025 的 `base_link → camera_link: z=-0.15 m` 只保留为历史 profile，不再作为
  2026 飞机的实机相机外参。
- 投递机构安装关系暂沿用 2025 飞机，不修改旧对准补偿、舵机编号、PWM 或释放逻辑；
  这表示“未发生今年的机构增量”，不表示已经重新测量或完成实机投递验收。

## 2. 测量基准与坐标约定

平移测量统一使用两个物理基准点：

1. 相机基准为镜头的光学中心，不取外壳边缘、支架孔或镜片表面；无法直接接触光心时，
   由镜头轴线和传感器平面位置估计，并记录估计误差。
2. 主参考为 MID360 雷达 IMU 的坐标原点/数据手册标定基准。飞控侧当前只有“飞控盒”
   口径，最终精测时应换算到飞控 IMU 原点，不能把盒体表面或安装孔默认当作 IMU 原点。

当前机械组确认“正下方”，所以暂取横向偏移 `x=0, y=0`。按项目机体系约定
`+x` 向前、`+y` 向左、`+z` 向上，物理测量为：

```yaml
mid360_imu_to_camera_center_xyz_m: [0.0, 0.0, -0.20]
flight_controller_box_reference_to_camera_center_xyz_m: [0.0, 0.0, -0.16]
```

若后续量出非零横向偏移，必须更新 profile，不能继续用“正下方”近似掩盖偏差。

## 3. 当前软件采用的 TF

现有 FAST-LIO 配置从 `/mavros/imu/data` 取得 IMU，并发布 `camera_init → body`；当前
TF 树没有一个已验证、连通的雷达 IMU frame。因此板端视觉入口先发布以下运行变换：

```text
body → downward_camera_optical_frame
translation: [0.0, 0.0, -0.16] m
quaternion xyzw: [-0.70710678, 0.70710678, 0.0, 0.0]
```

其中平移是本次机械数据在现有 `body` 口径下的工程接线值；旋转不是本次新测量值，而是
沿用现有单下视相机的光学帧约定，使相机光轴指向机体下方。
`board_camera_vision.launch` 默认发布该静态 TF；若整机
顶层 launch 已发布同一父子帧，必须传 `publish_camera_extrinsic:=false`，避免双发布者。

雷达基准 `-0.20 m` 不应直接填给当前 `body`。后续若建立并验证雷达 IMU frame，应按
完整链路发布雷达 IMU、飞控 IMU 与相机之间的变换，再决定由哪个顶层节点唯一发布。

## 4. 与仿真和导航工程的关系

当前整机仿真模型中的 MID360 与 KS2A543 相机采用旧机架数值，frame 原点也未证明等于
上述两个实机测量基准。实机 profile 与仿真 SDF 必须分开保留，不能为了数值一致直接把
仿真 `body → camera` 改成 `-0.20 m`。

导航组在最终整机 SITL 前需要完成一次模型坐标核对：明确 `body`、MID360 IMU、雷达
外壳原点和相机光心各自位置，再让仿真模型尽量复现实机几何。此项只更新已有 TF/SDF，
不需要新增话题、消息或兼容层。

## 5. 后续验收（本次未启动实机或仿真）

1. 静止上电后确认 TF 树只有一个相机外参发布者，并检查
   `camera_init → body → downward_camera_optical_frame` 连通、无跳变。
2. 用水平地面和一个已知位置目标核对：图像中心附近目标应投影到相机正下方，前后左右
   移动方向不得镜像；用此步骤确认下视旋转，而不是重新拟合内参。
3. 记录安装后实际横向偏移和俯仰/横滚误差；若超过任务允许误差，再更新平移/旋转。
4. 与导航/LIO 并发运行后复测有效地图点、同步 pose 和资源稳定性。
5. 投递机构只在获得明确的实机安全授权后核对 2025 补偿是否仍适用；本次不执行解锁、
   起飞、舵机或 PWM 动作。
