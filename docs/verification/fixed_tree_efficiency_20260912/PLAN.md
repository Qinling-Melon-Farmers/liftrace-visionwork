两组均使用当前同一任务/视觉/规划/控制代码、模型、机架、高度、速度、0.70m runtime、平地观测参考和资源设置，只改变local_motion_enabled。与前轮保持各seed等待上限一致；不在开/关之间修改算法或阈值。局部入口仍为每名义点最多1次、每场4次、每次12s，默认部署开关继续关闭。
