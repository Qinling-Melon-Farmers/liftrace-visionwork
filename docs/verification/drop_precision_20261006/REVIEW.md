# 投递精度优化范围与主审标准（2026-10-06）

本轮来自用户对H形态检测实飞成功后的迁移建议，采用既有高位研究分支；不另开长期分支，不连接或部署机载电脑，不改释放事务/槽位防重放/类别复核的权威关系。完成后仿真与历史精度对比，再决定推广范围。

## 采纳及暂缓

- 优先采纳：同一图像的完整姿态投影、源图像时间戳排重。质量排序后去重只保留为默认关闭的研究选项。原H的地面投影已有去畸变和完整TF基础，投递使用当前图像靶心而非记忆均值。
- 结构中心：以既有ROI/分割为基础；红十字仍需红色与形态证据。实拍与负例未支持的内圈/径向线分支不默认启用。环评分0.75/0.80沿用，不能用新评分刻度悄悄放宽。
- 用户明确12cm是槽位安装外参。现场槽序后/右/左与现有[-0.12,0]/[0,-0.12]/[0,0.12]一致；物理投放口向量与机体目标修正量必须区分。新路径不能一处补偿机体位置、一处继续要求靶心回像素主点。仿真现有槽位零偏移保持显式零值。
- 不把H下降锁定策略原样复制为投递永久锁靶心；不重复使用旧图像制造新鲜证据，不改变许可和执行事实的防重放机制。
- 不顺带修改FC reset、LIO时效、飞行速度/航路或AUTO.LAND/POSCTL策略，避免精度对照混入无关因素。

## 验证与通过条件

1. 生产方法定向测试：曝光时刻完整姿态/相机位置、畸变、当前姿态变化、无效TF、陈旧/未来/乱序图像、重复候选、不同槽位与航向。静态目标在已知姿态变换后应回到同一地面坐标。
2. 图像同帧旧新比较：检出连续性、候选排序、中心变化、耗时及结构负例。没有人工靶心真值的实拍只报告差异和稳定性，不标成真实精度；椭圆几何中心不必等于透视投影后的圆心，需区分。
3. 两轮固定场景新链仿真，以既有seed31/38同场景历史结果对照；统计正确类别/实际靶位、释放时机体真值与靶心误差、最新观测地面中心误差、对准耗时、拒绝/重试以及整场结果。真值只用于评测。
4. 不能仅凭误差更小推广：必须同时没有错误目标释放、时序门槛失效或完赛明显退化。仅两轮不能证明实机普遍精度提升，机械释放后的落点和箱体最外边缘仍需实飞标定。

光学依据：[OpenCV相机模型/去畸变](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)、[轮廓与形状工具](https://docs.opencv.org/4.13.0/d3/dc0/group__imgproc__shape.html)。这两份文档支持几何方法，不是本项目误差改善的实验结果。

分工：Beauvoir负责投影和新帧稳定链；Poincare负责轻量几何候选；Bernoulli负责历史与仿真评测；主代理负责接口、控制与释放一致性、修改审查、最终验收和分支推广。
