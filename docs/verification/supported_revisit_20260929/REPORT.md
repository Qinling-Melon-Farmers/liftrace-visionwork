# 冲突线索保留重访能力（2026-09-29）

## 结果与范围

修复“一个弱竞争位置使整个类别退出普通重访候选”。分离普通导航重访与高位提前中断：`NavigationMemory.update/interrupt_hints`继续按原冲突规则排除歧义；新增`revisit_hints`仅向低位导航提供每类一个得到支持的优先位置。没有降低类别、圆环、空间、图像时效或释放许可门槛，没有启动仿真或实机。

## 行为

- 无冲突线索沿用原行为，包括单个有效bbox可保存为导航假设。
- 有冲突时，普通重访只选已有独立双帧支持的粗位置或正式精线索。仍保留同类其他位置与同地其他类别供局部复核，不能仅因导航有三类就提前结束高位搜索。
- 同证据等级按独立有效观测数量排序，再按新鲜度破同分，持续得到支持的位置优先于新出现的弱竞争位置。采用原0.10秒最小采样间隔及位置一致性，重复图像/高频重发不计数；单位置计数上限255、每类最多两个位置，内存有界。计数只用于重访排序，不改变Hint.evidence_count、正式confirmed或释放门槛。
- 仍由原感知地图代价比较访问顺序，三维规划器执行航段。优先位置无结果时退役该位置，保留其它类和同类备选；普通重访仍有原两次尝试限制。记录已尝试的冲突位置，避免失败后又从冲突队列重复绕回。
- 到达低位后仍要求新鲜正式视觉确认。粗框本身不会发APPROACH，不会生成释放证据，地图/高度/边界检查不变。

### 确认后如何清理

低位确认B处panzer后：同在B的错误bridge/red_cross标签删除；A处可疑panzer粗线索被更强的低位证据压下，退出普通重访和待冲突复核集合，底层诊断记录可保留。C处真正bridge、D处真正red_cross继续保留。旧高位错误标签不能重新灌回B。

反之，先在C确认bridge不能证明A或B是什么，不会删掉远处panzer。此清理仅由新鲜正式低位确认触发，高位连续粗框不执行清理。此次没有修改0.60m空间关联规则，极近相邻真实靶仍需用同帧独立实例进一步验证。

### 板端专项

`FullCircleRuntime`按可重访集合冻结manifest，允许得到持续支持、但尚有竞争假设的类进入整圈后重访。全部普通重访处理后，在原75秒冲突复核预算/位置上限内处理剩余清单的备选，结束或按原规则报未完成；不新增整场牛耕补搜。`PriorityRevisitRuntime`也只复核冻结清单剩余类别，避免访问未纳入试验的类。`memory_only`仍不投递。

状态中`navigation_conflicted_classes`用于明确“可导航不等于已消歧”；`revisit_support_count`说明排序支持数，不能将其读作正式确认计数。manifest/memory_count仍是导航假设数量，不是confirmed或已投数量。

## 圆环0.80与后续阈值试验

现场参数是标准靶类别0.60/几何0.70、红十字类别0.80/几何0.70、独立circle/landing_pad候选几何0.80。精修关联圆环入口是0.70。**drop_circle对准消费独立circle confirmed，因此0.80可以间接阻止对准；它不是所有YOLO或所有投递的统一门槛。**

22:11 low_multi在drop_circle期间记录355条去重后的有效投影圆环：0.80可保留348条，0.75保留354条，0.70保留355条。7条低于0.80，其中4条在第二次释放之后；另两条投影消息延迟约0.84秒，即使降低圆环分数也仍需通过新鲜度检查。173.26秒已有有效对准证据，180.47秒第二次释放收到raw_actuator_ack。故不能归纳为“本轮因圆环低于0.8完全没投”。证据拒绝还含偏移超限72次、stale_observation31次、geometry_stale9次；这些是消息次数，不能相加当等待时长或全部归因为评分。

可把**仅circle评分0.80→0.75**列为实拍A/B，不要直接改共用aux阈值连带放宽H；保留语义目标绑定、地图同一目标、中心稳定、新鲜度、槽位/高度与释放许可。先评估低分圆环的实际中心误差，不单看多通过了几帧。本轮不修改这些阈值。

同一145条粗观测扫阈值：0.60/0.65最终三类仍冲突；0.70/0.75/0.80只剩panzer多位置冲突；各档新重访集合都能保留三类。0.70滤掉两条边缘bridge与装甲车上的错误red_cross，但不能消除0.8以上的边缘panzer。因此可优先试0.70，不能声称已经确定最优值；0.60默认暂保留。

需补充1m/s实拍：同一布设、五类、良好/较暗光照、顺/横视场方向、边缘截断与相邻靶。比较正确位置首次形成时间、每靶独立帧数、错类/重复位置率、普通重访与提前中断是否不同、低位确认耗时及靶心误差。当前0.5m/s试飞及固定轨迹离线样本不能代替1m/s实飞识别率。
