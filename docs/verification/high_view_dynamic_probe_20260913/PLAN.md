# 受限高位—低位复访动态实验

本阶段只验证一个高位线索能否经原规划/控制链带来低位新鲜重捕。**不投递、不声称完成整场任务、不使用场景靶坐标安排目标。** 原默认任务管理器和37项Gate不改；独立入口选用研究管理器和分段Gate。

## 执行顺序

1. 原SITL起飞链至低位巡航，原start gate确认设备、地图和任务就绪。
2. 上升至FC AGL2.6m，首先完成home同柱上升的原规划到达确认。
3. 场地四个高位观察目标：(-3.5,1.0)、(3.5,1.0)、(3.5,5.5)、(-3.5,5.5)，移动仍由实时点云和原规划器处理。预算45模拟秒含上升，不强求走完整圈。
4. 从已有视觉候选形成有界高位线索，按可用类别权重选择一个；不向原投递候选队列注入陈旧目标。
5. 回到已确认的上升柱顶，再经原规划器同柱下降至FC AGL1.4m。仅限本次静态场景，不把它推广成任意空间的自由通道证明。
6. 下降到达后恢复低位指令/地图上界，向线索位置发出无投递语义的SEARCH复访事务。到达后最多等待15模拟秒，要求低位新鲜候选、正确类别、明确关联、连续帧及原时效条件；歧义候选不计成功。
7. 成功或失败均结束该段，使用原ABORT/保持接口退休事务，由分段评估器结束仿真。此处ABORT表示测试段收尾，不伪装成三槽任务COMPLETE。

## 保护与记录

- 研究管理器是原ROS任务壳的专用子类，原MissionCore/MissionRuntime负责序号、期限、过期结果及执行器契约；不存在第二个规划目标发布者。
- 上升失败、其它非预算运动失败、线索过期、位姿跳变、标定变化或低位重捕超时均保留失败，不连续无分析重跑。
- 粗线索误差半径候选0.20m，关联范围0.60m；没有放宽原释放证据，也不把它们当成碰撞净空。
- 规划速度上限0.8m/s，原碰撞/膨胀继续生效。返回/下降/复访各有原30s运动事务上限。
- 分段Gate读取仿真真值只用于独立核验边界、碰撞与物理靶关联，绝不向研究管理器提供真值。高/低位置误差分别报告，不把关联成功当作0.25m统计误差门槛通过。
- 记录原key_recorder的航迹/高度/指令/事件、high_view_probe_events和Gate。默认不录bag或视频。

首轮使用固定树seed32，之后依据首个失败阶段或重捕结果决定下一步，不直接扩大三投矩阵。该阶段不是正式P0全部通过或机载放飞验收。
