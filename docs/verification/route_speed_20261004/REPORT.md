# 三种高位航线与矩形旧策略：八轮结果（2026-10-05）

**八轮及全部汇报视频已完成。按用户确认的“落地静止后由飞手切停”口径，7轮完成飞行降落、1轮空中碰树；原软件Gate仍为3 PASS、5 FAIL。** 四个软件FAIL发生在已落地静止之后，不算空中飞行失败。另有seed38新矩形把碉堡当panzer完成模拟释放，不能算三个预期高权重目标正确投递。公共流程修复和本次记忆修复已另做离线回归；本批不能作为这些修复的新闭环验收，也不据此将实验路线提升为整机默认。

## 版本与场景

八轮全部冻结`feat/high-view-route-speed-20261004`的`2b0678b9`。没有在运行中替换源码；最后一轮停止并检查ROS/Gazebo/PX4零残留后，研究工作树才快进到公共复核修复。`d523c53c`及其各分支适配的离线回归与本八轮分开，详见[复核修复](../motion_constraints_20261005/REVIEW_FOLLOWUP.md)。本轮不再自动新增动态仿真。

同seed四种方案采用相同靶位、净空内环10×10m、5cm外墙、原始均匀四树、障碍柱开启、水平0.25/上0.20/下0.10m、H80cm。搜索区域为[-0.5,7.95]×[-5,5]，84.5㎡；剩余为走廊/分隔墙，整场仍是100㎡。固定树替换后，原历史靶位若重叠则按seed重新合法生成，所以只对本批同场景比较，不声称与多日前同seed场景完全一致。

相机光心AGL目标2.60m，对应FC参考点AGL2.76m、local ground=-0.22、相机下偏0.16m。按实测FC2m时3.6×1.8m视场线性外推，水平地面幅宽约5.087×2.543m。完整理想航线覆盖84.331/84.5㎡≈99.8%；无树遮挡、无偏航/倾斜、无提前中断假设。它不是实际识别覆盖率。三种航线采用相同固定朝向，几何长度矩形22.8m、双线19.0m、三线26.6m。

## 失败诊断

1. **seed31/38新矩形**：无障碍接触，已在H附近触地，随后probe位姿跳变触发ABORT。两轮真值落点偏差约10.06cm、2.35cm；原始Gate仍FAIL。seed31对应ULog显示落地后高度参考重置，不能套用实飞“EV高度超时重融”作为所有SITL的原因。LIO在触地前误差较小，FC高度错误明显放大。
2. **seed31双线**：H检测与下降已执行，地面状态有记录，但任务LAND未收终态、到600秒期限失败。需要检查终态/控制交接；不应修改Gate掩盖。
3. **seed38双线**：高位把碉堡附近重复识别为panzer并提前中断；低位正确改判pillbox，转而完成红十字、桥梁，然后进入LOW_COVERAGE长补搜才找到panzer。进一步结合支撑接触及Gazebo真值已确认落地静止，约7.328s后才ABORT。前序仅按飞控仍报下降状态而判“不能确认落地”的结论撤回；按用户口径计飞行降落完成，原软件Gate仍FAIL。末段位姿异常的具体估计器原因需独立ULog核对。
4. **seed38三线**：高位同样受有重复支持的错误panzer假设影响，低位否定后完成两投。ROS108.890s、LOW_COVERAGE交接后约2.18s，55cm工程包络与`juniper_Tree_1`接触，深度约0.127mm。记录力为0不抵消几何接触；原始Gate碰撞失败。此时不在走廊。需要进一步对照真值、点云占据和执行轨迹检查净空，不能仅凭直线权重推定原因，也不自动减小包络。

seed38新矩形的panzer复核坐标(4.543,-3.464)距pillbox仅0.191m、距真实panzer2.596m，随后按panzer执行模拟释放。这是类别/身份判断问题，不能把2.596m解释成普通投影误差。其余表内同类低空中心多为约0.07–0.22m；误差并不等于实际投递散布。

补充定位到具体软件问题：低空YOLO在78.784s已输出pillbox（0.9524），视觉记忆仍用历史panzer票数维持旧标签，并把异类观测用于刷新旧类确认计数。不是低空一直识错。ROS88.000s用1号槽mock释放时机体距碉堡约3.6cm。本批23次模拟释放中仅此一处标签/真实靶位不符；没有包裹弹道，不能当作真实落点计分。pillbox权重1.5、panzer2.5，同环带基础分下相差1倍基础分。

[记忆修复与4202帧回放](../memory_semantics_20261005/REPORT.md)：异类新证据立即使旧类别当前确认失效，连续挑战票数替代无限历史票数；重复ID合并不复活旧标签。70–90s错误可用panzer由72帧变为0，新版76.447s确认pillbox，早于原79.359s复核决策。新增真实CandidateRecord→任务复核回归，未新跑SITL。

“优先持续支持位置”的策略并不保证类别正确：碉堡上的误panzer也可能得到多帧支持。双线/三线seed38低位纠正成功，说明否定链路生效；但高位提前结束后仍付出了全场补搜代价。后续应定向研究类别竞争证据与高位覆盖终止条件，而非将所有错误都归因于排序没启用。
