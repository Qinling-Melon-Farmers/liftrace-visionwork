## 用户确认的物理杆臂

杆臂以 FC 为起点、实际出料口为终点，坐标系为机体 FLU：X 向前、Y 向左、Z 向上。单位均为米。

| 出料口 | FC → 出料口杆臂 r（FLU） |
|---|---|
| rear（后） | (-0.12, 0, 0) |
| right（右） | (0, -0.12, 0) |
| left（左） | (0, +0.12, 0) |

XY是本轮用户确认的物理测量；垂直杆臂尚未测量，当前二维表计算时Z按0处理，并非声称测得三维安装位置。历史代码中的 7 cm、10 cm 或已有 12 cm 参数表不代替本次物理确认，也不据此追加未确认的槽号或 PWM 映射。

## 投递：高位补偿、停稳冻结，再下降

令 q 为有效机体姿态，R(q) 将机体 FLU 向量旋转到控制使用的地图/任务坐标系；靶心、FC 与姿态必须在一致坐标和时间关系下使用。

目标关系为：

```text
FC_ref = 靶心 - R(q) r
actual_outlet = FC_current + R(q_current) r
```

用于水平补偿时取上述关系的 XY 分量：

```text
FC_ref_XY = 靶心_XY - [R(q) r]_XY
```

高度仍由当前阶段的高度目标管理，不能把地面靶心 Z 直接当作高位 FC 高度。R(q) 按完整姿态处理，不把机体杆臂当作固定地图轴加法。

执行顺序：

1. 在高位先计算所选实际出料口对应的 FC 补偿目标，水平移动到补偿位置。
2. 低速到位，并取得当前目标的有效视觉语义证据后，冻结本次事务的目标与补偿 FC XY 参考；在此之前不开始下降。
3. 按冻结的 FC XY 参考下降，到最终高度后同时核查实际出料口、冻结 FC 位置和停稳窗口。
4. 满足本表以及任务链既有释放许可后，才允许进入释放动作。冻结并不等于释放已获许可。

冻结后的误差定义为：

```text
outlet_xy_error = ||actual_outlet_XY - frozen_target_center_XY||
frozen_fc_xy_error = ||FC_current_XY - frozen_FC_ref_XY||
horizontal_speed = max(FC水平速度, 投口水平速度)
投口速度 = FC速度 + 角速度 × 当前旋转后的安装杆臂
z_error = |FC_current_Z - 当前阶段FC高度目标_Z|
```

| 最终释放前条件 | 门槛 |
|---|---|
| actual_outlet 到冻结靶心的 XY 误差 | ≤ 0.04 m |
| FC 到冻结补偿参考的 XY 误差 | ≤ 0.04 m |
| 水平速度 | ≤ 0.05 m/s |
| 高度误差 | ≤ 0.05 m |
| 垂向速度绝对值 | ≤ 0.10 m/s |
| 新鲜、不同时间戳的 odom 样本 | 至少 3 个 |
| 合格样本的时间跨度 | 至少 0.30 s |

这些条件共同构成最终停稳门槛，不能用“位置刚到一次”或重复消费同一个 odom 代替。窗口应由新 odom 形成；样本不满足条件时不能把先前计数凑成连续停稳结论。里程计与位姿的新鲜度上限为0.20s，样本间隔上限0.20s；完整姿态将child速度旋转到任务系，重复源时间戳不增加稳定计数。

冻结状态遵守以下口径：

- 无效图像本身不得清空或解除已经取得的 freeze，也不得触发重新捕获并覆盖冻结参考；冻结不替代其他既有证据/许可检查。
- 每次目标参考都按“靶心减旋转后的杆臂”求值，不在已有补偿目标上再次加减杆臂；重复回调和重复消息不得累加位移。
- 冻结参考固定用于本次下降事务；实际出料口仍用当前 FC 与当前姿态计算。因此姿态变化可能使 actual_outlet 误差重新超限，即使 FC 已在冻结点，也不能只看 FC 误差放行。
