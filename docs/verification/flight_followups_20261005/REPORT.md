## 重要接口变化

ReleasePermission / ReleaseResult 增加固定动作身份与执行事实。它们、许可仲裁器、代理、Bridge、任务核心和控制器需要成套部署并重新构建消息。旧 patrol_control/Servo.srv 仍为 bool 服务，不改变硬件组调用命令；工程链增加同属控制包的 ServoAction.srv（默认 /mission/servo_action），回传固定请求身份和执行事实，避免控制包反向依赖uav_mission形成构建环。bool失败本身不证明未执行。

控制与任务的软件回执只证明调用及返回事实，不能证明载荷实际脱落。真实机构约1秒延迟尚需板端对照设定点间隔和实际动作验收。
