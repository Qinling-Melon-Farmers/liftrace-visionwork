## 候选行为与验证边界

用户允许先补偿到位再下降。本轮候选用开关`drop_system/compensate_before_descent`：开启时冻结后先保持捕获高度，FC/投口双XY达到分类门槛（标准6cm、红十字4cm）后单向转入下降；关闭可恢复原同时补偿/下降用于对照。下降后误差反弹不会自动回升，也不能把曾经到位锁存成以后永久可投。

冻结不再要求持续获得新视觉ready，避免补偿让靶心离开像素主点后一直无法下降。最终释放仍检查当下双XY、高度与有效许可。没有新增速度门槛、累计停稳窗口、点云准入或新的恢复状态机。

仅凭瞬时XY通过不能证明已停稳，所以串行方案也不能承诺消除全部反弹；它先去掉两种动作同时启动的因素，供后续实飞比较。目标0.40m/.35～.45m窗口和6cm标准门槛分别是独立改动，不把旧轨迹平移当作新方案成功证据。
