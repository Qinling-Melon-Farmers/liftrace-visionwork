# 飞行工作台启动修复说明（2026-10-15）

本包是原工作台的局部修复版；仅调整四个生产文件，并附两项回归测试。

## 修复内容

- web/competition_geometry.js：恢复本机已保存地图后，增加“重新生成坐标命令（不连接飞机）”，可按当前运动优化、障碍柱、高位续扫及参数选项重新生成匹配命令。
- web/app.js：有效配置核对加入地图内容与草稿版本；确认弹窗返回后，再核对当前坐标、选项和飞行/实投确认，变化后要求重新确认。
- wb_geometry.py、wb_competition_geometry.py：以来源路径、草稿版本、坐标及适用开关生成稳定的配置文件标识，替代按分钟命名。同一请求跨分钟保持同一命令，同分钟修改生成不同路径；已有配置内容不符时仍拒绝覆盖。

## 预期操作流程

1. 选择正确的任务组和场地配置，核对地图航点、H 坐标及当前选项。
2. 刷新页面恢复草稿，或修改选项后，点击“重新生成坐标命令（不连接飞机）”；任务模块使用原有的生成坐标命令入口。
3. 核对新命令，再按原流程执行配置检查。仅勾选选项并不代表实际配置已经验证。
4. 由操作员完成必要的飞行/实投确认，再确认启动弹窗。弹窗期间修改坐标或选项时，应重新生成并确认。

解压到新的独立目录后使用原启动脚本。此包未替换正在运行的旧工作台；不要为验包启动第二套服务。既有 manifest.json 保留历史基线信息，本说明描述本次增量。
