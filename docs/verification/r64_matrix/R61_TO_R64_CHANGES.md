- 按最终测量统一FC下16cm相机、IMU下21cm相机、镜头落地6cm；实际机体50×50×37cm，模拟包络55×55×40cm。相机随完整机体姿态刚性运动，不增加云台。
- 修正CAD装配错位、可见支架/传感器安装及仿真投影外参；物理模型和视觉TF一致，保持校准1280×720图像与CameraInfo。
- 场地调整为9.6m内净，起飞H贴边居中，终点H外圈与墙留10cm；取消独立bigbox，四组树箱；目标扩展到整个搜索区域，保留树冠/目标间隔约束。R64矩阵后来揭示了忽略隔墙实体的布设漏洞，不能把R61实现写成当时已完全正确。

- 整理精简整机与部署/仿真包、历史/当前资产界限和UTF8路径打包。

## R62：仿真传感器和起飞链

- 仿真MID360输出PointCloud2，对应仿真LIO类型4；实机CustomMsg类型1不改。
- 修正Gazebo展开后的iris::base_link等引用；碰撞包络和雷达自身封闭壳体对光线透明但保持物理接触，机体/旋翼/环境遮挡不删。
- 主刚体参考改为FC，IMU测量归入主刚体，合并虚拟IMU质量/惯量，消除固定关节采样与地面抖动；spawn=0.225包括支撑高度和5mm起飞垫。恢复此前成功模型的ODE接触设置。
- 起飞XY在距离限幅后仍锁住起飞锚点；SITL悬停初值0.713由1.577kg模型质量和电机系数推导，实机不得照抄该质量标定。
- 场外增加简单墙/柱/箱体/顶面，为正装雷达提供室内特征；不模拟观众，不把真值送给LIO/任务。

- 首投/恢复阶段成功不当全场PASS；R62后续三投恢复碰靶FAIL保留。
