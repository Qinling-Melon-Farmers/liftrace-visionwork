## 三轮失败

**seed3：最终近地落地失败。** 三投/三恢复/两门/9点路线均完成，H对准后进入AUTO.LAND，450.251s触碰东侧Wall_11。AUTO.LAND航向目标跨度仅0.0256°，R63的约90°历史重置跳变未复现。近地时实际与估计位置明显分离：450.257s真实local位置约(4.521,8.213,0.181)，邻近MAVROS约(4.057,8.540,-0.444)。近地惯性/高度融合、接地动力学及落地检测贡献尚未完整隔离，不能宣称降落故障已经全部解决。[时序](seed_03_failure/timeline.json)、[姿态/位置](seed_03_failure/final_pose_comparison.json)、[航向证据](seed_03_failure/auto_land_yaw.json)。

**seed5：第三目标接近超时，故障返航落起飞H。** 红十字板伸入墙体，385.703s开始APPROACH，505.704s达120秒动作截止，规划日志多次new_trajectory_attempt_failed。随后以target_action_timed_out_uncertain返回(0,0)，539.344s解除武装。最终中心距起飞H约4.42cm，保守包络最大半径0.430m，属于起飞圈内回收成功，但仅投2槽，完整任务FAIL。这不是420秒提前返航，也没有穿走廊。“post_delivery_return_success_count=1”在该场景是普通RETURN_HOME成功计数，不能误说完成了投后路线第一点。[时序](seed_05_failure/timeline.json)。

**seed7：近隔墙红十字接近/捕获时碰墙。** 同样有靶板角点压墙。原目标y=7.1947，规划器改为安全侧y=7.0447并报告到达；之后设定值又向原靶位方向变化。363.127s在y≈7.1247处，55cm包络到达隔墙搜索侧y=7.4边界并接触Wall_13，尚未第三次释放。除布设漏洞外，还暴露“规划调整后的安全接近点→视觉捕获”交接应持续考虑机体净空，不能因视觉目标存在就退回不安全位置。[时序](seed_07_failure/timeline.json)、[规划记录](summary_stats.json)。

## 固定版本、参数与记录

先导飞行源1983b2f；矩阵/初始R64包405bda42仅增加文档和先导记录，已核对无飞行文件差异。PX4为99c4040加deployment/px4_patches补丁；本批中途无调参、无代码变更。树箱和门在这11轮固定，仅靶标位置/朝向随机；不能称为树箱/门全随机验收。

- 恢复：控制交接与桥阈值0.95local；桥稳定窗口0.5s/0.15m；固定恢复目标等待新任务。

- 走廊：1.5m总宽，两处0.80m开口，低空限制0.7m；常用航段local0.23/AGL0.45m。
