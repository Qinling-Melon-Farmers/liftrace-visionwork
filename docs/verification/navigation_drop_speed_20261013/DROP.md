# 2026-10-13 投递末段20秒兜底

> 后续正常路径已另行放宽，并将下降前确认与末段释放分离，见[NORMAL_RELEASE.md](NORMAL_RELEASE.md)。下文记录先前20秒兜底的作用边界。

## 本次行为

保留原靶心检测、类别确认、物理槽位补偿和串行补偿下降。正常达到本分支释放要求时立即调用，不等待20秒。同一次新ALIGN开始后计时20秒，重复命令/上下文心跳不重新计时。

20秒仅允许在以下已成立的流程中不再因最终精细水平误差反弹而继续等待：已冻结同一靶心、已完成该分支串行补偿并进入下降、当前高度仍在原释放区间、原释放许可/承诺仍然有效。动作身份、槽位、防重复、取消/截止、反馈新鲜度、控制权和原边界规则继续生效。不要求再累计低速停稳时间，不再次追低位残缺图像，不刷新冻结观测时间。

原许可中的漂移限制仍然生效；本改动不保证任意水平偏差都能投递。20秒也不是承诺必须在第20秒投出，尚未捕获、尚在高空或许可不成立时仍等待原流程或由任务期限结束。

## 配置入口

正式生成基底：`patrol_uav_ws-patrol_planner/src/uav_mission/config/competition/control_base.yaml`。
试飞生成基底：`patrol_uav_ws-patrol_planner/src/uav_mission/config/vcl06_horizontal_control.yaml`。

```yaml
drop_system:
  release_timeout:
    enabled: true       # 末段水平精度等待的兜底开关
    after_sec: 20.0     # 同一次ALIGN开始计时，不是下降后另等20秒
```

在生成的控制YAML中设为false即可保留本分支原有释放判断。首次动作、取消后新动作、投递结束均重新管理计时；检测到ROS时钟回退，该动作禁用超时兜底，普通精度到位路径不因此失效。
