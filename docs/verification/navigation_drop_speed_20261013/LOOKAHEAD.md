- 高位搜索/续扫、投后前往走廊入口首段巡航：1.0m。
- 接近目标、近边界、低空覆盖、普通返航、走廊入口下降、走廊门区/开阔段、近H导航、终端阶段：0.6m。
- 初始 `/px4_max_distance` 与 `/traj_server/traj_server/target_dist` 同为0.6m。首轨迹接纳距离保持本分支原值；规划速度/加速度也保持原值。

`following_speed_profile`和`corridor_speed_schedule`继续从现场YAML读取并校验，但正式/试飞生成器在输出时统一上述前视字段。旧现场YAML显式0.2/0.4等低档会转换为0.6；不回写现场源YAML，不迁移场地坐标、高度或门锚点。必须重新生成运行配置；旧run目录中的配置不会随源码自动更新。

门前/门后必要航点保护保持，未提高规划速度或加速度，也没有更改到点位置容差。两档前视不是轨迹不会回摆的保证，最新走廊倒退及非法起点恢复问题仍需另项修复。

## 实际作用边界

前视单位是米，不是米每秒。任务调度同时设置规划器轨迹前视和控制端通用位置指令限距，后者也可能影响普通位置模式的起飞、投递补偿和下降响应。独立H下降通道按原实现处理；本轮没有改其独立速度参数。不能把“未改对准/释放阈值”理解成末段动力学必然完全不变。

历史仿真及2025原工程不全仓改数值。运行库保留旧缺省，新两档策略由本次正式/试飞生成入口启用。低空覆盖新增可选配置字段仅在本次入口显式使用，旧运行入口缺省不变。
