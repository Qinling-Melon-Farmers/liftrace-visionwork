## 前视候选与收益边界

两包进入ALIGN前，0.2m近边界导航区间分别只有约5.14秒和3.82秒，净XY位移0.278m和0.342m。不能把随后整个投递停留也计作低前视耗时，不能把前视翻三倍直接换算成速度或节时翻三倍。

把正常导航分成1.0/0.6m值得单独动态验证，但它与“所有控制模式最低0.6m”不是同一改动。门口转弯、近边界制动、H近场、HOLD/ABORT、直接位置控制的对准下降都有各自作用；不能一并改掉后宣称仍只是巡航提速。

优先级建议：先查明持续高度跟踪偏高，避免30秒高度等待；再评估近边界调度覆盖范围；最后以保留门前后必要点的1.0/0.6导航候选进行专门实飞。当前规划上限1.2m/s与加速度1.0m/s²已开启，不应把它们和0.6m前视混为一项。

全场尾部已出现start_occ=1、kinodynamic搜索候选因碰撞拒绝；加大前视不能使占用起点变合法，也不能替代脱困恢复或门位净空确认。当前数据不支持判断是否发生实体碰撞，更不能推演H失败。
