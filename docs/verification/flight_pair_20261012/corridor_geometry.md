# 全场进入走廊的点云与门位几何核验（2026-10-12）

结论：W3→W4 的右绕已存在于规划输出，不能只归因于跟踪过冲。配置穿门线与已发布膨胀占据图的窄带有明显横向差异；实际FC曾进入该膨胀图的占据体素。**这些事实支持规划几何余量不足，不能据此认定实体碰撞或量出真实门框净空。**

本轮只读取现有reindexed bag及JSON；不启动ROS节点、回放或仿真，不改runtime、源码、配置或Git索引。控制/规划失效时序由时序分析负责，本报告聚焦几何。

## 已膨胀图中的通道偏差与末段余量

在263.789–271.763 s接收到的相关快照中，第一配置平面所在体素行Y=-0.05 m、飞行高度层Z=0.734926 m，左侧占据中心到X=7.85、右侧从X=8.05开始。按0.1 m体素外缘，二者间只有约**X∈[7.90,8.00]、宽0.10 m**的一列未发布为占据的体素带。

这里的0.10 m是**已膨胀图中FC点的表观通行带**，不是实体门洞宽度，也不是已证实自由空间；发布缺点不区分未知与自由，且只是局部高度层。

- 该带中线X≈7.95，比名义穿门线X=7.693641右移约**25.64 cm**。名义线在此层并未对准表观通行带，而规划峰值正向其附近偏转。
- 实际横穿配置平面X≈7.916，在上述单层体素外缘模型中距左侧仅约**1.6 cm**；这不是机体/桨叶距门框的物理净空。
- t≈266.190 s，FC=(7.8862,0.0983,0.7448)，落入接收于265.756 s的占据体素盒；该帧**接收年龄≈0.434 s**，源年龄未知。可判“FC点与所示膨胀占据区重合”，不可判实体撞门。
- t≈270–272 s，实际位置向W4的X折回并进入所示膨胀占据区，与时序分析的start_occ=1背景一致；因点云无源时间戳，不能宣称独立复现了内部同拍占据判断。
- W4=(7.693641,-0.707166,0.684926)本身在附近快照中的最近膨胀体素外缘距离仅约**0.007 m**，即约1 cm量级。此值受0.1 m格点、体素盒近似和接收时差影响，不应当作毫米级实测净空；它说明折回终点紧贴所示占据边缘。

**能判断：目标穿门线/折回终点与当前显示的规划占据几何缺少稳健余量，规划右绕不是凭空出现。不能判断：真实门中心究竟偏了25.64 cm，或是哪一种实体/虚拟源造成占据。**配置墙平面也不是从原始门框拟合出的测量平面；现有数据不支持确定真实门的X/Y安装误差。

## 雷达/地图能否代表机体净空

本bag提供的是融合地图经处理后发布的占据体素中心。当前导航源码SDFMap::publishMapInflate输出occupancy_buffer_inflate；发布时没有写入有效源stamp。源码生成器设定0.1 m分辨率、水平膨胀0.25 m，并可能执行禁越柱等处理；这是来源源码语义，不作为当前实机二进制版本或逐体素来源证明。

不能把0.55 m名义机身框与已膨胀云相交再判实体险撞，不能再减去机体半径当物理净空，也不能简单反膨胀还原真实门宽。最初图中的0.55 m框仅为名义示意，非本次实测尺寸；最终图已移除它。姿态包络、安装杆臂、点云漏扫/遮挡、定位误差与虚拟柱来源均未在本bag中形成可验证的实体净空闭包。

需要原始/未膨胀静态点云、有效源时间戳、同坐标实测门框及当前机体包络，才能进一步区分门位偏差与建图/膨胀/虚拟柱，并计算实体净空。本轮不扩大分析或修改配置。
