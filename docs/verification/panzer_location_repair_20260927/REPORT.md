# Seed38 高位提前中断与位置级复核修复

日期：2026-09-27。状态：282项回归、两工作区编译与离线参数检查通过，准备冻结代码实跑。

## 本轮目的

上一轮开启修正障碍柱、水平膨胀0.275m后，seed38完成三投和降落，但为red_cross、bridge、tent，并非三高权重。H附近panzer粗线索在两个独立图像获得支持后触发高位提前中断，真实panzer约在5.16m之外；低空未确认这处线索，最终被旧近墙复核逻辑误判为整类不可达。

本轮同时处理上游提前中断与下游降级，不只优化补搜。历史真panzer曾被识别并投递，但历史完成三高权重不等于整轮走廊降落也通过。

## 修改范围

- 高位单帧0.60粗框仍可形成导航线索。默认panzer只有已有精修视觉线索才可计入提前中断所需的三类；其余类别仍允许两个独立图像的粗支持。完整高位航线走完仍允许使用部分或粗线索回访，不强求提前中断。
- 完成低空观察仍无正式候选时，仅撤销该类别在该位置的线索。旧catalog重发或后续弱框不恢复它；新鲜精修证据可以恢复，同类其他位置仍可重访。
- 近墙局部复核耗尽本身不再禁用整类、不再自动去投低权重目标；正式APPROACH的规划/对准失败仍走原有降级处理。槽位、释放许可、投递证据不放宽。
- 障碍柱算法、0.275/0.20/0.10m膨胀、FOV、2.6m高位、既有速度和走廊配置保持本轮对照口径。
