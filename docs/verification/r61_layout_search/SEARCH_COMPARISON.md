# R61：记录场景的搜索策略几何预筛

2026-09-09。复用原仓的牛耕航线、栅格A*、碰撞与视线遮挡函数，通过`recorded_search_replay.py`比较五种路线。没有更改整机的搜索策略。历史M0/M2默认2.4m、随航段转向等假设仍属于旧研究配置，本报告单独加载实际场景和固定航向相机。

输入分两组：R60实际seed1–11（旧场地、真实55靶记录）；R61内净9.6m的新11套离线布设（生产拒绝采样器生成，只有seed11在Gazebo静态渲染核对，其他不是新飞行）。均对树冠包围盒半边长0.40/0.50m做敏感性比较。

假设：已知静态地图；路线生成不读取靶位；水平净空0.30m；FC离地1.40m、相机下16cm；固定yaw=0，光学X=-机体Y、光学Y=-机体X；采用归档CameraInfo的K/D；速度0.50m/s、转向惩罚1s、10Hz采样、连续可见0.20s。标准靶“精修可见”近似为中心及圆环四个极点入画，五点至少三点视线无遮挡；并非真实检测器的圆环接受标准。畸变多项式只用于光学视场内，防止远处离轴点被折回图像产生虚假可见。

## 判断

旧R60受限靶位下，北先搜索的第三个中心可见时间约34.56s，快于X调整的62.19s；扩大出生范围后反而慢于X调整。因此不应拿旧11组分布优化出一个固定“先去北边”的比赛策略。

固定机头时，沿Y搜索的换带方向对应相机短边，几何完整入画机会明显减少；少几米航程不等于更好搜索。优先候选是保留X方向覆盖，按当前地图生成可达端点；自由区间分段能补可见性，但带来更多转弯和30–42s名义时间。该离线A*拥有准确地图，没有覆盖SLAM误差和在线重规划波动。

全覆盖约266–308s还没算投递、返程、走廊与降落，应继续保留发现后中断投递及满足三槽后的早停，不能把全扫一遍后再投当作已满足600s。下一步若获飞行授权，应选少量明确对照来验收，而非直接替换已有飞行策略。

## 复现

在独立liftrace-sim仓中使用已有Python环境（本机conda rl_drone，53项unittest通过；未安装新环境）：

```bash
python recorded_search_replay.py --scene data/recorded_fields/r61_inner960_seed01_11.json --camera config/r61_camera_info.json --tree-radius 0.4 --output results/r61_tree040
python -m unittest discover -s tests
```

改变scene为`r60_actual_seed01_11.json`、tree-radius为0.5即可复现其余三组。原始比较JSON含每条路线、每seed每靶首次可见时间和假设。结果不预测YOLO概率、投递成功率、完整Gate或实际动力学时间。
