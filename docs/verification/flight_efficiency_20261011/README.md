## 第一门为何仍撞

危险预报后，MAVROS确实保持约0.35秒，随后接上新轨迹；恢复附近仍有约0.31m/s水平速度。不是一直盲目执行旧曲线，也不能据此单独认定未停稳造成碰撞。

四个共线门前后点被合并，规划直接面向走廊末端；新曲线门附近X较目标列偏约45cm，且目标曲线AGL降到约0.423m。FC的X基本跟随曲线。因此不能把这45cm全归于控制跟踪失误。

当前源码周期碰撞检查看EDT，发布前完整曲线检查同时看占用和EDT，存在判据差异；原bag没有同一内部占用/ESDF版本，不能宣布本次确因ESDF滞后漏判。在线避障在工作，但本场景实际避障失败，可靠性不能据此认定正常。

## 最小下一步

1. 走廊优先：保护跨墙最近门前后引导点；统一周期与最终占用/距离/高度判据，并只补必要的首次违规点、地图版本及保持解除诊断。实测门洞与包络仍需核对，不从点云缺口硬定坐标。
2. 普通高位点：离线比较12/15/18cm到点范围及0.8/0.5秒驻留，显式区分航点用途；升高、下降、接近、门/H不随之放宽。先解释终端误差，再做动态验证。
