## 三类有界恢复：独立本地候选

来源是高位研究分支 `62afbef8` 的恢复提交，选择性迁移地图层、FSM、轨迹服务器、控制接收门禁与桥接，不迁移同分支实验投影。旧控制修改前快照来自 `b520ee66`，保存在 `legacy_baseline/20261008/simplified_drop_h_recovery/`，含文件清单与规则要求的SHA256。

恢复支持退出虚拟禁越柱、退出额外膨胀缓冲、从阶段软件限高的轻微超高回入。真实实体及必要机体净空、未知与场界仍拒绝；保留原goal/动作身份/截止时间，不能复活已ABORT任务，也不获准接管视觉投递或H。

| 恢复约束 | 接线值 |
| --- | --- |
| 最大速度 / 加速度 | 0.30m/s / 0.50m/s² |
| 最大局部范围 / 时间 | 0.80m / 8秒，且不超过原剩余期限 |
| 允许阶段超高 | ≤0.25m |
| FC硬离地界限 | 0.05～3.50m，与现有FC地面参考一致 |
| 输入 / 地图年龄 | ≤0.25秒 / ≤0.50秒 |
| 跟踪余量 | 0.08m |

复核修复了一处实际集成错误：MAVROS child-frame速度必须用同条里程计完整姿态转到任务系再进入恢复曲线；普通规划速度原行为不动，非法姿态/子帧/速度拒绝恢复。

独立 `deployment/competition/candidates/recovery_validated_field_local.yaml` 以10月7日实测有限场地配置为基础，显式开启三类恢复、运动优化和高位续扫，使用本轮H参数。它是新候选，不是已验收的10×10正赛配置。正式模板的恢复默认仍关闭，因为现有恢复仅有离线/合成运动验证；本轮按用户“本轮一起适配，暂不上板”完成接口与参数接线，不自动推广为已实飞能力。生成与显式关闭测试见 [generated_candidate.json](generated_candidate.json)；JSON临时生成路径仅说明实际配置来源，已清理，不能用于飞行。
