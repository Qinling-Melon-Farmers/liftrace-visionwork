# 投递目标与释放窗口解耦（2026-10-10）

按现场复盘调整本地候选：**FC下降目标0.40m AGL，最终允许释放高度仍为0.35～0.45m AGL**。未连接、编译或部署板端，未运行新飞行或Gazebo；不能把本地构建通过写成实飞通过。

## 修改原因与实际行为

此前控制器直接把 `release_setpoint_height` 同时用于下降目标和释放下限，配置生成器又由目标加0.10m得到上限。仅改 `drop_agl` 会把放行区间错误地移到0.40～0.50m。

本轮把三者分别生成：

```yaml
# 均为FC中心离地高度，实际local Z由启动时地面参考换算。
drop_agl: 0.40
release_min_agl: 0.35
release_max_agl: 0.45
```

控制参数对应 `release_setpoint_height`、新增 `release_min_height` 和既有 `height_threshold`。旧配置不提供新下限时，控制器默认沿用旧下降目标作为下限；旧场地没有显式窗口时保留原生成规则。新增配置检查拒绝上下限只填一项、非有限值或目标不在窗口内。

冻结靶心、完整姿态旋转12cm投口杆臂、同时补偿与下降、冻结后不追残缺靶心均保持。最终几何检查仍要求当前新鲜反馈中FC与投口两项水平误差均小于4cm，并处于上述高度窗口；不增加速度上限、0.30秒累计窗口或下降点云准入。任务许可、正确槽位、取消及防重复执行规则保留。

任务预授权范围继续保留原0.27～0.47m AGL，没有借本次修改收紧跨节点许可；最终控制放行仍受0.35～0.45m约束。
