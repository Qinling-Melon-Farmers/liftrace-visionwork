# 对准与投递链路核对（2026-10-11）

本次只读取源码与既有录包，没有连接板端。上次部署记录和10月10日录包目标为FC AGL0.35m；0928分支38647c92及参考分支已将目标改为0.40m，未部署。两者最终释放窗口均为0.35～0.45m。主仓main=3d72e3e9仍保留0.35m默认，不能把候选配置说成main或实机已更新。

## 实际调用顺序

1. 任务选定目标，完成既有接近/复核，进入ALIGN，绑定动作、目标和槽位。
2. 视觉累计5张不同源时间戳的合格图像；类别/几何/时效通过、像素误差≤30px。图像准入年龄仍为0.5秒。重复缓存短暂过期时立即撤销ready，但可保留已积累计数，距最后合格源图像超过1秒才清零；重复消息不能增加计数或延长保留期。新坏帧、身份变化等仍清零。
3. 控制器接受新鲜ready、匹配上下文、有效几何和新鲜位姿后，冻结靶心与补偿后的FC目标；不再在高位累计70次或等待完成12cm补偿后才下降。
4. FC目标XY＝靶心XY－完整姿态旋转后的投口杆臂XY。机体FLU安装表：后仓(-0.12,0)、右仓(0,-0.12)、左仓(0,+0.12)m。冻结后横向补偿与下降同时执行，不追低位残圈，不在上次补偿结果上再次累加。
5. 当前同一次新鲜运动反馈中，FC距冻结补偿目标、按当前姿态算出的投口距冻结靶心，两项XY误差都严格小于4cm，且当前FC高度位于0.35～0.45m，才满足最终几何条件。速度数值只作诊断，非有限反馈拒绝；不再附加速度大小门槛或0.30秒累计窗口。**没有把过去分别满足过的XY和高度锁存为永久许可。**
6. 仍须当前许可与动作/目标/槽位匹配，未取消、未执行、执行结果未处于不确定状态；代理识别请求依据的许可版本，短暂等消息到齐，不拿旧否决拒绝新授权。当前有效许可预授权高度余量为0.27～0.47m，不能代替控制端0.35～0.45m的最终检查。
7. 舵机异步调用，不阻塞控制目标发布；真实脉冲约1秒，默认调用超时10秒。成功ACK提交投递，再爬升恢复；确定未执行与已经开始但结果不明分开处理，不自动重复开同一仓。软件成功不等于载荷实际落出。
8. moving recovery在ACK至少0.6秒后累计至少3条新样本、跨度至少0.15秒，还需高度≥0.9m、水平速度≤0.25m/s、向上速度-0.03～0.60m/s等原条件。恢复速度门槛不等于投递释放速度门槛。实际恢复时长取决于爬升，并非固定0.6秒。

## 许可时间容易混淆的地方

- 当前上下文任务链沿用Manager decision deadline；08动作预算为60秒，不是冻结后重新给60秒。
- release_guard中45秒是旧无上下文入口的承诺看门狗，不能泛称当前任务只有45秒承诺。
- 原承诺水平漂移大于20cm仍拒绝。单份许可有效期0.25秒，控制端还核对≤0.20秒年龄，许可通过周期发布更新，不应将这两个数加成固定等待。
