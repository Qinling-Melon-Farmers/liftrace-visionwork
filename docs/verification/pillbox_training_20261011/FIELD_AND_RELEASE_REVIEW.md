# 当前场地引导点、HINT与投递补丁回算

2026-10-11。读取两份实飞bag及内部膨胀点云，不改板端、原bag、模型或现场参数。第一轮用户确认撞第一门、未放地堡；第二轮放置了地堡。

## 1. 第一门并非单纯的控制跟踪偏差

第一轮相对bag时间199.5秒：原目标列X=7.69165，规划/控制设定X=8.14467，FC约8.136～8.140。约45cm横移主要来自规划曲线；FC相对设定的X差仅约0.5～0.9cm。走廊目标AGL0.9m，重规划曲线在第一墙附近却降到约0.423m，飞机随后下降至约0.51m。不能把这些都解释成飞控没跟住航点。

原门前后共线点被运动优化合并，实际seq15直接指向走廊末端(7.69165,-3.46256)。因此，“填写门前后点”目前不保证它们成为逐点约束，也不保证整条曲线维持0.9m。200.258秒已切MANUAL，205.200秒才出现任务ABORT；后续估计高度异常不计作真实飞行高度。

内部地图在192.403秒、第一墙附近一度出现X约8.10～8.60m的未占用候选带；后续同区域又出现占用。它是膨胀地图的投影，不是认证的门洞净空。不能据此直接把门中心改成8.35m；该位置还超过当前中心边界X=8.25m。真实门框坐标、撞击侧、地图后续填入占用的原因仍未闭合。

## 2. 适合当前布局的打点方式

保留当前场地原点与轴约定：起飞FC中心地面垂足为原点，+X朝场内、+Y向左。当前生成器对相对输入只加启动参考XY，不自动按起飞yaw旋转；不能将手持测量坐标和另一套朝向混用。

先分别测第一、第二门洞**实际净空边缘**，取中点得到x1、x2；同时核对墙面是否仍为相对Y=0、-1.4m。两门随机开口，不应默认共用X=7.7。保持已有入口点和H中心，门附近采用以下填写框架：

| 引导点 | 相对起飞点输入 x,y,agl | 用途 |
| --- | --- | --- |
| 第一门前 | x1, +a1, 0.9 | 在门前完成横向对齐 |
| 第一门后 | x1, -b1, 0.9 | 整机离开第一墙后再转向 |
| 第二门前 | x2, -1.4+a2, 0.9 | 对准第二扇实际开口 |
| 第二门后 | x2, -1.4-b2, 0.9 | 穿过后再去H |

a、b由机身外廓、墙厚、到点容差、接近速度与可用转向距离确定。作为测量讨论起点，前0.8m、后0.6m分别对应Y=+0.8/-0.6和-0.6/-2.0；这不是已验证可飞配置，两门间只有1.4m时，还必须检查横向换列是否放得下。不能为凑点而把转弯安排在机体尚未离开门框的位置。

**先核对优化后的实际航路。** 若这些门引导点仍被合并，单改YAML无法保证引导效果；后续应定向保留门前后约束，或针对走廊关闭共线点合并，再验证生成轨迹。不要因此全局关闭已验证的投后交接等运动优化。本轮仅提出建议，未修改合并器。

现有点云只给出“优先复测X约8.1～8.6m区域”的线索，无法代替x1、x2实测值。另需调查规划为何选择低到0.42m的过门曲线；只有上限1.0m，不等于有0.9m恒高保证。

建议把0.70作为粗HINT小幅提门槛的下一轮候选，不更改精修确认、冻结和投递门槛；0.75待更多帐篷/远距样本核对后再考虑。已有跨类别同位置冲突处理仍须保留，不能因提高置信度便取消。当前未改默认值或上板。
