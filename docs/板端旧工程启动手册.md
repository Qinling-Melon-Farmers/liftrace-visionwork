# 板端旧工程启动手册（含 YOLO）与话题订阅关系

> 适用：OrangePi 5 Plus 机载电脑（ROS Noetic），2025 赛季旧工程完整链路。
> 开发机（WSL2）复现时用仿真入口（见文末第 5 节），切勿在仿真中启动 actuator_pwm/相机 SDK。

---

## 1. 板端工程总览

```text
/home/orangepi/
├── patrol_uav_ws-patrol_planner/   # 主飞行工作区（定位/建图/规划/控制）
├── Visual/                          # 视觉工作区（yolov5_detect + depth）
├── detect_ws/                       # 相机与早期检测实验工作区
├── actuator/                        # 舵机工作区（actuator_pwm）
└── 启动脚本（tmux）：
    ├── location.sh   # 主飞行链（MAVROS/Livox/FAST-LIO/patrol_control）
    ├── vision.sh     # 视觉链（舵机/相机/圆环/十字/YOLO/降落）
    ├── 1_launch.sh / 2_launch.sh / 3_launch.sh  # 三路 PWM 舵机
    └── record.sh     # rosbag 记录
```

**启动顺序（推荐）**：`1/2/3_launch.sh`（舵机）→ `location.sh`（飞行链）→ `vision.sh`（视觉链，等飞行链 roscore 就绪后）。

## 2. 启动流程

### 2.1 舵机（PWM）— 1/2/3_launch.sh

```bash
# 1_launch.sh（pwmchip0 → actuator_pwm control1.launch）
tmux send-keys "sudo chmod 666 /sys/class/pwm/pwmchip0/pwm0/*" C-m
tmux send-keys "cd ~/actuator/ && source devel/setup.bash && roslaunch actuator_pwm control1.launch" C-m
# 2_launch.sh（pwmchip3 → control2.launch）；3_launch.sh（pwmchip4 → control3.launch）
```
> 也可先用 `init_pwm.sh`（export + period 20ms + chmod 666）统一初始化。

### 2.2 主飞行链 — location.sh

| 窗格 | 命令 | 启动内容 |
|------|------|---------|
| 0 | `sleep 13s; rostopic echo /mavros/local_position/pose` | 位置监视 |
| 1 | `roslaunch mavros px4.launch` | MAVROS ↔ 飞控 |
| 2 | `roslaunch livox_ros_driver2 msg_MID360.launch` | Livox MID360 点云 |
| 3 | `roslaunch fast_lio mapping_mid360.launch` | FAST-LIO（雷达+IMU 定位） |
| 4 | `cd patrol_uav_ws-patrol_planner && source devel/setup.bash && roslaunch patrol_control patrol_control_real.launch` | **主控 + Fast-Planner** |

`patrol_control_real.launch` 加载 `config/patrol_real.yaml`（完整航线）并 include `plan_manage/launch/patrol_planner_real.launch`（Fast-Planner）。

### 2.3 视觉链 — vision.sh

| 窗格 | 命令 | 启动内容 |
|------|------|---------|
| 0 | `cd ~/patrol_uav_ws-patrol_planner && source devel/setup.bash && roslaunch actuator_pwm launch_all.launch` | 舵机服务端 |
| 1 | `cd detect_ws && source devel/setup.bash && roslaunch camera_sdk camera_video0.launch` | 相机（1280x1024 MJPG，20Hz） |
| 2 | `cd patrol_uav_ws-patrol_planner && source devel/setup.bash && roslaunch patrol_control circle_detection.launch` | 圆环检测 |
| 3 | `roslaunch patrol_control cross_detection.launch` | 红十字检测 |
| 4 | `cd Visual && source devel/setup.bash && roslaunch yolov5_detect detect.launch` | **YOLO 双模型** |
| 5 | `roslaunch patrol_control landing_detector_node.launch` | 降落 H 检测 |

### 2.4 记录 — record.sh

```bash
rosbag record /camera/color/image_raw /livox/lidar /livox/imu /tf /tf_static \
  /fastplanner/goal /mavros/setpoint_position/local /freedom/static_pointcloud \
  /planning_vis/trajectory /cloud_registered /sdf_map/occupancy_inflate \
  /freedom/static_voxels /mavros/local_position/pose /iris_mid360/camera/rgb/compressed
```

## 3. YOLO 检测链详解

### 3.1 detect.launch（`Visual/src/yolov5_detect/launch/`）

```xml
<param name="/path_of_model1" value="$(find yolov5_detect)/best_rknn_model"/>   <!-- best 4 类 -->
<param name="/path_of_model2" value="$(find yolov5_detect)/tank_rknn_model"/>  <!-- tank -->
<param name="/path_of_image"  value="$(find yolov5_detect)/scripts/"/>          <!-- 预热图 -->
<node name="yolo_detect"   pkg="yolov5_detect" type="yolo_detect.py" output="screen"/>
<node name="image_process" pkg="yolov5_detect" type="image_process" output="screen"/>
```

### 3.2 两个节点

| 节点 | 语言 | 职责 |
|------|------|------|
| `yolo_detect.py` | Python（ultralytics） | 订阅图像+门控 → 双模型推理（best 4 类 + tank）→ 发布 `/yolo_detect`；tank 命中调 `/visual/service` |
| `image_process` | C++ | 提供 `/visual/service`（image2center.srv：像素→地图坐标，内参硬编码 fx≈997/1280x1024）→ 发 `/detect/tank_status` |

> ⚠️ launch 参数指向 RKNN **目录**，但 `yolo_detect.py` 实际用 ultralytics 加载 .pt（`best.pt`/`tank.pt`）——路径语义历史遗留；开发机复现需改为 .pt 绝对路径。

## 4. 话题订阅关系全图

### 4.1 patrol_control（主控，`patrol_control.cpp`）

**订阅**：

| 话题 | 类型 | 来源节点 | 用途 |
|------|------|---------|------|
| `/mavros/local_position/pose` | PoseStamped | MAVROS | 位置/姿态 |
| `/fastplanner/setpoint_position/local` | PoseStamped | Fast-Planner | planner 轨迹指令 |
| `/detect/waypoint_mark_point` | PoseStamped | circle_detector_node | 圆环目标点（对准） |
| `/detect/cross_mark_point` | PoseStamped | simple_cross_detect | 红十字目标点 |
| `/detect/land_mark_point` | PoseStamped | landing_detector_node | 降落 H 目标点 |
| `/yolo_detect` | String | yolo_detect.py | 类别名（比对 goal → align_ok） |
| `/detect/servo_complete` | Bool | — | 舵机完成反馈 |
| `/servo/complete` | Bool | actuator_pwm | 舵机完成 |
| `/detect/tank_status` | PoseStamped | image_process | tank 地图坐标 |
| `/detect/cross_status` | Bool | simple_cross_detect | 红十字存在性 |
| `/uav_vision/selected_target` | TargetCandidate | 新链（可选） | 2026 候选目标 |
| `/uav_vision/drop_offset` | 自定义 | 新链（可选） | 像素→世界对准 |

**发布**：

| 话题 | 类型 | 消费者 |
|------|------|--------|
| `/mavros/setpoint_position/local` | PoseStamped | PX4（MAVROS） |
| `/fastplanner/goal` | PoseStamped | Fast-Planner（planner 模式） |
| `/detect/class_control` | Bool | yolo_detect.py（推理门控） |
| `/detect/tank_control` | Bool | yolo_detect.py（tank 门控） |
| `/detect/control` | Bool | circle_detector（圆环门控） |
| `/cross/control` | Bool | simple_cross_detect |
| `/detect/landing_control` | Bool | landing_detector_node |
| `/detect/servo_status` | Bool | — |
| `/detect/point_class` | Int8 | 状态机阶段（0=Takeoff 1=Run 2=Align 3=Land） |
| `/uav_vision/align_mode` | String | 新链（对准模式） |
| `/control1` `/control2` `/control3` | Bool | actuator_pwm（旧直发舵机） |

### 4.2 视觉检测节点

```
camera_sdk（/camera/color/image_raw, 1280x1024 MJPG 20Hz）
  ├→ circle_detector_node ── /detect/waypoint_mark_point（+ /detect/control 门控）
  ├→ simple_cross_detect ── /detect/cross_status + /detect/cross_mark_point
  │                        （订阅 /cross/control 门控）
  ├→ yolo_detect.py ────── /yolo_detect（+ 调 /visual/service）
  ├→ image_process ─────── /visual/service + /detect/tank_status
  └→ landing_detector_node ── /detect/land_mark_point（+ /detect/landing_control 门控）
```

### 4.3 定位/规划链

```
Livox MID360（/livox/lidar + /livox/imu）
  → FAST-LIO（fastlio_mapping，/Odometry + /cloud_registered + /map_generation）
  → FreeDOM（/freedom/static_pointcloud + /freedom/static_voxels）
  → Fast-Planner（/fastplanner/goal → /fastplanner/setpoint_position/local + /planning/pos_cmd）
  → patrol_control → /mavros/setpoint_position/local → PX4
```

## 5. 开发机（WSL2）仿真替代

| 板端 | 仿真（本机） | 说明 |
|------|-------------|------|
| 相机 SDK | PX4 模型相机插件（/iris_mid360/camera/rgb/image_raw） | `patrol_full_competition_sim.launch` |
| 舵机 PWM | sim_helpers `/Servo` mock 或 uav_mission guarded 链 | 不启动 actuator_pwm |
| YOLO | sim_helpers 动态类别 mock 或 新链 target_detector.py（conda） | cv_bridge 冲突规避 |
| location.sh | `sim_run.sh`（阶段 0 规范） | 见 `top_level_scripts/sim_run.sh` |

仿真入口：`SIM_HELPERS=1 bash top_level_scripts/sim_run.sh <场景> roslaunch patrol_control patrol_full_competition_sim.launch ...`
