## 3. 候选与权重的真实语义

当前逻辑**不是全局记忆目标按权重排队**，而是“当前新鲜候选局部按权重选择 + 发现时序
驱动立即中断”。具体为：

1. `target_memory` 给当前候选按类别权重排序：
   `red_cross=10, tank=5, panzer=2.5, bridge=2, pillbox=1.5, tent=1`；
2. 只有已经确认、最后观测年龄不超过 `0.5 s` 的候选能发布为
   `/uav_vision/selected_target`；若同一帧/时间窗同时可见多个目标，权重高者优先；
3. 导航组 `CandidatePolicy` 只检查 `map_valid/state/class/有限坐标/新 ID`，不读取权重；
4. manager 在 `SEARCH` 收到第一个合法 `selected_target` 后立即切到 `APPROACH`；
5. `APPROACH/TARGET_HOLD` 期间的新目标回调被忽略，不进入持久任务队列；
6. ID 在准入时就加入已接受集合。即使后续 `capture_timeout`，同一 ID 也不会再次执行。

因此本轮 pillbox 与 tent 同区域出现时，pillbox 因 `1.5 > 1.0` 先被选中，证明了局部权重
有效；但尚未看见的 bridge/panzer/red_cross 不会参与比较，失败 pillbox 也没有冷却重试。
若要满足“全场记忆—权重队列—三投”，任务层后续应消费 `/uav_vision/targets` 的长期地图
候选，显式维护队列、执行结果、冷却/重试和剩余时间，而不能只订阅 `selected_target`。

## 5. 当前阻塞与建议归属

### P0：导航/任务组

- 在导航组自有新分支设计持久候选队列：允许类目 profile、权重、地图位置、距离、观测
  年龄、已投/失败状态、冷却重试和剩余时间；本分支不修改上游 manager；
- 把“新鲜观测可立即中断”和“已记忆候选可稍后执行”分成两套准入；
- 给 manager 增加明确投递结果接口，失败候选不能永久丢失，也不能无上限重试；
- 优化 10 min 时序：第三投优先于完成全覆盖，三投后立即返航；
- 复核 2.2 m 搜索航点执行时的高度上冲、长航段轨迹和 20×20×5 地图 z 边界。

### P0：视觉组

- 保持 `/uav_vision/targets` 的 stable ID、地图坐标、质量、`last_seen` 和拒绝原因可靠，
  不把长期记忆伪装成当前新鲜观测；
- 为随机红十字落地“搜索阶段疑似线索可抵近、投递前双确认”的分级候选；
- 针对 pillbox `capture_timeout` 保存/回放抵近阶段图像，量化 1.2 m 高度下圆环是否出画、
  关联是否断裂，再决定相机高度或几何阈值，不凭单轮调参；
- 在下一轮报告中增加搜索/接近/捕获/对准分阶段耗时和最大高度，便于定位时间损耗。

### 联合 Gate

- 固定同一 world/seed/模型，600 s 内完成 3 个不同 stable ID 的顺序槽位投递、返航和落地；
- 0 越界、0 碰撞、0 错误释放；搜索状态高度不得超过 4 m；
- 随机红十字只有航线实际覆盖其视场后，才评价“漏检”；
- headless 通过后再启动 GUI/RViz。本轮按用户要求暂缓 GUI。

该结果对联调的含义是：当前候选准入与评测接口已经可用，但算法召回仍有明确边界。四类
标准靶在 1.2/2.4 m 静态均成功，3.6 m 静态仍全失败；动态 panzer 1.8 m 两档速度成功、

1.8 m 未形成连续确认。失败 red_cross 已出现有效检测和地图帧，视觉组应先收敛双路重叠与
完整帧连续性。正式导航 Gate 不应把“目标未 selected”一律归因于 manager，也不能把
`MEASURED` 写成视觉算法达标；导航组仍负责候选接受后的持久队列、失败结果、冷却重试和
剩余时间调度。

按导航组《视觉组需求.md》应区分两种完成度：

- 双方冻结的首轮最小交付已完成 100%：seed=11、23/23 trial、6/6 产物、无 infrastructure
  gap，`P_confirm/P_selected/P_interrupt` 定义与墙钟/曝光/地图失败归因均已落地；但算法只有
  13/23=56.52% 确认/选中，不能写成性能 PASS。
- 原始完整性能曲面目前约 18.4%：静态高度 15/25 格，中心线高度×速度 8/100 格；横向偏差、
  偏航/加减速/转弯、多目标 ID 压力、30-seed、真实相机/OrangePi 和联合链实际
  `P_interrupt` 尚未完成。当前 CSV 也还缺逐帧 camera pose/角速度/归一化偏差/yaw，以及
  raw→resolved→geometry→center_refined 的完整阶段布尔和正式聚合曲面字段。
