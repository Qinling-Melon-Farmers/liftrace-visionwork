# 后续效率与投递精度：仅分析，尚未实施

本轮范围是相机视场、搜索区边界和降落修复。A/B/C沿用原有速度档，不在三轮之间调参；本页没有新增飞行配置。数据结论以本轮完整报告为准。

## 怎样判断还有多少时间可压缩

逐段分开统计高位搜索、回降/复访、三次对准与释放、末投恢复、进廊转场、走廊和H降落。只有同一冻结场景、共同里程碑均成功的区段才能算节时；失败截止时间不能当完赛时间。2.6m原走廊与快走廊对照同时包含已有的走廊高度和分段速度，不能把全部差值单独归给速度。3m收益也不能只看理想视场面积，要扣除额外爬升/下降、漏识别、低位重捕和绕障成本。

优先分析长时间原地等待和不必要的阶段串行，其次才考虑增加运动速度。初次规划无解与已经接受轨迹后的停滞必须分别列出：前者看目标高度、区域约束、起终点占据与规划尝试；后者看真实位移、弧长投影、重规划交接与有界恢复次数。一次恢复成功不意味着所有停滞已消失。

潜在方向及实施前需要的数据：

| 方向 | 应先证明什么 | 暂不改变的约束 |
|---|---|---|
| 高位提前结束与三点访问次序 | 三类有效线索的首次齐备时间、排序代价与实际绕行差值；冲突坐标先逐点低位复核 | 高位线索不能直接授权释放；不得越树顶或提前进廊 |
| 减少初次规划等待 | 重复尝试的首因，尤其低高阶段边界、H捕获目标与规划高度上限一致性 | 不靠无限重试或重置任务deadline掩盖失败 |
| 末投到进廊衔接 | 恢复、转场、进廊下降各自耗时；验证移交确实释放旧轨迹 | 机构确认、离靶净空、入口低空条件仍需满足 |
| 走廊分段提速 | 窄门局部真实速度、横向/竖向跟踪误差及倾斜包络 | 80cm开口、原55cm飞行包络、门体高度与跟踪余量 |
| H末段效率 | 真实支撑接触、飞控landed状态与估计漂移；稳定接地优先 | 不以提前停桨、跳过识别或忽略墙碰换取短时间 |

本轮不新增上述速度优化。后续若实施，应一次只改变一个可解释因素，并保留相同seed及成功区段的前后对照。

## 投递精度的下一步

当前可从日志计算的是**成功mock ACK瞬间的真实飞控中心XY与靶模型中心距离**，不是快递盒落点。先区分四项误差：视觉靶心提取、投影/相机外参、机体跟踪、真实释放口与飞控中心的杆臂。不得用仿真真值实时修正控制来制造更好成绩。

建议离线联合检查释放前一段时间内的图像中心、融合靶坐标、LIO位姿和Gazebo真值：若矢量偏差跨目标/航向一致，优先查坐标与杆臂；若随图案/视角变化，优先查圆环/红十字中心和投影地面高度；若释放瞬间跳动，查速度、延迟与连续稳定窗口。只有分清偏差来源，才讨论收紧释放门槛或延长对准时间，避免增加耗时却不改善真实误差。

真实机构目前按用户要求暂留**每投10s、三投共30s**的预算。它是待标定的完赛预算附加项，不是已经实现的等待行为，也不是要求每次强制空等10秒。正式机构需要区分“命令接收”和“释放成功”；反馈成功后才能结束事务，失败/超时不可伪造成功。最终应记录触发到成功的分布及最长耗时，再决定超时、重试与任务截止前准入策略。

## 仍需覆盖的边界情况

- 同一高权重类别出现两个空间簇，低位先查到的簇其实是误识别；两个簇都无法重捕或真实目标被遮挡。
- 高位路线被树群截断、目标位于树后、早期地图不完整、下降位置与任务区边界同时限制规划。
- 定位缓慢漂移、位姿/图像时间戳陈旧、低帧率或间断观测；同seed单次通过不能覆盖这些情况。
- 80cm门开口靠近任一端点或中间任意位置，门前转弯叠加升降、估计高度偏差与机体倾角。
- H靠边、首次CV捕获失败、接地检测延迟、接触后反弹和AUTO.LAND估计漂移。50cm只用于LAND物理代理，不应扩大到搜索/过门或静默忽略墙接触。
- 任务异常退出、剩余载荷槽不一致、机构成功反馈延迟/重复、通信中断。预算与状态不能因恢复或重新规划而重置。

三轮都使用同一seed，即使全通过也只说明这套固定布局的A/B/C完成，不构成多seed鲁棒性、实机投递精度或板端资源验收。

## 本批数据补充（仿真结束后，只作分析）

本批B最快187.733s；3m的C为216.548s，仍有panzer/pillbox空间冲突，经现有低位复核成功，不能把3m直接替换为默认。A/B三投前差24.049s，投后差39.885s；后者比整场63.934s差值更贴近走廊配置的收益。

最明确的剩余等待是panzer：ALIGN至锁定释放证据A/B/C为30.463/4.858/17.231s，而三轮规划进展恢复均0次。释放许可在该等待中主要显示no_release_commitment，现有归档缺少连续未通过证据的像素误差/质量细项，暂不能唯一定位其视觉根因。应优先设计轻量观察记录，不能把这段误称为规划停滞，也不应先放宽释放门槛。

九次真实FC误差中位8.01cm，ΔY全部为负，平均约−7.02cm。旧像素偏移兼容控制路径按yaw做二维变换，检查完整姿态、相机投影、ROI中心、稳定窗口和释放杆臂可作为后续诊断候选；当前资料不足以确认哪一项产生了该方向偏差。按用户要求，本轮没有据此修改控制算法。

地面支持目前在碰撞日志中单独归类。未来还应区分初始待起飞/合法LAND支持与任务中意外擦地，避免“不是墙碰”被错误理解为任意阶段触地均可接受。本批只记录，没有新增该行为策略。
