# 高位分级记忆、低空消歧与开柱回归

2026-09-27。用户批准实施高位方案，并要求修复后开启障碍柱、水平膨胀0.275m重跑seed31和38。本页先记录代码验收，动态结果运行后更新。

## 已实施

1. **发现仍宽松，提前中断另有依据。** 一次≥0.60类别框、有效时刻投影仍保存为导航线索。提前TOP3要求每类为原精修Hint，或两张不同源图像支持：间隔0.1–1.0s、位置差≤0.5m，且无未解决冲突。重复发布、换ID的同一帧不能增加支持。高位航线结束可携带部分/单帧线索下降，不无限等待三类。
2. **有限假设可更新。** 每类最多两个空间位置。证据顺序为低空正式确认、精修Hint、粗框；同等级的不同位置保留冲突，不能最后一帧获胜。第三个强位置能替换早期弱位置；TTL/epoch/时钟重置同步清理冲突。高位定位时间戳始终为源时间。
3. **按实际位置复核。** 冲突地点以0.6m关联范围去重，不再按类别＋列表下标重复派飞。低空新正式候选若证明该点是pillbox，就撤销该点的panzer假设，保留别处的panzer；旧高位消息重发不能恢复被排除的标签。两个同时合格的竞争标签仍不放行。
4. **沿用现有REVISIT/REACQUIRE。** 到达后最多5s观察，满1s仍无正式确认时，最多一次0.5m换观察点。需新鲜位姿/地图、场地边界和可达栅格候选；实际航段仍交原三维规划器。换位及后续观察共用原5s窗口，不重新计时。保留75s全局冲突上限；去掉额外固定25s截断，以原任务航段deadline和75s较早者为限。超时只表示本次动作未完成，不等于证明物理不可达。
5. **投递链继续使用低空新证据。** 不从高位Hint合成CONFIRMED，不放宽APPROACH/ALIGN/稳定/槽位/释放反馈；已投类别不重复投；近墙不可达后的低权重替代仍可执行。已有速度、高低高度、FOV、走廊与降落逻辑未加新提速。
6. **膨胀统一改为XY 0.275/up 0.20/down 0.10m。** 主配置与完整研究入口一致，路线排序栅格同步读取0.275。SDF的5cm体素向上取整，因此实际水平扩张为6格=0.30m；不是精确27.5cm几何距离。55cm是机体工程包络边长，不是规划器自动识别并相加的机体半径；旋转、跟踪和体素边界仍须动态检查。

障碍柱沿用本轮已修复的有限凸包/中部轮廓算法，两个实验均开启；未回到早期大凸包环带。

## 边界和待验收

两帧一致不能消除持续误分类；高空若根本未看清panzer仍可能需要补搜。0.6m地点合并不适用于两真实目标间距小于关联半径的场景。5s局部窗口是候选策略参数，需实跑检查是否过短；没有按离线用例宣称提速百分比。本轮未训练模型、未改变板端或main。

回归为历史seed31/38同地图、2.6m、已有快走廊；除了策略修复，也修过柱并将有效膨胀从0.25增加到0.30m，故与此前关柱轮只能作整套方案比较，不能把时间差全部归于视觉优化。
