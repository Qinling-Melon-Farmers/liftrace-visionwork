## 2. 原视觉需求已经交付了什么

已导入KS2A543 B100/C25/D11，当前数据目录为`data/vision/vsim04_20260904_ks2a543`，provenance指向视觉交付v4和源revision6743099。

- B100：5类×5高度×4速度，进入精确格点查表；每格仅seed11一次0/1测量。
- C25：横向偏差数据保留，未作为完整概率曲面拟合器消费。
- D11：11种受支持动态条件；其余39种未运行，不能算失败。
- `p_selected`不是导航`P_interrupt`；provenance明确保留后者为null。
- 1280×720相机、接受的K/D和13.705Hz板端600s吞吐背景已登记。旧需求里对1920×1080标定的提醒不能直接当成当前内参仍未确认。

因此，应保留这些数据和来源，补当前1.4/2.6m、实际速度、横向位置、提示误差及当前确认逻辑的缺口；先核对“高度是FC还是光心”及模型/阈值版本，不直接拼旧表或重复整张100格。单格一次成功不能通过再跑几千次Monte Carlo变成可信成功概率。

## 3. 为什么旧默认模型不能直接评价当前高位方案

| 旧默认/现有能力 | 与当前链的差距 | 影响 |
|---|---|---|
| baseline搜索区域6.2×8m、演示障碍 | 当前9.6m场地、实录随机树/门/靶 | 原参数排名可能针对错场景 |
| 2.4m搜索、M2 3.4m升高转运 | 当前高2.6/低1.4且禁止越障碍投影 | 旧模型可能奖励现实中不允许的捷径 |
| 随航段转机头 | 当前固定机头、刚性相机 | 有效航带宽度与可见时机不同 |
| M2每次Cue投递后回中断点 | 当前累计三类中断、下降后按目标复访 | 航程/时序模型不等价 |
| 精确B100格点以外`legacy`回退 | 当前1.4/2.6和实速大多不在精确格点 | 输出可能由假设概率而非实测数据驱动 |
| 已知准确地图A*、恒速和固定服务时间 | SLAM、轨迹投影、保持锁、控制限幅/超调不在模型中 | 无法诊断第二门停滞或证明靠墙安全 |
| R64实录与固定姿态几何工具（仅fork） | 有用，但数据截至09-09，尚未包含新高位批次 | 需要增量导入，而非重建整套工具 |

不要把该仓改造成第二个Gazebo，也不要继续用旧M2得分/时间直接宣布当前策略最优。

3. 新入口复用A*/相机/遮挡函数；路线构建不读靶位，之后才用真值做几何评测。输出航程、名义全线时间和指定三类几何可见时刻；检测概率、完整任务时间保持null。
4. 已完成20组离线对照和74项测试。没有运行飞控、ROS或实际投递。

初次结果：高位9/10静态几何路线可构造，7/10累计三类中心几何可见、4/10满足更严的五点近似；低位为10/10、10/10、9/10。这些比例不是识别召回或完赛率。高位可见时间中位数约26s、低位约108s来自不同可见子集且速度不同，不能相除宣布整体节时。

33实际PASS而名义几何未齐三类、37/39实际PASS而五点近似未齐，是重要的模型适用性提醒：固定水平姿态、AABB树冠和名义避障路线不是实际飞行。本工具可以发现风险、筛候选，不能否定已发生的实跑结果。

## 5. 55cm包络统一口径

55cm按用户说明已是主动膨胀近10cm的鲁棒设计，不是裸机外形。新profile直接取半宽0.275m（固定yaw=0的XY近似），**不再加一份原鲁棒padding**。倾斜时只计算该设计包络本身的投影；额外余量如需敏感性分析必须显式声明。

原M1c演示`horizontal_clearance=0.45m`是障碍膨胀/点路径参数；旧实录入口又用0.30m。不能把这些数与0.275再无条件相加。新入口避免混用，但其几何可行仍不是动态跟踪保证。Guard接触与真实机体接触分别解释，既有Gate记录不改写。

## 6. 接下来最值得做与不值得做的事

| 建议 | 用途 |
|---|---|
| 保留并优先：实录姿态/相机回放，与当前名义几何对齐 | 解释33等模型假阴性；比较航带补缝、航向和可见驻留 |
| 小范围：同速度、同场景的高位骨架/航带候选 | 分离高度、航路和速度效应，只挑少量候选交给SITL |
| 增量：观测线索时间线与提示空间误差 | 让早停/低位复访不再默认完美坐标；保留历史B/C/D数据 |
| 后续：有来源的阶段耗时、失败/等待统计 | 区分名义几何时间与经验时间；给范围而非伪精确完赛预测 |
