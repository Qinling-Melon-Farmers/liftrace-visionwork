## 高度新发现

seed33旧轮375–386s的真值Z峰值0.4914（AGL0.7114），LIO峰值0.4940；MAVROS Z末值-0.4235，而真值末值0.4838。最终MAVROS设定点最高仍是0.28，并未指令超出上限。原“对准爬升”现象不能直接归因为阶段参数不一致；飞控高度估计与LIO/真值分离是关键未解决因素。

该旧轮EKF2_EV_CTRL=9（未融合外部高度）、HGT_REF=0、BARO_CTRL=1。原架构对LIO垂直可观测性已有保留；本轮不仓促切换高度来源或放宽0.7m Gate。通过原有三路位姿和指令记录继续检查，报告中单列差异。
