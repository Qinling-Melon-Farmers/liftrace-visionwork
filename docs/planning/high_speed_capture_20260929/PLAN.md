# 高速飞行拍摄与识别测试

2026-09-29，新增专项计划，待现场执行。这里的“高速”指飞机以1m/s经过靶标，不是改变视频播放倍速或提高相机帧率。本次仅补充计划，尚未新增可执行的第09组入口，也未修改八组默认速度、识别阈值或部署到飞机。任务安排以各分支VISION_2026_ROADMAP.md为准。

## 要解决的问题

确认从0.5m/s提高到1m/s后，五类靶标是否仍能在有限视野时间内形成正确粗线索和独立多帧支持，分清运动模糊、曝光、推理抽帧、处理延迟、边缘截断与记忆冲突。该专项只采集和评价，不因发现目标执行接近、对准或舵机释放；真正的低空复核和投递另由闭环专项验证。

## 对照安排

先以现场已采用的飞控中心离地2.0m做高位对照，保持同一布设、机头方向、模型、相机分辨率、图像方向和录包负载。不要在该对照中同时改变高度、曝光策略和检测阈值。

| 条件 | 实际目标航速 | 光照 | 每种条件的采集 |
|---|---:|---|---|
| A | 0.5m/s | 正常 | 两次相同方向直线经过 |
| B | 1.0m/s | 正常 | 两次相同方向直线经过 |
| C | 0.5m/s | 较暗 | 两次相同方向直线经过 |
| D | 1.0m/s | 较暗 | 两次相同方向直线经过 |

先完成正常光照A/B，再完成较暗C/D；这四种条件是采集单元，不要求每个单元单独起降。返程、转弯和加减速另行标记，不混入直线等速统计。若一次航段不能让五类都充分进入画面，分批摆放并对每一批重复A/B/C/D，不能为凑齐数量把靶板重叠。

- 五类都采：bridge、panzer、red_cross、pillbox、tent，尤其补齐缺少新增实拍的后两类。既要有清晰中心画面，也保留自然出现的边缘/局部截断画面。
- 分开记录真实近邻靶、同一靶多标签与同类多位置；尽可能记下各靶在固定起飞坐标系中的实测中心、尺寸和布设照片。
- H靶作为独立背景负例采集，保持H几何识别链原状，不重新加入panzer特判。若现场没有H，本项明确记为缺失，不宣称通过。
- 高位对照后可补1.4m低位0.5/1.0m/s同条件经过，研究低位重访能否及时确认；2.6m及更大场地另行安排，不自动超过现场2m约定。

## 航段与速度统计

复用前方6m、左右±1.5m的现场范围，直线位置和端点根据实际净空确定；本计划不把边界端点写入飞行配置。继承已知外参、自动地面基准和新建图/视觉READY检查。

不能只把YAML速度填1.0就算完成高速试验。以同一固定坐标系的实际水平速度、源时间戳和同步姿态划分有效航段；优先读取有明确坐标约定的速度反馈，位置差分仅作交叉核对。定位跳变和过期样本单列，不能算成高速。

建议分析窗口：0.5m/s档取0.45–0.55m/s，1m/s档取0.90–1.10m/s，连续至少1秒；这是本专项统计口径，不修改控制或安全门槛。目标实际可见时间与速度窗口的交集才计入相应档，目标仅在减速段检出要单列。高度、横向偏差和角速度一并呈现。

现有现场加速度约0.35m/s²。理想一维匀加减速下，从静止加到1m/s再停下共需v²/a≈2.86m，加上1秒等速约需3.86m，尚未计端点净空、轨迹平滑和实际跟踪。因此6m小场地要明确留出加减速段；无法形成有效速度窗口则记“高速样本不足”，不能靠提高加速度或缩边界凑通过。后续实现入口时必须核对任务限速、规划器、跟随距离及控制限幅，不仅改一个巡航参数。

## 录制与回放

复用板端TrialBag和本机tools/bag_replay。板端保留压缩相机bag及视觉/位姿事件，独立MP4编码继续默认关闭；回到本机统一生成原片、视觉叠加、轨迹动画和多画面视频。不要用5/10fps导出视频代替原始相机消息评价检测帧数或模糊。

必须保留：原始相机源时间戳/CameraInfo、检测/精修/投影/targets、navigation_hints和probe_status、TF、位姿/速度/飞控状态、视觉perf、节点日志与实际运行YAML。现有录包已涵盖这些话题；需实际核对持续输出而非仅存在一个空消息。曝光、增益、自动曝光模式、分辨率、相机与检测实际频率能读取就记录，读取不到明确标未知。

保存模型文件名及匹配metadata、源码版本、场地布设、灯光状态、航段方向和地面基准。初轮保持原录包话题与负载一致；地图是否降频后续单独调整，不把减负前后混成纯速度收益。

回放工具在视觉板端完整工程及导航板端参考分支中使用；导航研究分支本身不是完整工具包。按工具README处理分卷、选择map/camera_init并校验时长。成片1倍速，图像框按源时间对齐；在线响应延迟另按消息到达与源时间计算，不从回贴框视频估计。

## 评价与交付

每个物理靶、每次经过分别记录，不只累计YOLO框数量：

| 层级 | 指标 |
|---|---|
| 采集 | 目标可见区间、有效速度/高度区间、图像与检测频率、丢帧、曝光信息和模糊样例 |
| 检测 | 各类逐帧正确检出/错类/漏检，H误检，首次正确检出时间；人工标注可见实例作为分母 |
| 粗记忆 | 首个正确有效投影、独立支持帧数、位置离散程度、错误类别/重复位置、优先重访位置是否对应真靶 |
| 提前中断 | 是否达到原双帧/时空一致门槛，冲突如何影响资格；不能把可重访数量当confirmed数量 |
| 低位确认 | 后续低位样本中形成confirmed所需时间与拒绝原因；仅高位拍摄不能验收这项 |
| 负载 | 推理耗时、源到接收延迟、过期拒绝、输出连续性；同时记录板端负载/温度（若可读） |

现行粗线索0.60及独立支持0.10–1.00秒/0.50m先冻结；圆环、正式确认和释放门槛不随本试验放宽。高位图像应能形成可重访的正确位置，不要求高位圆环或正式confirmed才算有价值。可离线对比粗阈值0.60/0.65/0.70，但原始在线结果单独保留；若记录或推理导出已经截掉低分框，则须重跑原始图像，不能凭缺失框评估更低阈值。

交付每靶每经过表、0.5/1m/s同条件对照、首次正确线索耗时与延迟分布、错检/漏检截帧、实际速度高度图和四种回放。某类只在一次经过中产生单帧正确框，结论应分别写“可发现”与“未形成提前中断支持”，不能合写为已确认。

1m/s下预期可见靶若反复没有正确可重访位置，先区分曝光模糊、视场不足、检测稀疏和记忆过滤，再选择相机调整、模型补样或局部减速。通过两次小样本不代表所有布局可靠；完整高位→低位→投递仍需后续闭环实飞。

## 数据复用

原bag与全帧存档保留。按整个航次/布设分离训练与验证，近邻视频帧及其增强派生不能跨集合。所有五类补充正常/较暗实拍；H保持投递类别空标签。记录难例原因（阴影、过曝、运动模糊、截断、相邻实例），下一轮训练再据本专项结果选择增强，不把验证片段全部回灌后宣称泛化提升。
