## 2. 试飞顺序与每阶段唯一主问题

以下架次是推荐的最小安排，不是统计可靠性保证。失败后先定位首个失败阶段，不无分析原样重复。每阶段达到通过条件后才增加下一个变量；手动接管保留有用数据，但该自主任务不记PASS。

| 阶段 | 主问题／场景 | 推荐安排 | 正常结束与晋级条件 |
|---|---|---|---|
| P0 地面准备 | 实际舵机服务、相机方向、配置来源是否匹配 | 现场地面检查；飞手确认后进行机构带载测试 | 三槽逐一确认实际释放，名称/回执匹配；不计飞行架次 |
| P1 红十字单投闭环 | 已中断后，能否真正投出并恢复？ | 同一独立红十字，2次单投 | 正确槽位释放一次→恢复完成→按专项结束；重复运行无重复释放 |
| P2 标准靶单投 | 装甲车能否从类别框变为可投坐标？ | 先装甲车，重复一次；再桥靶1次 | 类别与圆环有效关联→地图候选→对准→实投→恢复 |
| P3 低空连续投递 | 第二／第三次事务能否正确接续？ | 红十字＋装甲车2投；再三类3投 | 不重复投同一目标、不复用已用槽位，每投后继续任务 |
| P4 高位搜索重访 | 高位信息能否用于低位再找到目标？ | 先1个目标，再2个、3个 | 2.6m搜索记录线索→降至低位→逐个重捕投递；未发现目标不虚构投递 |
| P5 H与走廊交接 | 已通过走廊，能否接上视觉降落？ | H专项1次；走廊＋H至少1次 | 过门后在指定开阔区升高识别H，视觉对齐并自主落地 |
| P6 固定整场 | 搜索、多投、走廊、H能否一次连续完成？ | 先低空路线1次；再高位路线同布局1次 | 从任务启动至落地无人工重启／补指令，分段指标齐全 |
| P7 扩展与比较 | 改布局后是否仍可靠，高位是否省时？ | 先单因素，再混合布设；必要时成对复测 | 汇总所有成功/失败，不只挑最快轮；之后才单独提高速度 |

P5可与P1–P4穿插执行，因为无需投递机构；P6之前必须完成。P0/P1使用真实执行器时，由现场按试飞流程确认，不由本方案自动触发。

## 3. 场地、坐标和参数原则

- 局部专项继续用总面积4×4m：起飞在近侧边中点，固定起飞系+X朝场内、+Y朝机体初始左侧。目标在内部留有机体与规划余量的位置，首轮不放近墙或树旁。4×4只验局部闭环，不能验证比赛全场覆盖率，也不要硬塞完整走廊＋三靶。
- 本次最简测试配置里的6m航点、home_xy=[4,0]不能直接搬进4×4专项；后者在边界上，并不是起飞点。每个专项的搜索终点、结束点和原地降落语义须明确。P6/P7使用足够大的实测场地。
- 第一次补验P1尽量保持9月25日实际成功中断轮的航高、速度和外参，只修复机构接线及明确专项结束条件。其搜索local Z约1.0m不是离地1.0m，实速约0.85–0.96m/s。不要同时将高度改成1.4m、速度改成0.5m/s、换外参后再归因机构差异。
- 后续高位专项目标仍为FC离地2.6m、低位重访1.4m；高度改变单列为试验变量。投递、恢复、H识别高度分别配置，需同时对齐任务、控制、许可、规划限制。不能只改一个航点Z。
- 继承现场当前相机旋转、标定及槽位补偿；旧四套known_rig仍有早期方向，不能直接覆盖9月23日已修正的相机四元数0,1,0,0与像素矩阵[-1,0,0,1]。map与camera_init是否采用单位静态TF，以现场成功配置及坐标核对为准，不另叠加发布者。
- 地面local Z约0与相机离地高度是两件事。优先沿用专项已有静置地面基准能力；最简测试目前仍有ground_z=-0.22默认值，迁移时统一处理，不要求飞手每次手算外参。
- 各阶段先沿用相关成功轮速度、膨胀、跟踪与限高设置；树柱建模和进一步提速另开变量，不与初次实物投递／高位接入同轮改变。

## 4. 各阶段操作与观察点

### P0：把“忘开舵机”变成明确的准备项

核对实际底层服务是启动入口传入的名称（本次默认为/legacy/Servo_raw），并记录slot→实际机构的对应关系。地面带载确认每槽触发、物品释放及反馈耗时。服务应答只能证明软件调用结果，不自动证明物品脱离；缺硬件释放传感器时由现场录像/观察补证。

每投10s暂作为待标定的机构时间预算，不是固定悬停10s，也不是一到10s就认定成功。当前实现是否已消费该预算须单独确认；不要在测试现场用sleep掩盖反馈缺失。记录最长实测耗时后再修订预算。

将独立红十字放前方中央，静态预览一次是否仍有几何和有效投影。此前标准靶衬底上的红十字可以保留为对照，但不再作为唯一材料。

### P1：红十字单投，补齐最短未通过链

先无障碍、单目标直飞；不引入高位队列。主链为SEARCH→APPROACH→ALIGN→RELEASE→RECOVERY。记录红十字首次原始检测、首次有效投影、确认、中断、释放许可、实际释放、恢复完成七个时间点。

通过需要：真实释放一件且正确槽位；任务成功确认一次；恢复实际高度和设定点一致；结束交接没有旧轨迹残留。结束建议沿用单投专项“恢复后原地降落”，但当前最简full入口不能凭名称保证仅投一次即落地——须先完成专项适配；此前01专项为mock，不能把mock回执当实投。

第一架通过后，用另一个槽重复，并记录FC/释放槽中心/实际包裹落点对靶心的误差。近中心构图、独立红十字材料及机构接线的改变逐项记录。

### P2：标准靶单投，把视觉前置缺口独立验证

装甲车置于前方开阔位置，采用已知能容纳圆环的高度与构图，先证明搜索模式下“类别＋圆环→关联→有效坐标→确认”成立，再允许任务中断投递。同帧两种框出现只是中间证据，不能代替map_valid和候选确认。

装甲车通过后测试桥靶。先保证完整视场，再引入略偏心构图；不从截断严重、近墙、遮挡开始。缺环时当前精修器不会自动指挥爬升：本阶段靠预设观测高度验证，不把尚未实现的主动视场恢复写成已有能力。

### P3：低空两投，再三投

先用两个位置分开的目标，使首投后需要飞行一段才能获得下一个目标，避免两者一直同框。第二轮加入第三类目标，并记录实际槽序、重复候选抑制、投后恢复和下一航段启动。

重访依据必须是实测视觉候选，不把测试人员测得的靶坐标注入任务；测量值只用于离线误差评估。该阶段通过才能说明投递执行链适合被高位策略复用。

### P4：高位记忆重访，先隔离记忆与飞行交接

4×4内设置有余量的内环。先单个独立红十字：飞完一圈、冻结实际找到的一个目标、降至低位、重捕、投递、恢复后在最后目标附近按专项落地。再增加装甲车至两个，最终三个；数量为1/2/3均应正常结束，无目标应报告未完成，不生成虚构队列。

首批沿用02专项“完整一圈后重访”，用来观察整圈定位一致性。随后单独开启比赛候选模式：“全部三个指定高权重线索合格则提前结束高位搜索；否则到路线结束／既定预算后转入已设计的恢复策略”。全圈测试与提前结束测试分别记录，不混算效率。

必须验证：高位线索作为低位接近提示，低位仍需新鲜几何/投影/释放证据；目标ID、类别及访问顺序可追踪；一个目标重捕失败不清空其他有效目标。首次高位闭环可用mock隔离策略，正式晋级P6前仍须真实释放通过，不能长期停在mock成功。

空场高位通过后，再增加一处可控障碍，只改变障碍条件，检查不从树上方越过、不可达点交接及补搜。禁止越树功能不是将航高提高即自动具备：当前板载最简配置关闭人工障碍柱，研究分支的规则约束和相应规划配置需明确集成并验证。

### P5：H单独验收，再接已成功的走廊

H先放起飞点前方约2m：低空接近→在固定XY处升高取得H特征→对齐→下降→落地。记录H观测与飞行阶段一致、最终水平误差和落地状态；人工POSCTL接管降落不算自主H通过。

随后复用已成功的走廊门位、航点、速度和规划配置，只新增末端H交接。H识别爬升点必须在已离开门洞且具备净空的位置，不能在窄门里原地拉高。实测几何决定走廊高度；不把旧04专项1.4m默认值直接当比赛门洞可用值。

如果走廊相关源码/参数未改，本阶段重点验“进入走廊的初始状态、过门后接H”，不重新做一套基础避障研究。

### P6–P7：完整链与可比较的效率

先固定场地、三类目标和门位。P6低空全链是实机回退方案；随后相同布设、相同低位/走廊速度/释放配置运行高位方案，只比较搜索策略变化。记录总时间及搜索、重访、对准、机构等待、恢复、投后入廊、过门、H降落各段，不能用某轮视频长度或失败提前结束判断更快。

P7先分别改变靶位、门位、障碍位置，最后组合随机布设；近墙目标、视场截断、一个高位点不可达、只发现1–2个目标均属于后续样本。机构不可用、旧帧/缺TF等异常优先在地面或离线验证，不通过空中故意断开制造故障。任何效率比较同时报告完成情况、落点误差及接管次数。

## 6. 每轮记录与通过尺度

每轮保存一行登记：阶段/目的、源码revision及未提交修改、实际启动参数、布局照片/尺寸、相机方向、任务坐标系与地面基准、真实或mock、槽位装载、正常结束方式。仅在修改机架/安装时重测外参；每次飞行确认实际加载的是这份外参。

沿用详细录包与 [bag回放工具](../../../tools/bag_replay/README.md)：原图/CameraInfo、TF、位姿/设定点/规划、视觉原始/精修/地图/候选、任务指令/结果、对准证据/许可/释放结果。板端已有录像不要重复多路录原始视频。原始bag留本地归档，报告/索引进入Git；回放后只清理可再生帧，保留原始数据。

| 指标 | 判断方式 |
|---|---|
| 任务通过 | 预定步骤和结束条件全部成立，无人工补任务；失败/接管不删记录 |
| 投递成功 | 任务回执与真实释放观察同时记录；mock单列 |
| 对准精度 | 报投影坐标误差、释放时槽中心误差、包裹落点误差，三者不能互相代替 |
| 定位稳定 | 同一物理靶跨阶段位置差、返回偏差；无真值时只叫重复一致性 |
| 飞行表现 | 实际AGL依据、速度分布、最长无进展时段、规划失败与控制模式切换 |
| 效率 | 同布局完整任务计时；未完成轮保留到失败耗时，不充当节时收益 |

投递精度初期先测量分布，以实际靶有效得分区和包裹尺寸判断落点；此方案不凭空宣称“10cm即比赛通过”。建议每个关键模块至少两次连续完整通过后晋级；单次过门成功继续保留为成功，不被这一建议追溯改成失败。

## 7. 下一次到场建议

第一组：P0机构准备与独立红十字预览→P1红十字实投及恢复→P2装甲车单投。有异常就停在对应层定位，不直接增加高位策略。

第二组：P3低空连续两投/三投；穿插P5 H专项与已有走廊串联。

第三组：在完成高位入口适配后执行P4的1→2→3目标，再安排P6完整比较。每组不要求一天飞完，也不预设实际成功时长。
