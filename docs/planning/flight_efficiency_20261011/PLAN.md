# 飞行效率与过门能力长期优化

2026-10-11。任务排序以根目录VISION_2026_ROADMAP.md为准；本文件定义测量与验收，不是已实施的飞行补丁。

## 测量方法

| 项目 | 分解计时 | 优化方向与验收 |
| --- | --- | --- |
| 起飞升空 | 控制接管→首个爬升设定点→实际离地→达到搜索高度→首段搜索运动 | 区分任务等待、设定点限幅与飞控爬升响应；明确瓶颈后调整一项，不直接提高全部速度。比较用时、超调和横漂。 |
| 中断后下高停顿 | 中断决定→下高目标→下降完成→限高ACK→下一目标→首条有效轨迹→实际运动 | 区分地图/位姿等待、阶段确认、重规划与任务重复等待。可准备下一目标，但派发仍满足当前约束；保留原期限。 |
| 高位航点停滞 | 每个目标ID的到点事件→下一目标发布→轨迹生效→实际离开 | 输出逐点表、P50/P95/最大值、全场累计等待；未到达与失败跳点单列，转弯低速不直接算停滞。先测量再决定是否连续过点。 |
| 第一门避障 | 碰撞预测→新轨迹→对应地图→控制设定点→实际机体轨迹 | 核查门框净空、轨迹完整检查、地图更新后的停止/重规划响应及门前后约束是否被优化删除。不能仅以没有ABORT为通过。 |

测量使用ROS事件时间、目标ID和轨迹ID，注明采样间隔；实际运动判据与速度噪声门槛随分析报告公开，不将统计门槛新增为飞行停稳条件。用同一路线、同一版本、同一参数对照，保留有效搜索覆盖和门口转向余量。当前尚未形成逐航点停滞统计表。

## 第一门已有结论

来源：本地`试飞产物/analysis_flight_10111009_1/COLLISION_REPORT_1.md`及原始第一轮bag。用户确认撞第一道门。

- 195.673秒规划器报告当前轨迹预测碰撞；196.045秒发布新轨迹。因此避障检查及重规划并未完全失效或关闭。
- 门前后共线点被合并，实际目标从入口列直接到走廊末端。输入点不等于逐点约束，目标X约7.692不能保证整条曲线保持该X。
- 199.5秒规划/设定X约8.145，实际FC约8.136～8.140；约45cm横移主要来自规划曲线，当时X跟踪差不到1cm。规划同时从0.9m降到约0.423m，实际FC约0.51m。不能全归因于飞控跟踪不准。
- 200.258秒已切MANUAL，205.200秒才记录manager ABORT；碰后定位异常不能倒推为碰前超高或ABORT导致撞击。

结论是“在线避障在运行，但本场景实际避障失败”，不是“避障可靠性已经通过”。尚缺真实门洞中心/高度、完整运行参数/版本及同一时刻规划查询地图，不能确认是打点、建图、膨胀、曲线验证或执行响应中的哪一项单独造成碰撞。

## 下一步核查与验证

1. 对齐同一时刻地图、重规划曲线和机体外廓，避免用不同时间或混合高度的点云投影判定碰撞；点云stamp为0时保留接收时间限制。
2. 核对原始占用、膨胀、未知区域、完整轨迹检查与碰撞预测后的制动/继续执行行为；缺记录处只补必要诊断。
3. 对门前后点区分普通中继与穿门约束，检查优化后的路线是否仍满足实际门洞中心和高度净空；不盲目关闭全部运动优化。
4. 在获得单独运行授权后，做固定门场景验证，再现场验证：整机无接触通过、地图变化时能停下或生成可行轨迹、无路径时不继续冲门；脱困研究的“退出后重规划”不能代替碰前避障。

现有串行投递、类别阈值及恢复研究的验收状态分别保留，不由本计划宣布上板通过。
