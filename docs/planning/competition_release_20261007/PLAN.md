## 后续卡住后恢复能力（待实施）

目标：规划/跟踪卡住后，安全退出到可用净空点，再继续原未完成航段；“退回”优先指进入困难区域前的近邻安全点，不默认返起飞原点，不保证旧点当前仍安全。

- 先区分无进展、跟踪保持、起点落入膨胀/虚拟柱、真实阶段高度超限和FC坐标reset，沿用总任务/动作期限及人工接管优先级。
- 地图保留实体及必要机身净空、额外虚拟延长的来源。只有满足实体净空的恢复路径才可采用；不能清空周围地图或随意缩小必要膨胀。
- 从当前真实估计位置和速度出发，在新鲜地图上检查完整退出路径，低速受控退回最近可达的合法点。历史安全点需按当前地图重新检查，不跳过起点、不瞬移规划起点、不直接沿原轨迹倒放。
- 高度恢复仅针对定位可信的真实软件限高超限，检查下降净空并允许制动过程；FC单独reset不能按错误高度下压。硬场地上限、实体碰撞约束继续有效。
- 恢复轨迹贯通搜索、最终样条/距离场检查、轨迹服务器和控制器，避免规划放行而执行仍锁住。释放期间及结果不明时保留事务和槽位锁，恢复不触发重复投递。
- 回到合法起点后，重新规划到原未完成设计目标；门前/门后顺序不自动跳过。不反复循环或重置总计时，失败进入已有保持/失败处置。
