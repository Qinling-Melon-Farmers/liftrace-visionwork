# 冻结试飞后的完赛时间优化计划（2026-10-03，仅计划）

用户明确要求本轮只更新速度计划，不实现，不改位姿跳变保护、飞行参数或当前板端。不因工作台修复启动仿真。导航基线是 `feat/high-view-liveness-20260919`，不是已停用VCL06。

本次对照视觉研究 `7fec701`、导航 `d010cd4`、板端 `13b2f15` 的实际执行代码。研究快速入口与室内专项不是同一速度档；[整机接线及冻结差异](../competition_freeze_20261003/REVIEW.md)须先处理。

## 1. 为什么测试到点停顿，正赛会不会停

**会。当前完整策略也沿用逐个目标→减速到达→稳定判定→下一个目标的执行链。** 高位优先改变搜索/访问顺序，并没有将单点规划变成连续通过航点。

| 层次 | 当前机制 | 对停顿的贡献 |
|---|---|---|
| Fast-Planner `kino_replan_fsm.cpp` waypointCallback | 显式 `end_vel_.setZero()` | 轨迹趋向以零速度到目标；不能仅靠关“等待时间”变成连续飞行 |
| `planner_execution.py` 到达确认 | 有对应轨迹结果；新鲜同frame位姿；三维位置误差、三维速度同时满足；必要时yaw也满足；持续驻留 | 默认速度≤0.20m/s且驻留0.50s；抖动/陈旧位姿会重置驻留，不是固定只停0.5s |
| board `trial_config.py` | 位置容差0.12m、驻留0.8s | 室内专项为验证链路更保守；不能据此推断研究档各点也固定等0.8s |
| 研究常规桥接档 | 常规位置容差0.18m、驻留0.5s；APPROACH有独立接近容差 | 仍需停车交接；投后恢复等特定阶段另有0.12m/0.8s，不能混作全场参数 |
| 发布下一个目标/新轨迹 | 当前点完成以后才继续 | 包含调度、重规划和设定点交接时间；不是所有可见停顿都来自驻留 |

RETURN到达还涉及约0.10rad的航向判定。三维速度门槛意味着垂直方向尚未稳定也会让航点等待；应看XYZ/速度/轨迹状态解释，不能只看俯视位置。原来把航点四元数误当速度会给出错误+X末速，已被零末速修复；**不能为提速撤销这个修复**。

## 2. 现有速度档的口径

| 参数 | 研究快速入口 | 现场专项 | 含义 |
|---|---|---|---|
| 规划速度上限 | max_vel=1.2m/s | 通常0.5m/s | 轨迹约束，不保证实速 |
| 规划加速度上限 | max_acc=1.0m/s² | 通常0.35m/s² | 决定短航段能否达到上限 |
| 前视/设定点限距L | 高位巡航1.0m，精调0.4m，近边0.2m，门/H/终止0.15m | 独立现场限距与低速配置 | 单位是米，不是m/s；traj_server与下游限距应一致 |
| 快走廊开阔档L | 0.4m；门墙附近0.15m | board生成器移除corridor_speed_schedule | 不要认为专项0.5等于研究走廊已按该分快档实飞验收 |
| 名义速度预算 | 0.5m/s | 独立预算 | 估算任务时间，不发运动命令 |

研究门区慢档在距门墙平面≤0.75m时进入，≥0.95m退出；距H≤0.8m为接近档，既有迟滞应保留。初始起飞、视觉精调、恢复和降落不全部经过Fast-Planner，统一提高max_vel并不能加快所有阶段。

## 3. 可以先做的优化及难度

这里的“先做”指将来获准实施的顺序；本轮没有代码改动。

| 方向 | 具体实施边界 | 难度 | 验证/收益判断 |
|---|---|---|---|
| 起飞爬升 | 定位/地面基准稳定后，分离垂直爬升曲线与普通XYZ限距，保持起飞XY锁定；核对PX4实际升速/加速度参数 | 中 | 真值/估计高度、vz、倾角、横漂、位姿丢弃；从解锁到低位/高位稳定分别计时 |
| 靠边目标远段快、近段慢 | REVISIT/DELIVERY当前只看目标near，导致整条长航段都慢；改为依据沿实际路径剩余距离、当前净空与制动余量分段 | 中 | 远段速度提高且末端不超调，不削弱边界许可。不要仅按到靶心直线距离切档 |
| 减少无意义停点 | 合并同一直线的重复导引点；保留视场转折、避障、门前/H/投递功能点 | 小到中 | 覆盖率和被跳过区域补扫不退化，特别复查场地中央panzer盲区 |
| 稳态确认缩短 | 针对普通巡航停止点评估更短驻留；不动释放前稳定、H对准、门前下降许可 | 小实现、中验证 | 先统计每点等待构成；不能把所有dwell设0（当前配置也不允许0） |
| 真正连续过点 | 给普通巡航点增加明确“通过”语义；停车点维持现行规则；规划非零末速及下一轨迹及时衔接 | 中到大 | 涉及manager/bridge/planner/traj_server同一契约，见下节；不是一个YAML开关 |
| 重访对准 | 提前应用所选槽位补偿、复用同ID/同槽/同frame且新鲜的观测，重捕与精修有界 | 中 | 报真实靶心/释放口误差、陈旧帧比例、许可耗时，不仅比ACK时间 |
| 投后恢复/入廊 | 依据可规划起点确定恢复高度；开阔3D通道才考虑恢复与水平转场衔接 | 中到大 | 不再出现投后起点占据；进入门区前达到合法低位并完成必要减速 |

0.5m/s与0.35m/s²下理想制动距离约0.36m；若速度改1m/s而加速度仍0.35，单制动距离约1.43m，尚未包含通信/控制延迟及跟踪误差。这解释室内6m航段和狭窄门前不能仅加倍速度。实际加速度若达不到配置值，所需余量更大。

## 4. 连贯飞行怎样实现，避免再叠加一套FSM

只扩展既有航点执行契约，不新建并行的速度任务状态机。

1. 普通巡航点允许通过，投递捕获、门前降高、窄门约束点、H对准、任务终止维持停车/稳定。路线生成时明确标注用途，禁止按“所有SEARCH都不停”处理。
2. 通过点以沿路线进度/越过点的横截面、横向及高度误差和方向一致性确认；加入滞回，避免靠位置球半径提前吞点。不能对通过点继续要求速度≤0.20m/s。
3. 规划器的边界条件显式携带期望通过速度/切线，下一段可提前规划；只在新轨迹通过检查且关联当前任务序号时交接。禁止借Pose四元数传速度。
4. 无后续安全轨迹时，保留可刹停的旧轨迹末端，按照既有失败策略处理；“连续”不能意味着无轨迹仍一直向前发点。
5. 转弯按实际曲率约束 `v²/R ≤ a_lat`，长直段提速，转弯平滑降速。普通视觉任务被中断后仍需有界制动并进入低位确认。
6. 日志分别记录：几何过点、planner接受下一目标、trajectory交接、动作完成；保持已有任务ID/轨迹ID因果关系，避免轨迹服务器先停而FSM还等或反之。

理想长航段下，每个停止点除了驻留，还多出减速再加速的时间；速度上限v、加速度a时这部分量级约v/a。板端0.5/0.35的示例约1.43s，加0.8s驻留约2.2s/点，仅用于筛选优化位置，不能承诺现场每点必省此值。短航段、避障绕行、视觉中断会改变估计。

## 5. 对准、恢复、入走廊的具体机会

### 5.1 对准与释放

高位粗线索用于导航，低位确认/精修仍负责身份与位置，最终新鲜释放许可不省略。不能因新模型准确些就把粗记忆当作可投坐标。优先把“到视点才开始处理”改为接近时持续保留可复用的新鲜观测，满足当前目标、槽号、frame、图像时序后减少重复等待。

将不同槽位的机体平移补偿提前体现在接近/对准参考中，避免相机中心到靶心之后再整机横移一次。换槽须刷新目标偏差及许可，不能重放上一槽结果。圆环/YOLO阈值放宽属于检测评估，不作为本轮速度优化捷径。

用户保留的每投10秒机构预算是预算储备，不应实现成固定sleep10秒。正确反馈到达后可继续；没有物理离机反馈时如实区分服务ACK与机械释放。可在等待中计算下一目标/路线，但不能在释放未完成时执行离开动作。

### 5.2 恢复和走廊入口

历史成功31/32/37的最后恢复约2.21/3.48/2.71s，入口调整与下降约7.31/4.83/3.79s；走廊与后段约73.79/71.66/69.10s。不同历史版本，仅用于说明量级：不能为省2秒恢复破坏可规划起点，而忽视一分钟以上的后段。

最后一投之后先恢复到可规划姿态/净空，再去入口暂驻点；若开阔空间允许，可规划一条带受控高度变化的三维航段减少“先原地高升、再横飞、再原地降”。前提是扫掠整个体积可通行、目标高度含ground/机体偏置、实际门前能刹停。靠墙/门边没有该通道时保持分段。

已有走廊分段档只在已验证的开阔段提高前视，窄门附近保留慢档和迟滞；上次把水平膨胀全局缩小牵连走廊的教训仍适用。此次不新增膨胀切换逻辑，不把禁飞柱、碰撞包络和速度档混为一件事。

## 6. 测量和实施顺序

验收前先固定候选代码、模型、场地、录制与位姿保护口径；不得用不同碰撞包络/模型/地图的旧用时作为纯速度A/B。历史seed2672原走廊/快走廊/3m轮的251.667/187.733/216.548s说明分段有潜力，但不代表当前板端完赛时间或3m一定更快。

建议先完成当前冻结整机验收，再逐项比较：

1. 从已有日志把每个航点的移动、刹停、dwell、规划等待、视觉等待分开统计；实速分位数与停顿次数一并输出。
2. 独立起飞爬升档、普通点驻留/重复点、近边重访远近分段，分别做单因素验证。
3. 普通巡航连续通过作为独立接口变更；不得同时调整YOLO/圆环阈值或撤掉位姿保护。
4. 对准预补偿、最后恢复/入口三维衔接排在成功率稳定之后；每阶段同时比较时间、实际偏差、规划失败和接管次数。
5. 高速拍摄专项使用0.5和1m/s对照，同一模型、同一靶位/光照；区分在线处理帧与节流后的bag帧，5Hz录像不能证明每个检测周期都有/没有结果。现场轻量录制保持冻结，若需要更高频数据另设采集配置，不扩大所有试飞负载。
