# v5 标准六分类数据集与飞行对地增强计划

> 日期：2026-07-14（持续更新）  
> 标准数据集：`vision_ws/test_data/yolo_dataset_v5_6cls_redcross_standard_20260713`  
> 当前默认 dev/sim 权重仍为：vision_ws/runs/liftrace_6cls_v5_flight_aug_20260713/weights/best.pt；20260714 新训练模型暂为候选

## 1. 当前数据事实

v5 是由 v4 合并结果整理出的训练标准入口，保留六类顺序：

```text
0 bridge
1 panzer
2 pillbox
3 tent
4 tank
5 red_cross
```

当前合并 v5 标准集规模为 1163 张 train、232 张 val，共 1395 张图像；区域聚焦增强训练集为 4649 张 train、232 张 val。v5 根目录只保留：

```text
data.yaml
dataset_manifest.yaml
images/train
images/val
labels/train
labels/val
```

v4 中的 `_import_redcross_tmp`、`merge_summary.json` 和 label cache 不进入 v5。v4 原目录仍保留，作为导入过程和结果追溯依据。

红十字当前导入标注的语义必须特别记录：现有框主要覆盖中央红十字/内圈区域，不等同于完整随机靶外轮廓或黑色有效区。黑色外圈仍应由传统几何链验证；若后续希望 YOLO 框覆盖完整靶板，必须另行制定标注规范并重标，不能通过增强假设补齐。

## 2. 现有训练增强基线

当前 `train_6cls.py` 已使用 HSV、缩放、平移、水平翻转、mosaic、RandAugment 和 erasing，但仍有明显空缺：

- `degrees=0`，没有显式旋转；
- `perspective=0`、`shear=0`，没有倾斜视角模拟；
- 没有运动模糊、散焦模糊和压缩退化；
- 没有受控局部裁切和遮挡测试；
- `mosaic=1.0` 对小目标可能造成过度缩小，需要验证而非默认长期保留。

因此 v5 第一轮训练不应一次性把所有增强拉满，应采用单因素/分组消融，确认收益来自真实飞行退化而不是训练集变形记忆。

## 3. 面向飞行对地场景的增强清单

### P0：必须优先验证

| 类别 | 策略 | 建议范围与注意事项 |
| --- | --- | --- |
| 旋转/姿态 | 小角度 roll、视角旋转 | `±3°/±6°/±10°/±15°` 分级；不使用垂直翻转；保留原始目标的地面方向分布。 |
| 透视 | 俯视到斜视的仿射/透视变换 | 小幅开始，逐步增加；必须检查框是否退化、目标是否被拉成不符合相机几何的形状。 |
| 运动模糊 | 线性方向模糊 | 水平、垂直、斜向，短/中长度分级；模拟平移、转向、起降时的速度变化，不把所有样本都模糊。 |
| 散焦 | 高斯/圆盘散焦 | 模拟低高度对焦未稳定、起飞/降落瞬间；与运动模糊分开做消融。 |
| 小目标尺度 | 多尺度缩放和输入尺度变化 | 保留远距离小目标，控制 mosaic 不把目标缩到不可辨识；记录最小有效像素尺寸。 |
| 数据划分 | 按视频/场景分组切分 | 同一视频相邻帧不得跨 train/val；增强副本只能留在原视频所属 split，避免泄漏造成虚高指标。 |

### P1：第二轮加入

| 类别 | 策略 | 建议范围与注意事项 |
| --- | --- | --- |
| 局部裁切 | 随机边缘裁切、局部视野截断 | 保留一部分目标被截断的样本；若可见面积过小，删除该框或标为忽略，不能保留错误完整框。 |
| 局部遮挡 | CoarseDropout、矩形遮挡、轻度 CutOut | 模拟桨叶保护、机体边缘、障碍物和临时遮挡；不要遮掉所有关键形状，红十字与黑圈应分别测试。 |
| 光照 | 曝光、gamma、亮度/对比度 | 覆盖室外强光、阴影、逆光、起降近地反光；红色/蓝色颜色扰动要窄，避免破坏类别语义。 |
| 传感器退化 | 噪声、JPEG、轻度色偏、低照度 | 用于相机链路和板端编码退化；需保留原图作为对照。 |
| 阴影/反光 | 局部阴影、亮斑、低频照明 | 重点覆盖白色圆环、红十字和灰色地面；避免合成出真实场景不可能的纹理。 |
| 近地场景 | 地面纹理、斜视、边缘入画 | 起飞/降落阶段目标通常占比快速变化，保留低空大目标与边缘裁切样本。 |

### P2：有真实样本后再使用

- 轻度 copy-paste：只在地面平面、尺度、阴影和透视一致时使用；不能把目标粘到空中或穿过障碍物。
- MixUp/CutMix：先作为消融项，不作为默认增强；对红十字黑色有效区和多目标关联可能制造不自然边界。
- 合成雾、雨、强烈色偏：除非比赛场地确实存在对应条件，否则不应优先投入。
- 大角度透视、强剪切和大范围擦除：容易改变目标形状，可能提高离线分数却损害真实识别。

## 4. 推荐训练顺序

1. 用 v5 原始图像复现当前 v4 六分类训练口径，记录 v5 数据路径变更带来的差异。
2. 只加入小角度旋转、受控透视和多尺度，形成 `geometry` 实验。
3. 单独加入运动模糊/散焦，形成 `blur` 实验。
4. 加入局部裁切与轻度遮挡，形成 `occlusion` 实验。
5. 加入光照、噪声、压缩，形成 `photometric` 实验。
6. 对红十字、bridge 以及小目标样本做按类、按场景的错误分析，再决定是否使用 P2 增强。
7. 选出综合模型后，必须在原始 val、飞行退化 challenge 集和真实视频回放上分别评测，不用增强后的图像替代原始验证集。

建议训练产物采用独立名称，例如：

```text
liftrace_6cls_v5_standard_baseline_20260713
liftrace_6cls_v5_geometry_20260713
liftrace_6cls_v5_blur_20260713
liftrace_6cls_v5_flight_aug_20260713
```

## 5. 训练验收指标

- 六类整体 Precision、Recall、mAP50、mAP50-95；
- `red_cross` 在小目标、模糊、旋转、局部遮挡下的 Recall；
- `bridge ↔ red_cross` 混淆矩阵；
- 红十字框中心偏差和框尺度稳定性；
- 起飞/降落视频上的帧级召回、连续命中长度和首次发现距离；
- 原始 val 与 challenge 集性能差值；
- 推理时延、显存/内存和 RKNN 后处理一致性。

任何增强方案只有在真实退化集和回放链路上同时改善，才进入默认训练配置。

条件固定为运动模糊、旋转、局部裁切、目标变小、强光、暗光、遮挡和多目标同帧；几何变换同步更新 YOLO 框。逐条件 YAML 和结果位于 condition_*.yaml、yolo_stress_eval_*_20260714/summary.csv。
