## 3. 指标语义

### 3.1 P_confirm

一次 trial 从目标进入其声明的有效观察窗口开始，到离开窗口结束。窗口内同一物理目标必须
产生满足当前准入条件的候选：类别/profile 合法、连续帧满足、地图和关联有效、无拒绝原因、
年龄不超过 0.5 秒。partial trial 使用独立可见性口径，不能混入“完整入画”分母。

### 3.2 P_selected

满足 P_confirm 后，同一 stable ID 必须在离开窗口前出现在
`/uav_vision/selected_target`。有 confirmed 候选但未被当前排序选中，只计 confirm。

### 3.3 P_interrupt

visual-only 一律为 `null`，不得用 selected、typed decision、planner goal 或 planner
arrival 中任何一项替代。联合链必须在同一
`mission_id + decision_seq + target_id + target_first_seen + attempt + payload_slot`
动作键上得到真实执行 `STARTED/CAPTURE` 证据。

### 3.4 状态词

- `MEASURED`：trial 和六件套完整，不等于算法 PASS。
- `DIAGNOSTIC_ONLY`：诊断面；数值再高也不能改写为联合 Gate PASS。
- `NOT_GATED`：测量完成，但采用阈值未全部冻结。
- `NOT_RUN`：当前场景/runner 合同不具备有效测量能力，不计为 0 或失败样本。
- `FUNCTIONAL_REPLAY_ONLY`：实拍功能审片，无人工真值/同步 pose，不报告真实召回或地图误差。
