# 相机安装与当前飞行参数

当前SITL默认为R60候选：先导完整PASS，十seed2/10，未合main。硬件默认仍为此前配置，不能把SITL默认当作已验收实机配置。[全部运行参数及读回](verification/r60_full_matrix/REPORT.md#参数与记录)。

- 搜索1.40m、航线间距0.70m、投递取景1.60m；槽位静态/动态补偿为零。
- 三投后先到廊外1.40m，再同XY下降0.40m（到达误差0.05m）；之后走廊0.45m/H取景0.50m、规划顶界0.55m、指令顶界0.50m。
- 返程跟随步长0.15m、常规到达0.12m/停稳0.80s/速度≤0.20m每秒；Planner max_vel/max_acc仍1.0/1.0。
- SDF分辨率0.05m，XY/向下/向上膨胀0.30/0.30/0.10m；规划净空0.025m。局部端点调整搜索阶段0.15m，低空走廊0.10m，围绕原点、z不变。
- 世界是toudi3-random来源场景的迁移版本，走廊采用toudi4错列短墙样式，总宽1.50m、两通口严格0.80m；四棵树有0.30m垫座、总高约1.50m，无bigbox。

H完整环检测保留，并在R60入口开启同节点内的H笔画补充；它可以在外圈出画时找内部笔画结构，仍走原CameraInfo/TF/映射链。H对准10帧、横向0.08m，降至0.30m、AUTO.LAND高度条件0.40m。低空通过不等于转向/降落过程的完整机架净空足够，见[失败分析](verification/r60_full_matrix/FAILURE_ANALYSIS.md)。

相机标定图像1280×720，实机fx=725.351、fy=723.340、cx=631.672、cy=397.566；本轮Gazebo实际CameraInfo fx=fy=725.351，fy约0.28%差异明确保留。畸变与实际CameraInfo文件一并归档，不宣称渲染器与实机标定完全相同。

用户确认MID360正装位于机顶，相机在雷达IMU正下方21cm。当前IMU相对机体z=0.12412m、相机光心z=−0.08588m，差值恰为0.21m；前一个机体偏移来自仿真机架，实机须测飞控原点到IMU的关系。雷达射线原点(0.011,0.02329,0.13)m，内部雷达到IMU外参与IMU到相机外参分别配置。

图像随机体姿态/相机安装位置渲染，视觉投影使用对应TF；固定安装外参不能扩大镜头视场。水平平地近似下，机体1.4m时短边地面视场约1.31m；0.50m机体高度下约0.41m，因此低空H不能依赖完整1m外圈。

LIO提供水平位置/航向观测，飞控保留自身IMU/气压计高度融合；FreeDOM用融合机体TF和雷达安装关系建图。Gazebo真值只用于评测/记录。仿真额外接触代理的射线不可见有建模前提，不代表真实护圈遮挡可以忽略；[模型适用性说明](verification/r56_model_review/REVIEW.md)。

现场坐标按用户要求留待比赛处理，必须统一旋转/平移坐标数值和航向，不能只改frame名称。当前低空实际z误差仍在厘米到十厘米量级，不承诺实机仅靠名义0.65m就一定≤0.70m。
