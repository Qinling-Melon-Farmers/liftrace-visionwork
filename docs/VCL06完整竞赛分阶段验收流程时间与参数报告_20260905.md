## 4. 当前竞赛执行流程

```text
SITL 自动 OFFBOARD/解锁
  → 起飞点 (0, 0, 2.0)
  → 3D 误差 < 0.30 m 后 control_ready
  → 随机场、地图、Planner 锚点、Manager READY
  → /navigation/start_mission 只调用一次
  → 12 点蛇形覆盖搜索（2.40 m）
  → 视觉候选连续确认并形成 camera_init 地图坐标
  → red_cross / panzer / bridge 可立即中断
  → Planner 接近动态候选 (target_x, target_y, 1.20 m)
  → 冻结目标上下文，圆环或红十字视觉精对准
  → release_guard 统一检查事务身份、证据、控制态、位姿和高度
  → 短时 release_permission
  → Servo 安全代理 → raw mock ACK → payload slot commit
  → 恢复至不低于 0.95 m，继续被中断的同一个搜索航点
  → 三个 slot committed 后停止搜索
  → 九段已知走廊/H 路线，依次穿三门
  → H 上方 0.75 m，启用 H 检测并锁定 10 帧
  → 对齐下降 → SITL AUTO.LAND
  → ON_GROUND → LAND SUCCEEDED → Mission COMPLETE → disarm
```

`camera_init` 是局部坐标，着地后 z 可为负；落地依据是有限位置、H、AUTO.LAND、ON_GROUND、
LAND `SUCCEEDED` 和 disarm，而不是错误要求局部 z≥0。

H 检测主要几何阈值：外椭圆长宽比≥0.85、填充率≥0.70、半径 15～300 px；内部 S≤90、V≤110；
内部面积比 0.10～0.70、长宽比≥0.55、solidity 0.25～0.80、凹陷数≥2、缺陷深度比≥0.04，
内外中心距离比≤0.35。

## 11. 如何更快降落

r41 的降落已经稳定 PASS，`32.726 s` 不是整场时限阻塞。时间主要花在：

```text
等待首个 H：18.874 s（占 57.7%）
首帧到 10 帧锁定：1.873 s
锁定到 AUTO.LAND 交接：6.667 s
AUTO.LAND 到 LAND SUCCEEDED：5.312 s
```

因此优化优先级应是：

1. 在第 9 个 H 捕获航点接近末段提前预热 H 检测，但仍只接受晚于正式 LAND 指令的新鲜证据；
   理论上可回收等待首帧的主要部分。
2. 在专项 Gate 中评估把仿真 AUTO.LAND 交接高度从 0.40 m 提到约 0.60～0.65 m；可减少约 5～7 s
   手动下降，但不得直接外推为实机参数。
3. 10 帧锁存仅耗 1.873 s，不是首要瓶颈；不建议先靠降到 3～5 帧换取不足 1 s 的收益。

建议目标是把 LAND 从约 33 s 降到 20～25 s。当前总任务已有 170 s 余量，所以上述属于性能优化，
不是功能 PASS 的前置条件。本轮不修改飞行参数、不追加仿真。
