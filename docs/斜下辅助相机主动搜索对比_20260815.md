# 斜下辅助相机主动搜索对比

日期：2026-08-15

分支：`feat/oblique-camera-search-feasibility`

结论：**辅助相机有显著缩短搜索路线的潜力，但当前固定坐标原型稳定性未通过；不能据此
接入正式导航，也不能宣称 OpenCV 已适合真实赛场。**

## 1. 对比目的与边界

本次不再只统计“辅助相机比下视早看到几秒”，而是让评测专用外挂实际发布
`/fastplanner/goal`，比较两种搜索策略：

1. 基线：原 12 个非靶标坐标蛇形全覆盖，完成五类下视确认后返航；
2. 辅助：55°斜下 RGB 用 OpenCV 蓝色/椭圆粗发现，先走两行稀疏覆盖，再访问匿名粗候选，
   所有类别和最终地图点仍由下视六分类链确认，不足时恢复剩余全覆盖。

临时外挂只在 `uav_vision_eval` 中存在，未修改 `patrol_control`、正式 Mission Manager、
Fast-Planner 或执行机构源码。两种条件都禁止投递、Servo 和释放输出。

## 3. OpenCV 是否可行

固定姿态干净 Gazebo 烟测中，蓝环链获得 138 次观测、precision=1.0、地图误差 P90
约 0.013 m；主动首轮形成 4 个粗候选并实际缩短路线。因此它可以作为低资源粗发现基线。

它不能替代 YOLO：

- 只知道“像标准蓝环”，不知道 tent、tank 等中心图案类别；
- 红十字只有黑色外环，不在蓝环能力范围内；
- 真实环境的蓝色干扰、曝光、白平衡、阴影和磨损尚未验证；
- 一次错误粗候选会增加无效抵近成本，必须由连续帧、地图聚类、场地边界和下视复核约束。

若实拍 precision、有效发现距离或净路线收益不足，辅助粗发现应改用 YOLO，不要求坚持
OpenCV。

## 4. 双摄像头是否必须双 YOLO

不必须。推荐生产结构始终只有一个常驻 YOLO/RKNN 推理上下文：

```text
AUX_SEARCH        -> 只消费斜下相机
APPROACH          -> 斜下为主，接近下视覆盖范围时切源/低频交替
DOWNWARD_VERIFY   -> 只消费下视相机
DROP_ALIGN        -> 只运行下视检测和几何精修
VERIFY_TIMEOUT    -> 回辅助重捕获或恢复保存的覆盖索引
```

两路相机可以同时采集，但只有当前源进入长度为 1 的推理队列；模型不重复加载。这样既保留
YOLO 在真实环境中的鲁棒性，又避免两个推理实例同时占用 GPU/NPU。共享权重斜视召回不足
时，可训练独立斜视权重，但仍优先按阶段串行调度，不默认双模型常开。

## 5. 全随机世界和关键 corner case

当前 `toudi4_copy.world` 标准靶仍沿用旧坐标，只能作为原理基线。下一 Gate 应生成所有
标准靶和红十字随机布设的派生 world，并对同一 seed 分别运行基线/辅助，交换运行顺序。

至少分层覆盖：

- 辅助初始看见全部、部分、1 个和 0 个目标；
- 目标处于视场边缘、遮挡后方、场地边界及 planner 难到达区域；
- 蓝色干扰物造成匿名粗候选；
- 红十字可被辅助 YOLO看见、只能被下视看见、两者均在早期看不见；
- 粗候选坐标误差使下视 5 s 内无法复核。

评价指标应为最终发现率、搜索时间、路径、无效抵近、不可达、fallback、恢复后重复覆盖和
零错误投递，而不是要求辅助先看全所有目标。部分可见时，正确策略是先利用已发现候选，
再从最近未覆盖索引继续；若这反而增加总代价，应如实判辅助策略无优势。

## 6. 红十字策略

推荐用辅助 YOLO 对红十字产生高权重粗候选；发现后保存覆盖索引并优先抵近，只有下视
`red_cross` 语义和黑色外环/十字几何复核通过，才进入现有高权重中断投递链。复核失败则
恢复原搜索索引。辅助未发现时必须保留最低限度下视覆盖兜底。

可增加红色十字 + 黑色外环的 OpenCV 提示器降低漏检，但真实背景干扰未知，不能把它当成
红十字唯一检测路径。

## 7. 下一步 Gate

本分支完成固定坐标可行性收口后，不直接改正式控制。下一里程碑建议另开单一 feature
分支，范围只包含：

1. 一个 YOLO/RKNN 上下文的双相机阶段切源适配器；
2. 全随机全靶标 world 生成器和真值清单；
3. 辅助 0/部分/全部可见的同 seed 成对无 GUI A/B；
4. 红十字粗发现、下视复核、高权重中断和恢复索引；
5. 规划不可达时的候选跳过、最近未覆盖段恢复和总代价统计。

在多 seed 成功率不低于基线且搜索时间/路径中位收益足够显著前，不进入硬件采购或正式
导航接入。
