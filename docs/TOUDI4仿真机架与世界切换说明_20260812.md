# toudi4 仿真机架与世界切换说明

日期：2026-08-12

## 1. 当前默认仿真组合

统一仿真入口现在默认使用：

- 世界：仓库根目录 `toudi4_copy.world`；
- PX4 机型参数：`vehicle:=iris_mid360`；
- Gazebo 实际机架：
  `patrol_control/models/iris_mid360_downward_camera/model.sdf`；
- 下视图像：`/downward_camera/image_raw`；
- 相机内参：`/downward_camera/camera_info`；
- 图像光学坐标系：`downward_camera_optical_frame`；
- MID360：继续复用原 `mid360` 模型及 `/livox/lidar`、`/livox/imu`。

`vehicle:=iris_mid360` 不能改成 `iris_mid360_downward_camera`：前者对应现有
PX4 autostart 名称；新 SDF 通过 `vehicle_sdf` 参数覆盖 Gazebo 生成模型，两者职责
不同。

## 2. 相机安装与投影约定

ZIP 原模型将相机置于机体 `(0, 0, -0.05) m`，绕 Y 轴 `+90°`，Gazebo 相机
局部 `+X` 光轴因此朝下。组合 ROS optical-frame 旋转后的仿真外参为：

```yaml
translation_xyz_m: [0.0, 0.0, -0.05]
quaternion_xyzw: [-0.70710678, 0.70710678, 0.0, 0.0]
```

对应旧控制兼容像素轴映射为：

```yaml
pixel_to_body_matrix: [0.0, -1.0, -1.0, 0.0]
```

这些数值只属于当前仿真机架。实机必须用真实单下视相机标定覆盖，不得照抄。

## 3. 场景配套配置

仅替换 world 会导致飞机仍飞向 toudi3 旧坐标，因此本次成对新增：

- 旧视觉/旧控制固定路线：`patrol_toudi4.yaml`；
- 新视觉/旧控制固定路线：`patrol_toudi4_new_vision.yaml`；
- 全场覆盖搜索范围：`coverage_toudi4.yaml`；
- 仿真独立真值：`sim_target_catalog_toudi4.yaml`。

固定三投检测点当前对应 `dibao`、`qiaoliang`、`zhangpeng`，返航降落点对应
主 `landing_h=(-0.493412, -1.77269)`。toudi4 另含
`landing_h_clone=(2.78088, 6.28453)`，当前不作为主降落点。

## 4. 安全启动与检查

只看 world 和机架，不启动 PX4、控制状态机或执行机构：

```bash
cd /home/xhj/liftrace
source top_level_scripts/toudi3_combined_env.sh
liftrace_setup_toudi3_combined_env
SIM_NO_RECORD=1 top_level_scripts/sim_run.sh toudi4_rack_view \
  roslaunch patrol_control patrol_world.launch start_px4:=false gui:=true
```

检查话题：

```bash
rostopic echo -n 1 /downward_camera/image_raw/header
rostopic echo -n 1 /downward_camera/camera_info
rostopic hz /livox/lidar
rosservice call /gazebo/get_world_properties
```

停止仿真：

```bash
top_level_scripts/stop_toudi3_sim.sh
```

完整新视觉控制链仍使用兼容文件名
`toudi3_full_competition_sim_new_vision.launch`，但其默认 world、机架、相机话题和
航点均已切换到 toudi4。文件暂不重命名是为了避免破坏现有脚本与联调命令。

## 5. 旧基线回退

旧 `toudi3.world`、旧航点 YAML、旧 D435i 仿真机架均未删除。历史回归 launch
已显式传入旧 world/旧 SDF，避免受到新默认值影响。本次改动前的 `patrol_control`
和 `uav_mission` 快照保存在 `legacy_baseline/20260812/`。

- toudi4 能由 Gazebo 加载；
- 五类标准靶、主 H、H clone 和机架实体均存在；
