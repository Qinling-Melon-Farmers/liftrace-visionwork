# PX4 ULog 电机控制量可视化工具

独立桌面程序，使用 Tkinter + Matplotlib + pyulog。不连接飞控，不修改 ULog，不修改 PX4 参数。

## 安装与启动

需要 Python 3.10 或以上。Windows 官方 Python 通常自带 Tkinter。

```powershell
cd C:\Users\lihaoEN\Desktop\ssh\ulg_motor_viewer
python -m pip install -r requirements.txt
python app.py
```

也可以在命令行指定一个或多个文件、文件夹：

```powershell
python app.py "C:\Users\lihaoEN\Desktop\log_72_2026-10-4-12-05-42.ulg"
```

Linux 若缺少 Tkinter，需要安装发行版的 python3-tk 包。有图形桌面环境才能显示窗口。

## 界面操作

- **添加文件**：一次多选多个 `.ulg`。
- **添加文件夹**：批量查找日志，可勾选“包含子文件夹”。读取在后台线程进行。
- **日志列表**：Ctrl / Shift 多选以叠加对比，也可以“选择全部有效日志”。颜色区分电机，线型区分日志，图例 `[编号] M编号` 对应左侧列表的导入顺序。
- **M1～M4**：仅提取和显示前 4 个电机，勾选需要显示的通道。全 NaN 的未使用通道自动忽略；全零通道保留。CSV 和统计也只包含这 4 个电机。
- **显示飞行模式分区**：使用 `vehicle_status.nav_state` 的实际模式变化绘制背景色块，并标注手动（自稳）、板外（Offboard）、定高、定点、自动降落等。单文件显示整幅背景，多文件显示底部独立模式色带，色带中的 `[编号]` 对应日志曲线编号。短时段文字可能省略，左侧仍列出完整模式时间区间。未记录模式的区域显示“模式未知”，不会根据文件名或遥控开关猜测。
- **刻度**：控制量主刻度 0.05、次刻度 0.01；时间主刻度支持自动、0.2、0.5、1、2、5、10、30 秒，次刻度细分为 5 格。长日志选择过小间距时会自动放宽，缩放到局部后恢复所选间距，避免大量刻度卡住界面。
- **图表工具栏**：缩放、平移、恢复视图。
- **导出全部 CSV**：导出所有成功读取的日志，不受当前选择和通道勾选限制。在所选目录新建带时间戳的结果目录，包含逐采样数据和 `motor_statistics.csv`。同名源文件通过路径摘要区分。
- **保存当前曲线 PNG**：保存当前显示范围及曲线。
- **错误行**：点击查看无效文件头、缺少电机主题等原因；个别文件失败不影响其他文件。
- 同一路径已成功导入后会跳过。若文件内容更新，先清空列表再导入。

## 数据和统计含义

数据来源为 `actuator_motors.control[0..3]`，索引 0 显示为 M1，以此类推。存在多个 topic 实例时分别显示与导出。

飞行模式取自主实例 `vehicle_status.nav_state`，每条状态从其发布时间起保持至下一次变化。电机 CSV 新增 `nav_state` 和 `flight_mode` 两列；未知状态用 -1 表示。自定义或未识别的枚举显示原始数字，例如“模式 23”。对多旋翼，PX4 的 MANUAL（nav_state=0）通常对应遥控手动自稳，不是定高，因此标注为“手动（自稳）”；nav_state=15 标注为“自稳”。

这是控制分配后的电机归一化指令，不是电机转速、实际推力或最终 DShot/PWM 输出。Kill 后这些指令仍可能非零，而最终输出已经被锁定。不能用本工具单独判断停转原因或电机硬件故障。

电机编号不等同于物理输出通道。例如 M2 可能映射到 AUX4；位置需要结合机架配置核对。工具不自动猜测电机位置。

- 横轴为 `(timestamp - ULog头部start_timestamp) / 1e6`，是相对各自日志开始的秒数，多文件对比不按日历时间同步。
- 峰值、均值、样本占比使用全部有限值原始样本；统计包含起飞前和落地后，不自动推断飞行阶段。NaN 不按零处理。
- ≥0.95 为接近满输出，≥0.999 为满输出统计阈值。这是指令幅值，不能解释成对应百分比转速或推力。
- 满输出累计秒数采用相邻采样间前值保持估算，排除缺失值相邻区间；未记录的最后一个样本之后不累计。跨记录间隙仍是假设前值保持，不代表连续实际运行证据。
- 可逆电机可能出现负值，界面保留负值；当前满输出统计只统计正方向。
- 日志列表的跨度是第一至最后一条电机数据间隔，不等同于总文件记录时长。
- 大数据曲线仅在显示时抽取区间极值并保留缺失值边界，CSV 和统计仍使用完整数据。显示曲线不适合推断采样间的真实瞬态。
- 不支持仅包含旧版 `actuator_controls_*` 的日志，这类数据不等同于各电机控制量，程序会明确报错。
