① 看懂方向，填写范围

原点不移动

站在飞机后面朝机头看：前方是 +X，左边是 +Y。图上机头朝右，别把图的上方当作机头。

起飞点不在中间，怎么换算？

例：前9m、后1m、左2m、右4m。相对起飞点的物理外框为 X −1～9，Y −4～2。左右不相等完全正常，无需平移原点。

下方“FC飞行边界”应在物理外框内留出机体与跟踪余量；搜索区还要避开走廊。这个例子不会自动写入配置。

已有值来自当前所选配置。只改本次现场确实变化的范围，地图尺寸需包住全部航点。

② 生成搜索路线

用第①步的蓝色搜索范围生成，随后可拖点微调。

例如 0.20：四条边各内收20cm；0 表示沿蓝框边界。只是航点内收，不自动计算完整相机覆盖。

生成只替换搜索点，不改走廊、H、高度或速度。准备点 S 是进入搜索前的过渡位置，可用上方按钮单独设置。

③ 沿实际飞行顺序布点

点“＋走廊点”，依次点击门前 → 门后 → 下一道门前 → 门后 → H区。再点“设置H中心”。

示意图不是现场航线。每对门前/门后点须对着实测门洞中心；不要把墙上实心位置当航点。AGL 是 FC中心离地高度，不是脚架或镜头高度。

可选：填写墙面与低入口交接点

X常量墙在图上竖直，Y常量墙在图上水平；这里只填同一方向的相关墙，不能把四周不同方向的墙混进一组。入口序号指完成哪个走廊点后切换走廊限高。
