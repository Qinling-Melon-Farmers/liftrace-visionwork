# 飞行工作台界面方向

主任务是现场验证与离线证据复核，不采用营销首页。原有飞行控制、终端与遥测处理逻辑保持原样，以导航、操作分组和更清晰的文字层级改造界面。

- 配色：浅蓝灰 #edf3f8、白 #ffffff、海军蓝 #173b52、航空蓝 #17658d、琥珀 #c38a25；终端保持深蓝 #122333，以区别命令输出与操作区域。
- 字体：Microsoft YaHei UI 为中文操作字体，Bahnschrift 为可用的工程数字字体；终端沿用等宽字体，普通标签不使用等宽字体。
- 主布局：左侧固定工具导航，右侧是工作内容。主页连接与设备动作在顶部，任务 / 终端 / 遥测保持现有信息顺序。
- 离线页：左侧选择来源与导出内容，右侧保留任务阶段、结果和日志。视频与曲线使用各自参数与目录选择，不把视频编码参数放进曲线流程。

```text
导航      日志回放与分析                  本机离线
          日志与导出操作       任务状态 / 已有结果
          选择本地 bag         当前阶段与实际进度
          视频 | 曲线          播放器 / 分析报告
          独立导出目录        展开查看日志
```

设计审查：保留专业工具所需的密度，但移除“所有内容都是同尺寸卡片”的套件式布局；航空轨迹图形只出现在品牌及尚无任务的空状态，不散布装饰动效。页面不承诺没有证据的飞行状态。手机上导航与双列布局折叠，按钮保留键盘焦点，遵循减少动态效果偏好。
