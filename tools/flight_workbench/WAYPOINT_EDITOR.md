# 飞行前地图调整：按四步完成

模块04、08和独立正赛卡片都可打开“地图调整航点”。先选本次场地 YAML（配置文件），再按 **1 坐标与范围 → 2 搜索路线 → 3 走廊/H → 4 检查保存** 操作。更新本地服务后刷新页面。

查看页面标出的配置来源：在线读取所选板端文件，离线读取对应参考模板。**离线模板不能证明飞机当前用了这份配置。** 模块04只执行走廊/H专项，搜索点不会让它变成整场搜索任务。

## 1 坐标与范围：先量场地，再填范围

对照起飞坐标示意图，记住两件事：

- **屏幕右是 +X，沿起飞时机头朝前的方向；屏幕上是 +Y，沿起飞时机身左侧的方向。** 因而屏幕左是后方，屏幕下是右侧。这里说的“左、右”是机身方向，不是屏幕方向。
- **本次起飞原点永远是 (0,0)，不一定在场地中点。** 改边界不会移动原点；飞机转向后，地图坐标轴也不会跟着转。

例如：从起飞点量到机身左侧边界 **2m**、右侧 **4m**、前方 **9m**、后方 **1m**。四边按“X最小、X最大、Y最小、Y最大”填写，则物理外框为 **`[-1, 9, -4, 2]`**。屏幕上原点两侧不对称是正常的。

**这个物理外框不能直接当作 FC（飞控中心）的安全飞行边界。** 要实测机体、桨叶及突出部件的净空，并为转向、定位和跟踪误差留余量后向内收。例如每边内收0.4m，算得 `[-0.6, 8.6, -3.6, 1.6]`；0.4m只是算术示例，实际内收量以本机和现场测量为准。

页面几种范围各有用途，不要只改一个框就认为全场都已调整：

| 页面项目 | 当前后端实际用途 |
| --- | --- |
| 飞行边界 | 页面字段为 `center_bounds`，正赛对应 YAML 的 `flight_bounds`。用于航点、原点、H等坐标的外层检查及地图尺寸检查；04/08还将它用于规划搜索约束和障碍禁越柱的范围。填写可接受的FC中心区域，框内仍可能有墙、树箱等障碍。 |
| 搜索范围 | 页面字段为 `search_bounds`，正赛对应 `search_center_bounds`。路线生成以它为依据；正赛还用它约束搜索/重访网格及搜索阶段规划区域，应排除走廊和不适合搜索的区域。04/08用它生成低位搜索范围，高位搜索点及规划区域的外层检查仍用飞行边界。 |
| 低空覆盖范围（正赛） | `coverage_bounds`：供任务进入低位兜底搜索时生成覆盖路线，必须在搜索范围内。它不是高位路线的视场覆盖率，也不是新的飞行边界。04/08没有独立的此项，低位搜索沿用搜索范围。 |
| 目标范围 | `target_bounds`：供高位任务判断候选目标的接近许可、边缘复访及相应边界保护。不是填写已知靶标位置，也不保证其中每个目标都能投递。**正赛要求它在飞行边界内；04/08要求它包含飞行边界。** |

正赛的搜索范围在飞行边界内，低空覆盖范围在搜索范围内；准备点和高位搜索点须在搜索范围内。地图尺寸 X/Y/Z 是建图空间的总长度，不是四边坐标，且以原点为中心：起飞点偏在场地一侧时，仍要覆盖最远一边并满足检查要求的余量。

所有点和范围都要相对同一个起飞原点、同一组坐标轴测量。如果另一张图的方向与机头轴一致，可统一减去图上的起飞坐标；方向不一致时，还须转换方向，不能只减坐标。换起飞位置或初始机头方向后重新量点，工作台不会自动从GPS推算。

## 2 搜索路线：先生成形状，再微调

先填好搜索范围和准备点 S（升高搜索前的准备位置），再看路线缩略图，选择一种形状：

| 形状 | 生成结果 |
| --- | --- |
| 矩形 | 5点，沿四边一圈，第5点回到第1点。 |
| 两条扫描线 | 4点，在两个X位置沿Y往返，中间连线换到另一条。 |
| 三条扫描线 | 6点，在三个X位置沿Y交替往返。 |

“相对搜索范围内收”只把生成的搜索点从搜索框四边往里移，**不替你完成第1步的机体净空内收**。例如搜索范围 `[0.6, 7.2, -3.2, 1.2]`，路线内收0.2m，三线的X位置为 `0.8、3.9、7.0`，Y端点为 `-3.0、1.0`。

点击“生成 / 替换搜索点”会替换当前搜索路线，可撤销。三种路线**只改XY形状，不改所选YAML的高位高度、最大高度和速度**。想用另一高度，先选择相应配置；在同一份YAML里从三线改成矩形不会自动换高度。

已有点可以点选后输入X/Y精调，也可拖动；“上移/下移”调整飞行顺序，“删除”和“撤销”用于修正。搜索路线按编号前进，连线和缩略图只是设计路线，不代表实际避障轨迹或已经看遍所有靶标；生成器不计算实际视觉覆盖率。

## 3 走廊/H：按通过顺序填写门前、门后点

先量每道门的实际开口中心和两侧可停留位置，再按飞行顺序添加走廊点。对照门前门后图：同一门的两个点应分别放在墙的两侧，横向对准实际开口中心，连接它们的方向应穿过门洞。**不要把墙平面上的门中心写成停车航点。** 转弯或下一道门偏移时，按实际净空补充引导点。

例如向 +X 穿过 `X=5.0m` 的墙，实际开口中心为 `Y=0.5m`，可用 `(4.2, 0.5)` 作门前点、`(5.8, 0.5)` 作门后点；不把 `(5.0, 0.5)` 加为航点。这里的0.8m间距只是示例，必须现场核对门前后空间、机体净空和下降位置。

点选走廊点可输入X/Y和AGL；**AGL是FC中心离地高度**，不是镜头高度。新增点采用页面“新增走廊点AGL”，逐点核对，不要只看二维连线。H填写现场实测的H标记中心；“末点XY设到H”只改最后走廊点的XY，不改其高度，H接近和下降高度继续沿用所选配置。

墙面信息这样填：

- **墙轴X**：填写固定X的墙平面，如 `X=5.0`，地图上显示竖线；墙沿Y延伸。
- **墙轴Y**：填写固定Y的墙平面，如 `Y=-1.0`，地图上显示横线；墙沿X延伸。
- 多道墙用逗号分隔实测坐标。虚线只表示墙平面，供现有门附近保护/跟随规则使用，不表示门洞宽度、门中心或完整障碍轮廓。
- **入口序号从1起**，指进入走廊规则前需要完成的前几个走廊点，通常填1，即完成第1点后交接；不是门的编号。当前正赛正式检查要求此值为1。04/08地图检查允许1或2；只有原配置确有两点入口交接时才填2，入口交接点及之后默认AGL须不高于1.0m。

**墙面留空有条件：** 正赛留空会保留所选源YAML的墙参数，不会清除旧墙；只在源参数已实测且本次不改时这样做。启用运动优化的正式飞行仍需要有效墙面配置。04/08若已有墙面配置，清空其坐标会报错，应按实测填写，不能把留空理解成取消墙面保护。

## 4 检查保存：先核对，再生成本机草稿

1. 对照现场记录复核原点、四边、准备点、路线顺序、每道门前后点、AGL和H中心。正赛的“现场已实测确认”只有实际量过并核对后才能勾选，保存不会替你完成测量。
2. 处理地图检查提示，再点“保存到工作台”。**这一步只生成本机草稿和本组命令，不立即操控飞机，也不启动飞行。** 草稿按板端、工程目录、任务组及源YAML隔离，切换来源不会带入上一份草稿。
3. 回到本组核对生成命令，执行原“配置检查”。此时会在板端工程的 `logs/flight_workbench/site_overlays/` 生成并校验独立覆盖YAML；配置预览和后续飞行使用同一份覆盖文件，原现场YAML保持不变。地图或来源内容变化后重新生成命令。正赛仍走自己的 `deployment/competition/start.sh`。
4. **地图检查通过、正式配置检查通过，都不等于实体净空已实测通过，也不等于实际避障或视觉覆盖已验收。** 检查主要核对配置和坐标约束；门宽、机体能否通过、墙前后净空等仍需现场确认。启动任务是后续单独操作。

要停用草稿，回到本组点“使用原现场配置”；刷新不会重新启用已停用草稿。“恢复打开时的坐标”只撤销本次打开后的编辑，打开时可能已带有旧草稿。任务运行或等待确认期间不能应用、切换地图。
