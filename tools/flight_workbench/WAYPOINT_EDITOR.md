# 飞行前地图调整

模块04、08与独立正赛卡片均提供“地图调整航点”。更新本地服务后刷新页面。

1. 先选本次场地YAML。在线读取当前板端文件；离线使用同名参考模板，页面会明确标注。离线参考不证明板端实际配置。
2. 在地图点击添加搜索/走廊点；选择准备点或H后点击设置。点选已有点可输入X/Y/走廊AGL，支持拖动、排序、删除、撤销。
3. 可按当前搜索范围与内收距离生成矩形、两条扫描线、三条扫描线，随后手工微调。只改搜索点，不改飞行高度和速度，不自动估算覆盖率。搜索范围须排除走廊和不适合搜索的区域。
4. 正赛额外显示低空覆盖边界和“现场已实测确认”。空走廊/H需填完才能保存；保存不会替你确认场地。高位高度等沿用所选正赛YAML。
5. 保存并用于本组：只保存本机草稿并生成命令，不连接/启动飞机。草稿按板端、工程目录、任务组、源YAML隔离；切换来源不携带上一份。
6. 原“配置检查”会在板端生成并校验独立坐标覆盖文件。preview/flight使用同一份覆盖YAML，路径为工程内 logs/flight_workbench/site_overlays/。源文件保持不变；内容变化须重新生成命令。正赛仍调用自己的 deployment/competition/start.sh，不依赖08测试入口。
7. “使用原现场配置”停用草稿；下次刷新不会复活停用草稿。任务运行期间不能应用或切换地图。

## 起飞点不在边界中点

坐标原点仍是本次起飞时机体/FC参考位置(0,0)，不是场地中心，也不是场地左下角。
按现有约定机头朝场地+X，+Y向左；调整边界或航线不会改变定位原点。

例如起点距左边2m、右边4m、前边9m、后边1m，则名义外场边界是
`[-1, 9, -4, 2]`，顺序始终为 `[xmin,xmax,ymin,ymax]`。这是实测外场示例，
实际“飞行中心边界”还需按机体净空内收，不要直接当作允许机体中心贴边的位置。
搜索范围进一步排除走廊，如 `[0.6,7.2,-3.7,1.6]`；内收0.2m后，三扫描线的X为
`0.8、3.9、7.0`，Y端点为`-3.5、1.4`，不需要关于原点对称。

如果在另一张场地图上量点，机头轴与那张图平行时，统一减去起飞点坐标即可。
不平行时，必须把所有点与边界转换到同一任务坐标系，不能只平移而忽略航向。
起飞位置或初始机头方向改变后须重新确认地图；工作台不会自动从GPS推断起飞位置。

门墙虚线只是墙平面参考，不包含实际门洞/雷达点云。请填门前、门后的净空引导点；
地图检查不等于避障验收。正式三线2.16m、矩形/两线2.76m等高度取决于所选候选YAML，
地图中的“生成路线形状”不会偷偷切换这些高度。
