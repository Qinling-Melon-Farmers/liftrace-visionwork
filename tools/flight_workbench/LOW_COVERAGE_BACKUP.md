# 备用10：低空遍历全场（牛耕/回字形）（本地候选，未实飞）

这是额外备份卡片，原08与正赛卡片的入口和路线选择不变。需要板端先更新包含 `10_low_coverage_full`、`trial_low_coverage.py` 和新 `run_trial.py` 的0928入口，旧板端仅更新工作台无法启动此组。

## 怎么用

1. 选择“备用10 · 牛耕遍历全场”，默认模拟投递。
2. 选择搜索形状 **牛耕或回字形**，再选择 **FC离地1.8m（默认）或1.9m**。这里不是镜头高度，不能填0.18。
3. 点击“地图调整航点”，从本机导入已打点的 `waypoint_map.yaml`。支持原正赛平铺字段，也支持模块 `flight_area` 格式。
4. 在地图里核对起飞原点、准备点S、搜索范围、门/H，然后点击 **“保存并用于本组”**。只导入文件或导出文件不会应用到飞行。
5. 自动生成本组命令；改变形状、高度、投递方式或坐标后需重新生成，旧命令立即失效。核对命令含 `10_low_coverage_full/start.sh` 、`--coverage-pattern lawnmower` 或 `nested_rectangles`，以及 `--coverage-agl 1.8` 或 `1.9`，再运行配置检查。
6. 飞行按钮仍需现场确认；实投需选择真实投递并输入确认词。飞行命令会先对同一不可变地图运行 `preview --check-config`，成功后才进入 `flight`。

## 地图语义

原 `coverage_bounds` 映射为本模块 `flight_area.search_bounds`，作为牛耕遍历的范围。原 `flight_bounds`、`target_bounds`、`staging_xy`、走廊点和H均保留数值。原 `search_center_bounds`/`survey_xy` 属于高位搜索设计，本备份不执行该高位四边形；牛耕方向和间距以新模块配置检查为准。

本次随包的地图参考来自用户2026-10-15提供的waypoint_map：S=(0.6,0.05)，牛耕范围X=[0.4,6.8]、Y=[-4.1,4.1]，H=(8.3,-3.5)。五个走廊点仍为原图，不补造门前门后点，也不宣称已完善门保护。新现场请重新导入实测值。

虚拟柱与虚拟天花板关闭，实体点云和正常膨胀避障保留。高权重中断、投递补偿、投后继续搜索、走廊/H均复用新模块的现有链路。本备份与本次用户确认后的08投递FC目标均为0.25m；释放窗口仍继承当前08的0.10～0.45m，目标高度不等于释放许可阈值，其余投递/H策略继承08。本卡片不替换已有用户显式参数覆盖；02/06/独立正赛模板未扩改。最终候选由导航模块从测量范围动态生成：沿Y长线、跨扫描轴两端内收0.6m；牛耕间距2.6m、回字形独立圈内收1.8m；工作台不另添调节旋钮或发送间距覆盖。以当前模块配置检查输出为准。短路线以效率为候选目标，仅比较FOV理论扫过的地面面积，不把完整靶板或靶心覆盖作为本次指标，也不能把理想FOV覆盖写成实飞保证。bridge/panzer/red_cross形成有效确认可中断搜索，tent/pillbox在遍历后的选择逻辑中补充。
